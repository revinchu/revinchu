# KV 아틀라스 (`kv_reference/`)

광고 키비주얼 레퍼런스와 이미지·포트폴리오 사이트를 한곳에서 분류·필터링·검색·무작위 추천하는 정적 웹 페이지.
빌드 과정과 서버가 필요 없다. `index.html`을 브라우저로 열면 된다.

```bash
python -m http.server -d kv_reference 8000   # http://localhost:8000
```

## 구성

| 파일 | 역할 |
|------|------|
| `data.js` | 데이터: 사이트 180곳(16개 분류), 키비주얼 67건, 기법 20종, 무드, 업종, 광고 규격, 다국어 KV 키워드 |
| `app.js` | 화면: 해시 라우팅(`#kv`, `#sources`, `#search`, `#lab`, `#board`, `#specs`), 필터, 무작위 추천, 보드 저장 |
| `index.html` | 레이아웃과 스타일(라이트/다크 테마) |

## 화면

- **키비주얼 DB** — 업종·시대·기법·매체·무드 필터, 정렬, 필터 안 무작위 뽑기, 상세(아이디어 포인트·색상 코드·원본 이미지 검색 링크·비슷한 레퍼런스)
- **사이트 디렉터리** — 분류·지역·비용·검색 지원 여부 필터, KV 활용도순 정렬, 활용도 가중 무작위 추천
- **통합 검색** — 검색어 하나를 여러 사이트에 동시에. 검색창이 없는 사이트는 구글 이미지 `site:` 검색으로 대신하고, 영어·한국어·일본어·중국어·러시아어 KV 키워드를 붙일 수 있다
- **무작위·훈련** — 오늘의 키비주얼/사이트/기법, 칸 고정이 되는 연습 브리프 생성기
- **내 보드** — 키비주얼·사이트 담기, 직접 모은 레퍼런스(이미지 파일은 640px로 줄여 저장) 추가, 태그 필터, JSON 내보내기/가져오기. 브라우저 `localStorage`에만 저장된다
- **광고 규격** — IAB 배너, 소셜, 인쇄, 옥외 규격과 실제 비율 도식

## 데이터 원칙

- 키비주얼 원본 이미지는 저작권 때문에 싣지 않는다. 썸네일은 대표 색과 기법을 도식화한 것이고, 원본은 검색 링크로 출처 사이트에서 본다.
- 연도·제작사는 널리 알려진 공개 정보만 적는다. 확실하지 않으면 항목을 넣지 않는다.
- 사이트 추가: `data.js`의 `S` 배열에 `[이름, URL, 분류, 지역, 비용, 검색 템플릿, KV 활용도 1-3, 설명]`을 넣는다. 검색 템플릿은 `{q}`가 들어간 URL, 또는 `'site'`(구글 이미지 site: 검색), 또는 `null`.
- 키비주얼 추가: `K` 배열에 `[id, 제목, 브랜드, 연도, 제작, 업종, 매체[], 기법[], 무드[], 색[], 포인트, 검색어]`. 업종·매체·기법·무드는 같은 파일의 목록 값을 쓴다.
