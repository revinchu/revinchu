# 01. 기술 상세

## 1. 화면 구성 (PowerPoint 와 같은 배치)
제목 표시줄(저장 · 실행 취소 · 쇼 · 문서 이름 · 명령 검색) → 리본 탭(파일 · 홈 · 삽입 · 디자인 · 전환 · 애니메이션 · 슬라이드 쇼 · 검토 · 보기 · 도움말 + 상황별: 도형 서식 · 그림 서식 · 테이블 디자인 · 레이아웃 · 차트 디자인) → 왼쪽 슬라이드 미리 보기 · 가운데 편집 화면 · 아래 슬라이드 노트 · 오른쪽 작업 창(도형 서식 · 배경 서식 · 애니메이션 창 · 선택 창) → 상태 표시줄(슬라이드 n/N · 보기 단추 · 확대/축소).

## 3. 데이터 모델
`CLAUDE.md` 참고. 핵심: 좌표 px(96dpi), 글자 pt, 색은 `#hex` 또는 `@테마색:변형`, 그룹은 `grp` 같은 값(배열에서 붙어 있어야 함), 그림은 `pres.media[id]` dataURL.

## 4. 편집 화면 동작
- 글 상자 · 개체 틀은 클릭하면 바로 편집(커서 위치), 도형은 선택 후 글자 입력 · 더블클릭으로 편집, 표는 칸 더블클릭 + Tab 이동(마지막 칸 Tab = 새 행).
- 그룹: 첫 클릭 = 그룹, 다시 클릭 = 그 안의 개체 (PowerPoint 와 같음).
- 끌기: Shift = 가로/세로 고정 · 비율 유지, Ctrl = 복사, Alt = 스마트 가이드 끔. 회전 Shift = 15° 단위.
- 넘치는 글: '넘치면 텍스트 크기 조정' 은 편집을 마칠 때 글꼴 비율을 계산, '텍스트에 맞게 도형 크기 조정' 은 입력하는 동안 높이를 맞춤.

## 5. pptx
- 쓰기: 마스터 1 + 레이아웃 9(+ 불러온 배경 장식 묶음마다 1), 모든 글 서식을 명시적으로 기록, 표 · 차트(리터럴 값) · 메모 · 전환 · 애니메이션(p:timing) · 구역 · 바닥글 · 하이퍼링크 · 그림 자르기/효과, WIPOINT 확장(JSON)으로 같은 앱에서 정확히 왕복.
- 읽기: 개체 틀 위치 · 글 서식을 레이아웃 → 마스터 → txStyles 로 상속, 테마 스타일 참조(fillRef/lnRef/fontRef), 색 매핑(clrMap), 그룹, SmartArt 그림 파트, AlternateContent, custGeom, 마스터/레이아웃 도형(배경 장식 `bgObjects`), 전환 · 애니메이션.
- 검증: python-pptx(PowerPoint 기본 서식) · LibreOffice 재저장 파일 테스트, LibreOffice Impress 로 우리 파일을 열어 렌더링 비교.
