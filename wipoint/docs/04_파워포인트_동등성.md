# 04. PowerPoint 동등성 점수표 (WIPOINT 1.4)

기준: Microsoft PowerPoint (Microsoft 365, Windows) 에서 일반 사용자가 쓰는 기능. 점수는 "같은 결과를 같은 방식으로 얻을 수 있는가" (100 = 같음).

## 100점까지 남은 것 (다음 우선순위)
1. 도형 병합 (통합 · 결합 · 조각 · 교차 · 빼기) — 경로 불리언 연산
2. SmartArt 레이아웃 확대 (목록 · 프로세스 · 주기 · 계층 · 관계 · 행렬 · 피라미드 각 10종 이상) 와 dgm 데이터 모델 저장
3. 3차원 차트 · 폭포 · 트리맵 · 선버스트 · 상자 수염 · 깔때기 차트
4. 애니메이션 효과 추가 (나타내기/강조/끝내기 각 30종) · 전환 추가 (커튼, 소용돌이 등 3D 계열)
5. 그림 예술 효과 · 그림 압축 · 사진 앨범 고급 옵션
6. 쇼 녹화(내레이션 · 잉크 타이밍) · 실시간 자막
7. 사용자 지정 레이아웃 추가 · 개체 틀 삽입
