# 04. PowerPoint 동등성 점수표 (WIPOINT 1.8)

기준: Microsoft PowerPoint (Microsoft 365, Windows) 에서 일반 사용자가 쓰는 기능. 점수는 "같은 결과를 같은 방식으로 얻을 수 있는가" (100 = 같음).
