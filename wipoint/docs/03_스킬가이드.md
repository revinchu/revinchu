# 03. 스킬 가이드 — WIPOINT 에 기능을 넣는 방법

## 1. 명령 추가
1. `src/commands.js` 의 `register({ ... })` 에 `이름: () => …`. 문서를 바꾸면 반드시 `change(() => { … }, { scope })` (scope: `slide` 현재 슬라이드 · `all` 전체 · `none` 다시 그리지 않음).
2. 리본: `src/ribbon.js` 의 탭 정의에 `L(명령, 아이콘, 글자, { menu })` · `M(...)` · `B(...)`. 켜짐 표시는 `on: '키'` + `commands.js` 의 `ribbonState()` 에 같은 키.
3. 아이콘: `src/icons.js` 에 `이름: svg(\`…\`)` (20×20).
4. 단축키: `src/app.js` 의 `onKey` (편집 중이면 `onEditCtrl`).
5. `tools/smoke.mjs` 로 확인 → `bad 0`. 사람 손이 필요한 명령(파일 고르기 등)은 `SKIP` 에 추가.

## 2. 대화상자 · 메뉴
- `openDialog({ title, body, buttons })`, `formDialog(title, fields, onOk)`, `openMenu(anchor, items)` (`ui.js`, WIXEL 과 같음). 색은 `colorMenu(anchor, onPick, { none, auto })`.
- 입력 칸 `keydown` 에서 `e.stopPropagation()` (편집 화면 단축키로 새지 않게).

## 3. 글 서식
- 편집 중이면 `applyTextFormat(runProps, paraProps)` (선택 범위 · 커서 단어), 아니면 선택 개체 전체 `applyRunProps`. `commands.js` 의 `applyRun` / `applyPara` 가 둘을 고릅니다.
- 새 글자 속성은 `render.js` `runHtml`(그리기) + `pptx.js` `rPrXml`(쓰기) + `readRPr`(읽기) 세 곳.

## 4. 새 개체 종류 · 도형
- 도형: `shapes.js` `shapePath` 에 case + `SHAPE_GALLERY` 에 이름(OOXML prst 이름 그대로 쓰면 pptx 가 바로 맞음).
- 개체 종류: `render.js` `objectHtml`, `pptx.js` `objXml`/`readElement`, `model.js` 만들기 함수, 편집 화면 더블클릭(`editor.js onDblClick`).

## 5. pptx 검증 방법
```bash
node --test test/pptx.test.js
# LibreOffice 로 우리 파일 열어 보기 (Impress 필요: apt-get install libreoffice-impress-nogui)
HOME=/tmp/lo soffice -env:UserInstallation=file:///tmp/lo_profile --headless --convert-to pdf --outdir out 파일.pptx
pdftoppm -r 50 -png out/파일.pdf out/page
```
PowerPoint 에서 만든 파일을 읽는 기능을 고칠 때는 LibreOffice PDF(정답에 가까움)와 WIPOINT 화면(편집 화면 `.slide-host` 캡처)을 나란히 비교합니다.

## 6. 성능 · 구조 규칙
- 끄는 동안은 HTML 을 다시 만들지 않고 위치만 바꿈(`moveDom`), 끝날 때 한 번 `emit('change')`.
- 글 입력 중에는 편집 화면을 다시 그리지 않음(scope `text`), 미리 보기는 250ms 늦게.
- 큰 그림은 넣을 때 2560px 로 줄임(`shrinkImage`).
