# 02. 보완 항목 (1.0 기준)

> **이후 구현됨 (1.1)**: PDF 열기 · 포함된 글꼴(EOT/MTX) · Alt 키 팁 · 빠른 실행 도구 모음 · 스포이트 · 비디오/오디오 · 표 세로/범위 병합 · 칸 나누기 · 범위 테두리(대각선 포함) · 열/행 경계 끌기 · 차트 데이터 통합 문서(embeddings xlsx) · 모핑 전환 · 단락별 애니메이션 · 이동 경로 · 메모(댓글, 이전/새 형식 읽기) · 사용자 지정 쇼 · 화면에서 그림 자르기 · 동영상 내보내기(MP4/WebM).
> **이후 구현됨 (1.2)**: SmartArt 텍스트 창 · 그림 배경 제거 · 수식(LaTeX → MathML, pptx 는 OMML a14:m + 대체 글 상자) · 쇼 잉크 주석 유지(자유형 도형) · 트리거 애니메이션(interactiveSeq) · 슬라이드 마스터 보기(마스터 · 레이아웃 개체, 제목/본문 기본 서식) · 눈금자(들여쓰기 · 탭 정지) · 안내선(p15:sldGuideLst) · 개요 보기 편집 · 요약/구역/슬라이드 확대/축소 · 공동 편집(server.js SSE 중계 / BroadcastChannel) · 터치 편집.
> 남은 것: 공동 편집의 클라우드 중계(Cloudflare 정적 배포에는 서버가 없어 같은 브라우저 탭끼리만), 글자 단위 동시 편집(지금은 슬라이드 단위 나중 우선), 마스터 개체 틀 위치를 슬라이드에 반영, PowerPoint 진짜 확대/축소(p:sldZm) 형식 저장, 수식의 PNG 대체 그림.

## P1 — PowerPoint 호환 (사용자가 바로 느끼는 차이)
| 항목 | 현재 | 할 일 |
|------|------|------|
| 실제 PowerPoint 파일 검증 | python-pptx · LibreOffice 파일로만 확인 | 사용자 실제 .pptx 여러 개로 열기 비교 (LibreOffice PDF vs WIPOINT 화면), PowerPoint 에서 우리 파일 열기 확인 (복구 메시지 없음) |
| 글꼴 측정 차이 | 브라우저 글꼴로 줄바꿈 | 자동 맞춤(fontScale)은 파일 값을 그대로 씀. 줄 간격 · 자간 세부 조정 |
| 애니메이션 | 나타내기 10 · 강조 5 · 끝내기 5, 개체 단위 | 단락별 애니메이션(build="p"), 이동 경로, 트리거 |
| 전환 | 12종 (flip 은 pptx 에 fade 로 저장) | 모핑(Morph), p14 전환 저장 |
| 차트 | 리터럴 값으로 저장 (PowerPoint 에서 [데이터 편집] 불가) | 내장 통합 문서(embeddings/*.xlsx) 생성 — WIXEL 의 xlsx 쓰기 재사용 검토 |
| SmartArt | 도형 묶음으로 만들고 읽음 | 텍스트 창 편집, dgm 데이터 모델 저장 |
| 표 | 병합은 가로만 | 세로 병합 · 칸 테두리 개별 편집 · 열 너비 끌기 |
| 그림 | 자르기는 대화상자 | 화면에서 자르기 손잡이, 배경 제거 |
| 미디어 | 없음 | 비디오 · 오디오 삽입/재생 |
| 수식 · 잉크 | 없음 | 수식 편집기(OMML), 잉크 저장 |

## P2 — 기능 보강
- 슬라이드 마스터 보기(마스터 · 레이아웃 편집), 사용자 지정 레이아웃
- 눈금자 · 탭 · 들여쓰기 끌기, 안내선 추가/이동
- 개요 보기 편집 (지금은 읽기 · 이동만)
- 맞춤법 검사 고급 (지금은 브라우저 맞춤법 검사기)
- 슬라이드 쇼 재구성(사용자 지정 쇼), 요약 확대/축소(Zoom)
- 공동 편집 · 메모(댓글) — WIXEL 3 의 Durable Object 보관함 재사용 검토
- 동영상으로 내보내기
- 모바일 · 터치 편집
