# 06. PowerPoint 호환성 점검 (WIPOINT 1.8)

목표: PowerPoint 에서 만든 파일이 WIPOINT 에서 같게 열리고, WIPOINT 에서 저장한 파일이 PowerPoint 에서 같게 보이는 것.

## 점검 방법

| 점검 | 도구 | 결과 |
|------|------|------|
| 우리 pptx 의 스키마 | `tools/compat-deck.mjs` (모든 기능을 담은 88장 덱) → ECMA-376 XSD 로 모든 파트 검사 | 177개 파트, 오류 0 |
| 실제 PowerPoint 파일 읽기 | Apache POI 시험 파일 pptx 95개 · ppt 145개 | pptx 95/95, ppt 129/145 (못 여는 16개: 암호 11 · PowerPoint 95 이하 · 손상 · 퍼징 파일 — 모두 한국어 안내) |
| 화면 비교 | 같은 파일을 WIPOINT 와 LibreOffice 로 그려 흐림 후 차이 평균 (0 = 같음) | pptx 333장 평균 6.7 (1.7: 10.5) · ppt 495장 평균 7.3 (처음 33) |
| 왕복 | 원본 → WIPOINT 로 열어 그대로 저장 → 둘 다 LibreOffice 로 그려 비교 | 333장 중 243장 거의 같음(<2) · 40장 조금 다름 · 50장 다름, 평균 2.4 (처음 2.9) |
| 왕복 파일의 스키마 | 저장한 95개 파일 XSD 검사 | 새로 생긴 오류 0 (남은 것은 원본 파일에 있던 값 — 예: 62개 → 6개) |
| 도형 187종 | 모든 미리 설정 도형 + 조정값을 LibreOffice 와 나란히 | 모양 같음 |

## 1.8 에서 고친 것

- **도형**: ECMA-376 표준 정의(안내선 식 · 여러 경로 · 명암 채우기 · 글 영역)로 187종 전부 — 연결선, 실행 단추, 수식 도형, 설명선, 리본, 기어 등. 노란 조정 핸들, 삽입 갤러리 165종. 그룹 회전 · 대칭을 자식에 반영. 사용자 지정 도형의 안내선 식.
- **글자**: 밑줄 종류 · 색, 이중 취소선, 그라데이션 · 채우기 없음 글자, 네온, 그림자 세부값, 커닝, 필드(슬라이드 번호 · 날짜), 텍스트 단, 글 회전, WordArt 변환(15종 그리기 · 전부 보존).
- **차트**: 손대지 않은 차트는 원래 XML · 스타일 · 색 · 사용자 도형 · 데이터 통합 문서를 그대로 저장. 차트 · 축 글자 크기, 데이터 레이블 서식. PowerPoint 2007 차트의 생략된 레이블 설정을 명시.
- **PowerPoint 97-2003 (.ppt · .pps · .pot)**: 열기(저장은 .pptx). 마스터 · 제목 마스터, 색 구성, 글 스타일(가운데 제목 등 상속), 눈금자 들여쓰기 · 탭, 채우기(그라데이션 초점 · 무늬 · 그림 · 파생 색), 선 · 화살표, 그림(EMF · WMF · PNG · JPEG · DIB · TIFF), 그룹 회전 · 대칭, 개체 틀(마스터 채우기 · 선 상속), 하이퍼링크, 메모, 전환.
- **그림 형식**: EMF · WMF → SVG (수식 편집기 그림의 Symbol 글꼴 글자 포함), TIFF → PNG, OLE 개체의 VML 미리 보기.
- **보존**: 손대지 않은 도형 · 그룹 · 표 · 테마 · 애니메이션 · 전환 · 개체 id, 마스터 색 매핑과 슬라이드 재정의.

## 남은 차이 (알려진 것)

- WordArt 변환 중 25종(부풀리기 · 원통 등 두 경로 변환)은 평범한 글로 보임 (파일에는 그대로 저장).
- 3D 효과(입체 · 3차원 회전 · 재질 · 조명)는 근사 렌더.
- .ppt: 번호 매기기 글머리(PowerPoint 2000+ 확장 레코드), 일부 OLE · 동작 설정, 애니메이션(빌드 정보)은 읽지 않음. 저장은 .pptx 만.
- 화면 비교 기준이 LibreOffice 라서, LibreOffice 자체의 차이(글꼴 대체, 일부 그라데이션)도 점수에 섞여 있음.
- 비교 차이가 큰 왕복 사례 대부분은 글꼴 대체 · 원본 파일 고유 값(예: 비표준 테마)이며, 저장 파일을 PowerPoint 로 직접 열어 보는 확인은 아직 하지 못함.
