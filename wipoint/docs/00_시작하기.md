# 00. 시작하기 — WIPOINT (위포인트)

PowerPoint 한국어판과 같은 화면 · 단축키로 쓰는 **웹 프레젠테이션 프로그램**입니다. WIXEL(엑셀, `../tabula`)과 같은 방식으로 만들었습니다.

| 항목 | 내용 |
|------|------|
| 기술 | 순수 JavaScript ES 모듈, npm 의존성 0개, 빌드 결과 HTML 한 파일 |
| 규모 (1.0) | 소스 25개 · 약 8,800줄, 명령 200여 개, 테스트 26개 |
| 파일 | .pptx 열기 · 저장, WIPOINT JSON, PDF(인쇄), PNG, 읽기 전용 공유 링크 |
| 배포 | Cloudflare Workers 정적 자산 (`cloudflare/`), GitHub Pages · 아무 정적 호스팅 |
| 저장 | 사용자 브라우저(IndexedDB 자동 저장 · 최근 문서) + 내려받은 파일. 서버 저장 없음 |

## 빠른 시작
```bash
cd wipoint
npm start          # http://127.0.0.1:5179
npm test
npm run build      # dist/index.html 을 그냥 열어도 동작
```
