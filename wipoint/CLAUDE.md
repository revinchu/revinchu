# WIPOINT (위포인트) — PowerPoint-style web presentation app

Standalone, dependency-free browser presentation editor with a Korean PowerPoint UI. Sibling of WIXEL (`../tabula`) and built the same way. Rules for all agents: `AGENTS.md`. Handoff docs: `docs/`.

- Run: `npm start` → http://127.0.0.1:5179 ; test: `npm test` ; build: `npm run build` (dist/index.html, single file) / `npm run build:cloud` (dist-cloudflare/, deployed by `cloudflare/wrangler.jsonc` as static Workers assets, no Worker code).
- build.mjs allows only `import {…} from './x.js'` and `export const|let|function|class`; no dynamic import, no `export {}`, no `../` imports, no cycles.
- Units: slide coordinates are px at 96 dpi (16:9 = 1280×720, 4:3 = 960×720); EMU = px × 9525; font sizes are pt (px = pt × 4/3).
- Model (`model.js`, DOM-free): `pres = { size, theme, slides, media: {id: dataURL}, props, footer, show? }`; `slide = { id, layout, bg, hidden, transition, notes, objects, anims, bgObjects?, hideDecor?, section? }`; objects `shape | image | table | chart` with `x,y,w,h,rot,flipH,flipV`, `ph` (placeholder type), `grp` (group id — members must stay contiguous in `objects`), `hidden`, `link`, `alt`.
- Text body: `{ paras: [{ runs: [{t, b,i,u,s,size,color,font,hl,shadow,outline,spc,base,cap,link}], align, lvl, bullet: {type:'char'|'num', char|scheme}, marL, indent, lineSpacing, spcBef, spcAft, end }], anchor, insets, wrap, autofit: none|shrink|resize, fontScale, vert }`. `p.end` = format of the empty paragraph / next typed text. `formatRange(body, a, b, props)` formats a {p,o} range.
- Colors: `'#RRGGBB'` or theme refs `'@accent1:lm75:lo25'` (lm=lumMod, lo=lumOff, t=tint, s=shade, a=alpha). `resolveColor(theme, c)`. tint/shade are applied in linear RGB like PowerPoint (black tint 75% = #898989). Fonts `+mj`/`+mn` = theme major/minor.
- Rendering (`render.js`, DOM-free) produces HTML strings: `slideHtml(pres, slide, { prompt, editId, hide, index, links })`; the same output is used for the editor (scaled with CSS transform), thumbnails, slideshow, audience window, print and PNG export (`SLIDE_CSS` must be injected wherever slide HTML is shown). Editable text uses `data-p` / `data-r` JSON attributes; `textedit.js` converts DOM ⇄ model.
- Theme decorations (`themeDecor`) are generated from theme flags (accentBand, titleBar, dark) unless the slide has `bgObjects` (imported master/layout graphics) or `hideDecor`.
- App structure: `state.js` (S, `change()` with undo history, `register/run` commands, `on/emit` events, `goSlide`) ← `editor.js` (canvas, selection, smart guides, resize/rotate, draw, text edit), `panels.js` (thumbnails, notes, status bar, sorter, format/animation/selection panes), `ribbon.js` (TABS definition), `galleries.js`, `commands.js` (all actions), `show.js` (slideshow, presenter view, audience window, pen/laser, rehearse), `fileio.js` (open/save pptx/json, IndexedDB autosave + recent docs, print, PNG, `#view=` share links), `backstage.js`, `app.js` (boot, keyboard, clipboard, drag & drop). Modules never import app.js; cross-module calls go through `run()` / `emit()`.
- pptx (`pptx.js`): writer emits a master with 9 standard layouts (plus one layout per distinct imported `bgObjects` set), explicit run/para formatting, tables (`a:tbl` with explicit fills + WIPOINT ext holding style), charts (`c:chartSpace` with literal values + ext JSON), notes (notesMaster), transitions, `p:timing` for entrance/emphasis/exit effects, sections (p14), and WIPOINT `extLst` JSON on slides/presentation (`WP_EXT_URI`) so own files round-trip exactly. Reader resolves placeholder geometry and text styles through layout → master → txStyles, theme style refs (fillRef/lnRef/fontRef with fmtScheme), clrMap, groups (flattened with `grp`), SmartArt drawing parts, AlternateContent (Fallback first), custGeom, transitions and timing.
- Test fixtures: `test/fixtures/python-pptx.pptx` (PowerPoint default template via `make-python-pptx.py`) and `libreoffice.pptx` (LibreOffice re-save). Visual check: convert to PDF with LibreOffice Impress (`soffice --headless --convert-to pdf`) and compare with WIPOINT screenshots.
- The icon library is shared with WIXEL (`../tabula/assets/iconlib.json.gz`); `build.mjs` and `server.js` read it from there.
- PDF import (`pdf.js`, DOM-free): objects are found by scanning `n g obj` + object streams (no xref needed); filters Flate/LZW/ASCIIHex/ASCII85/RunLength + PNG predictors; content streams are interpreted (paths → rect/line/custom-path shapes, fill+stroke pairs joined, first full-page rect = slide background; text via ToUnicode / WinAnsi+Differences / Type0 W widths, grouped into lines then text boxes with `wrap:false` and `lineSpacingPt`; images: JPEG kept, others → RGBA → `opts.encodeImage` (canvas in fileio) and JPEG+SMask returned as `jobs` composited in the browser). Encrypted PDFs are refused.
- Embedded fonts (`fonts.js`, DOM-free): `ppt/fonts/*.fntdata` are EOT (optional XOR 0x50, optional MTX = LZCOMP adaptive Huffman ×3 blocks + CTF glyph records → glyf/loca rebuilt, cvt delta-decoded, hdmx/VDMX dropped). `pres.fonts = [{typeface, style, data: original fntdata dataURL}]` is written back unchanged; `fileio.applyEmbeddedFonts` registers them as `FontFace`. `snapshot()` excludes `fonts` (like media); autosave stores them separately.
- Keyboard: `keytips.js` (Alt / F10 badges from `data-kt`; ribbon items get `it.kt` from the `KT` table in ribbon.js, prefix-free, auto-assigned when missing; `ktAction` per item; menus get A–Z badges and arrow/Enter navigation). Quick Access Toolbar (`qatConfig` in localStorage `wipoint:qat`, default below the ribbon, Alt+1…9). Eyedropper (`eyedrop.js`) samples rendered slide pixels/colors (works without the EyeDropper API). Function keys are handled in `app.js` `fnKey` (also while editing text).
