# WIPOINT (위포인트) — PowerPoint-style web presentation app

Standalone, dependency-free browser presentation editor with a Korean PowerPoint UI. Sibling of WIXEL (`../tabula`) and built the same way. Rules for all agents: `AGENTS.md`. Handoff docs: `docs/`.

- Run: `npm start` → http://127.0.0.1:5179 ; test: `npm test` ; build: `npm run build` (dist/index.html, single file) / `npm run build:cloud` (dist-cloudflare/, deployed by `cloudflare/wrangler.jsonc` as static Workers assets, no Worker code).
- build.mjs allows only `import {…} from './x.js'` and `export const|let|function|class`; no dynamic import, no `export {}`, no `../` imports, no cycles.
- Units: slide coordinates are px at 96 dpi (16:9 = 1280×720, 4:3 = 960×720); EMU = px × 9525; font sizes are pt (px = pt × 4/3).
- Model (`model.js`, DOM-free): `pres = { size, theme, slides, media: {id: dataURL}, props, footer, show? }`; `slide = { id, layout, bg, hidden, transition, notes, objects, anims, bgObjects?, hideDecor?, section? }`; objects `shape | image | table | chart` with `x,y,w,h,rot,flipH,flipV`, `ph` (placeholder type), `grp` (group id — members must stay contiguous in `objects`), `hidden`, `link`, `alt`.
- Text body: `{ paras: [{ runs: [{t, b,i,u,s,size,color,font,hl,shadow,outline,spc,base,cap,link}], align, lvl, bullet: {type:'char'|'num', char|scheme}, marL, indent, lineSpacing, spcBef, spcAft, end }], anchor, insets, wrap, autofit: none|shrink|resize, fontScale, vert }`. `p.end` = format of the empty paragraph / next typed text. `formatRange(body, a, b, props)` formats a {p,o} range.
- Colors: `'#RRGGBB'` or theme refs `'@accent1:lm75:lo25'` (lm=lumMod, lo=lumOff, t=tint, s=shade, a=alpha). `resolveColor(theme, c)`. tint/shade are applied in linear RGB like PowerPoint (black tint 75% = #898989). Fonts `+mj`/`+mn` = theme major/minor.
- Rendering (`render.js`, DOM-free) produces HTML strings: `slideHtml(pres, slide, { prompt, editId, hide, index, links })`; the same output is used for the editor (scaled with CSS transform), thumbnails, slideshow, audience window, print and PNG export (`SLIDE_CSS` must be injected wherever slide HTML is shown). Editable text uses `data-p` / `data-r` JSON attributes; `textedit.js` converts DOM ⇄ model.
- Theme decorations (`themeDecor`) are generated from theme flags (accentBand, titleBar, dark) unless the slide has `bgObjects` (imported master/layout graphics) or `hideDecor`.
- App structure: `state.js` (S, `change()` with undo history, `register/run` commands, `on/emit` events, `goSlide`) ← `editor.js` (canvas, selection, smart guides, resize/rotate, draw, text edit), `panels.js` (thumbnails, notes, status bar, sorter, format/animation/selection panes), `ribbon.js` (TABS definition), `galleries.js`, `commands.js` (all actions), `show.js` (slideshow, presenter view, audience window, pen/laser, rehearse), `fileio.js` (open/save pptx/json, IndexedDB autosave + recent docs, print, PNG, `#view=` share links), `backstage.js`, `app.js` (boot, keyboard, clipboard, drag & drop). Modules never import app.js; cross-module calls go through `run()` / `emit()`.
- pptx (`pptx.js`): writer emits a master with 9 standard layouts (plus one layout per distinct imported `bgObjects` set), explicit run/para formatting, tables (`a:tbl` with explicit fills + WIPOINT ext holding style), charts (`c:chartSpace` with literal values + ext JSON), notes (notesMaster), transitions, `p:timing` for entrance/emphasis/exit effects, sections (p14), and WIPOINT `extLst` JSON on slides/presentation (`WP_EXT_URI`) so own files round-trip exactly. Reader resolves placeholder geometry and text styles through layout → master → txStyles, theme style refs (fillRef/lnRef/fontRef with fmtScheme), clrMap, groups (flattened with `grp`), SmartArt drawing parts, AlternateContent (Fallback first), custGeom, transitions and timing.
- Test fixtures: `test/fixtures/python-pptx.pptx` (PowerPoint default template via `make-python-pptx.py`) and `libreoffice.pptx` (LibreOffice re-save). Visual check: convert to PDF with LibreOffice Impress (`soffice --headless --convert-to pdf`) and compare with WIPOINT screenshots.
- The icon library is shared with WIXEL (`../tabula/assets/iconlib.json.gz`); `build.mjs` and `server.js` read it from there.
- PDF import (`pdf.js`, DOM-free): objects are found by scanning `n g obj` + object streams (no xref needed); filters Flate/LZW/ASCIIHex/ASCII85/RunLength + PNG predictors; content streams are interpreted (paths → rect/line/custom-path shapes, fill+stroke pairs joined, first full-page rect = slide background; text via ToUnicode / WinAnsi+Differences / Type0 W widths, grouped into lines then text boxes with `wrap:false` and `lineSpacingPt`; images: JPEG kept, others → RGBA → `opts.encodeImage` (canvas in fileio) and JPEG+SMask returned as `jobs` composited in the browser). Encrypted PDFs are refused.
- Embedded fonts (`fonts.js`, DOM-free): `ppt/fonts/*.fntdata` are EOT (optional XOR 0x50, optional MTX = LZCOMP adaptive Huffman ×3 blocks + CTF glyph records → glyf/loca rebuilt, cvt delta-decoded, hdmx/VDMX dropped). `pres.fonts = [{typeface, style, data: original fntdata dataURL}]` is written back unchanged; `fileio.applyEmbeddedFonts` registers them as `FontFace`. `snapshot()` excludes `fonts` (like media); autosave stores them separately.
- Keyboard: `keytips.js` (Alt / F10 badges from `data-kt`; ribbon items get `it.kt` from the `KT` table in ribbon.js, prefix-free, auto-assigned when missing; `ktAction` per item; menus get A–Z badges and arrow/Enter navigation). Quick Access Toolbar (`qatConfig` in localStorage `wipoint:qat`, default below the ribbon, Alt+1…9). Eyedropper (`eyedrop.js`) samples rendered slide pixels/colors (works without the EyeDropper API). Function keys are handled in `app.js` `fnKey` (also while editing text).
- Media: objects `{type:'media', kind:'video'|'audio', media, poster?, trim?:{st,end}, autoplay?, loop?}`; render shows the poster in the editor and a real `<video>/<audio>` only with `opts.live` (slideshow). pptx: `p:pic` + `a:videoFile|audioFile r:link` + `p14:media r:embed` (two rels to one `ppt/media/mediaN.ext`), poster as the blip.
- Tables: `S.cellRange = {id, ar, ac, r1, c1, r2, c2}` (drag across cells / Shift+click; clicking a cell of a selected table edits it, the table moves by its border). Merge = top-left `span`/`rowSpan`, others `hMerge`/`vMerge`; `splitCell` inserts columns/rows and extends other rows' spans. Cell `borders` keys l/r/t/b plus `dd`/`du` diagonals (`lnTlToBr`/`lnBlToTr`). Column/row grips in the overlay.
- Charts are written with `c:numRef/strRef` caches pointing at `Sheet1` of `ppt/embeddings/Microsoft_Excel_WorksheetN.xlsx` (`chartWorkbook`, minimal xlsx with inline strings) + `c:externalData`.
- Animations: `a.byPara` (expanded by `animSteps` into per-paragraph entries with `para`; pptx `txEl/pRg` + `bldP build="p"`), `cls:'path'` with `a.motion` (slide-fraction path like PowerPoint, `motionPoints`; pptx `p:animMotion`). Transition `morph` (`morphPairs` matches by name → content → placeholder → type; pptx `mc:AlternateContent` p159:morph with fade fallback).
- Comments: `slide.comments = [{id, author, text, at, x, y, replies, done}]` (pins in the editor overlay, 메모 pane). pptx writes legacy `p:cmLst` + `commentAuthors.xml` (pos units = px × 6); reader also reads modern threaded comments (`authors.xml`, p188). Custom shows `pres.customShows = [{name, slides:[slideId]}]` ↔ `p:custShowLst`; `startShow({custom})`.
- Crop on canvas: `S.cropping` (double-click a picture or [자르기]); `cropOverlay` draws the full image ghost + crop handles. Video export: `exportVideo` renders slides with `slidePng` to a canvas and records it with MediaRecorder in real time.
- The toast uses class `on` (not `show` — `.show` is the slideshow root).
- 1.2 — SmartArt: the first member carries `smartItems`/`smartMulti`; `smartTextPane` rebuilds the group live (`rebuildSmart`). Ink from the slideshow pen is kept per slide (`show.strokes`) and offered as freeform shapes (`ink: true`) when the show ends.
- Triggers: `anim.trigger = objId` removes it from the main sequence (`animSteps(slide, trigger)`, `triggerSteps`); the show plays it when that object is clicked (`show.trigDone`). pptx: `p:seq nodeType="interactiveSeq"` with an `onClick` spTgt condition.
- Background removal: `bgremove.js` (DOM-free flood fill from the edges + remove/keep marks) → new PNG media; `o.bgOrig` keeps the original ([그림 원래대로]).
- Zoom objects `{type:'zoom', zoom:{slide, section?, ret}}` render a live thumbnail (`zoomHtml`, `opts.pres`); in the show a click zooms into the slide/section and returns (`show.zoomBack`). pptx: a rectangle with an internal slide link (`ctx.hlink('#slideN')` → slide relationship + `ppaction://hlinksldjump`) + `zooms` in the slide ext JSON. Internal links `#slideN` are read back from slide relationships.
- Outline view (`S.view = 'outline'`) edits slides in the left pane: `outlineRows(pres)` / `applyOutline(pres, rows)` (model.js) keep untouched paragraphs (with formatting) and write row identities (slide/obj/pi) back.
- Ruler (`S.showRuler`): cm ticks, centre = 0; while editing text the first-line/hanging/left markers set `marL`/`indent`, clicking adds tab stops `p.tabs = [{pos, algn}]` (pptx `a:tabLst`, rendered as `tab-size`). Guides `pres.guides = [{dir:'v'|'h', pos}]` (default: centre lines) are dragged on empty slide area, dragged off to delete, Ctrl+drag copies, used for snapping; pptx `p15:sldGuideLst` (pos = px × 6).
- Touch (`initTouch` in editor.js): two-finger pinch zoom, long press → context menu, double tap → double click; larger handles under `(pointer: coarse)`.
- Slide master view (`S.masterKey`): `curSlide()` returns `masterSlide(pres, key)` (`pres.masters[key]` = slide-like `{objects, master: key, hideMaster?}`). Non-placeholder objects are drawn on slides through `slideDecor` (render.js; also used by the pptx layout writer); the master's title/body placeholder first-run font/colour/size become defaults via `setMasterText` (called by `slideHtml` and `pptxEntries`). Saved in the presentation ext JSON with `masterMedia` paths.
- Equations (`math.js`, DOM-free): `{type:'equation', latex, size, color}`; `parseLatex` → AST → `toMathML` (screen) / `toOMML` (pptx `mc:AlternateContent` Choice a14 with `a14:m`, Fallback = LaTeX text box); `ommlToLatex` reads PowerPoint equations back. Dialog: Alt+= / 삽입 › 수식.
- Co-editing: `collabcore.js` (DOM-free `baseline`/`diffPres`/`applyPatch`/`fullState`/`applyFull`, slide-level last-writer-wins) + `collab.js` (transport: server.js `/api/collab/<room>` SSE relay, or BroadcastChannel without a server; presence = name, slide, selection). Join with `?collab=<room>`; remote patches for the slide being text-edited wait in `collab.queue`.
- 1.3 — Mobile (`mobile.js`): `body.mobile` when ≤760px or forced (localStorage `wipoint:mobile`); `dragScroll(box, axis)` makes ribbon/tabs/menus/lists draggable. Hand tool (`S.handTool`, Space/middle drag). Context menus in `ctxmenu.js` (PowerPoint items with `(X)` accelerators + mini toolbar). Point editing (`S.pointEdit`, shapes → `o.path`).
- 1.3 — SVG: `svgimport.js` (`svgToObjects` → editable shapes) and `svgexport.js` (`slideSvg`, native SVG without foreignObject). Fonts: `webfonts.js` (45 public Korean web fonts, `webFont`, `fontsUsed`), `fontlib.js` (local fonts via Local Font Access, `ensureFont` loads stylesheets on demand).
- 1.3 — Large files: `openZipFile(file, {lazy})` (zip.js) reads the central directory from file slices (ZIP64 too); big `ppt/media/*` stay `Blob`s (`File.slice`, zero copy) and become `blob:` URLs registered in `blobstore.js` (`BLOBS`, `blobUrl`, `inlineBlobs` for SVG/PNG rendering, `mediaAsData` for json/share/collab). `pptxEntries(pres, { blob })` puts Blobs into the part list and `zipAsync` streams them (CRC in 16MB slices, returns a Blob). IndexedDB stores each media Blob once under `bl:` keys (`storeMedia`/`loadStoredMedia`, GC in `gcBlobs`). Thumbnails/sorter are virtualized above 40 slides (`lazyThumb`).
- 1.3 — Charts (`chart.js`): model fields `grouping`, `variant`, `axes.{x,y,y2}`, `grid`, `dataTable`, `palette`, `style`, `layout`, series `type`/`axis`/`trend`/`err`/`pointColors`/`sizes`; kinds col/bar/line/area/pie/doughnut/scatter/radar/bubble/combo. `chartXml` writes combo groups, secondary axes (ids 333…/444…), trendlines, error bars, dTable, only schema-valid `dLblPos`; `readChart` reads foreign charts back. UI in `chartui.js` (type dialog with previews, grid data editor, element menus, galleries, `chartPane`). Double-clicking a chart element (`data-el` in the SVG) opens its pane.
- 1.4 — Effects (`effects.js`, DOM-free): `o.fx = { shadow{inner,dist,dir,blur,color,alpha,persp}, glow, soft, reflect, bevel, rot3d }` (pt/degrees; legacy `o.shadow` = default outer shadow via `fxOf`). `fxStyle` → CSS filter (drop-shadows) + an SVG `<filter>` chain (soft edge, inner shadow, bevel lighting) + wrapper CSS (`-webkit-box-reflect`, 3D transforms). pptx: `fxXml`/`fxFromXml` (effectLst, scene3d, sp3d). Menus/pane: `fxui.js`.
- 1.4 — `COLOR_SCHEMES` (themes.js, 32 sets) for 디자인 › 색 (hover preview, custom colors in localStorage `wipoint:colorSchemes`); `replaceFonts(pres, from|'*', to)` (model.js). Slide show setup `pres.show = { type: speaker|browse|kiosk, loop, noAnim, penColor, laserColor, slides: all|range|custom, from, to, custom, useTimings, monitor: auto|primary|off|index, usePresenter }`; with several monitors (`screen.isExtended` + `getScreenDetails`) the show goes presenter view here + audience window on the other screen. Eyedropper: drag outside the window → system `EyeDropper`. Stock images: `stock.js` (Openverse / Wikimedia Commons parsing, `creditText`).
- 1.5 — Merge Shapes (`boolean.js`, DOM-free: `mergeLoops(shapes, op)` union/combine/fragment/intersect/subtract by edge classification, `loopsToShape` → custGeom at 0.01 precision). SmartArt (`smartart.js`): 47 `SMART_KINDS` in 8 categories, nested items (Tab/2 spaces/'-' = level), `SMART_COLORS`/`SMART_STYLES`; picture slots are shapes with `picSlot` (gray box, click inserts a picture), not `ph:'pic'`. Straight lines get an SVG box of at least 1px.
- 1.5 — Office 2016 charts (`chart.js`): waterfall/funnel/histogram(+pareto)/box/treemap/sunburst via `expandChart`; pptx writes `fallbackChart` (compatible stacked/bar charts with ghost series) and keeps the exact chart in the ext JSON.
- 1.5 — Transitions: `TRANSITIONS` entries are `[key, label, group]` (`TRANSITION_GROUPS` subtle/exciting/dynamic, 51 effects). `show.js` `playTransition(old, neu, tr, {host, raise, prev, cur})` is shared by the slideshow and the editor preview; clip-path shapes come from DOM-free `transfx.js` (multi-rect polygons joined through a hub point so frames keep the same point count); split/curtains/doors/fracture/shred use clones of the old slide (`.show-slide-ghost`, removed afterwards). pptx: base `p:` elements (blinds/checker/comb/randomBar/strips/diamond/plus/wheel), p14 (vortex/switch/flip/ripple/honeycomb/prism = cube/box/rotate/orbit, doors/window/ferris/gallery/conveyor/pan/glitter/flythrough/flash/shred/reveal) and p15 `prstTrans` in `mc:AlternateContent` with a fade fallback; durations other than 0.5/0.75/1 s are written as `p14:dur`.
- 1.5 — Animations: 38 entrance / 20 emphasis / 38 exit / 22 motion paths (`ANIM_EFFECTS`, `MOTION_PATHS`). Exit plays the entrance keyframes reversed (`reverseKf` mirrors offsets); `EMPH_HOLD` emphasis effects (transparency, darken, desaturate, colors, bold…) keep their end state. pptx presetIDs follow PowerPoint (`ENTR_PRESET`/`EMPH_PRESET`, exit = entrance ids), behaviors use animEffect filters (blinds, box, checkerboard, circle, diamond, plus, randombar, strips, wedge, slide), anim/animClr/set; motion paths read back to their `MOTION_PATHS` key.
- 1.6 — Artistic effects (`arteffects.js`, DOM-free: `ART_EFFECTS` 22 [key, label, a14 element, default amount], `applyArtEffect(rgba, w, h, key, {amount})`): the effect result is the picture's `media`, the original stays in `o.artOrig`, `o.art = {effect, amount}`; pptx writes them in a WIPOINT blip ext (`wp:art` + `r:embed` of the original) and reads PowerPoint's `a14:imgEffect` names. Compress Pictures: `compressPlan` (ppi, delete cropped areas) + canvas re-encode (JPEG when opaque). `usedMedia` walks every `media/poster/bgOrig/artOrig` key (posters, picture fills and master pictures used to be pruned on save).
- 1.6 — Recording (`show.js` `startShow({record: {mic, camera}})`): one MediaRecorder per slide (`recSegment`/`recCloseSegment`), audio/mp4 when supported else WebM → WAV (`recording.js` `encodeWav`/`resample`), saved as `narration: true, autoplay, hideInShow` media objects + `transition.advAfter` + `slide.inkRec` strokes with per-point times (`inkUntil` replays them). Setup `pres.show.noNarration`; slide ext meta `props` (autoplay/loop/narration/hideInShow) and `inkRec`. Video export mixes narration audio and timed ink. Live captions: Web Speech API (`captionSettings()` in localStorage `wipoint:captions` {on, lang, pos, size}, J key, audience window `#cap`).
- 1.6 — Custom layouts: `pres.customLayouts = [{key: 'cust:…', name, bgObjects?}]`, objects in `pres.masters[key]`; `layoutList`/`layoutName`/`addCustomLayout`/`removeCustomLayout`; `slidePlaceholders(pres, layout)` clones a custom layout's placeholders (text emptied, first-run format kept in `p.end`) and is used by `newSlide`/`changeLayout`/`resetSlideLayout`. Placeholder kinds `PH_INSERT` (chart/tbl/dgm/media are body placeholders with `phFor`, written as `<p:ph type="chart|tbl|dgm|media">`; clicking an empty one inserts that object). Master tab: 레이아웃 삽입/삭제, 개체 틀 삽입, 제목/바닥글 (`noFooter`). pptx: custom layouts are written as `type="cust"` layouts; foreign `cust`/untyped layouts become custom layouts on read (`foreignLayout`, placeholders + background graphics).
