API 설정 방법
  1. 네이버 검색광고 계정 생성
    https://searchad.naver.com 에서 계정을 만드세요.
  2. API 키 발급
    로그인 후 우측 상단 계정 관리 → API 관리 에서 API 액세스 키와 시크릿 키를 발급받으세요.
  3. 고객 ID 확인
    로그인 후 URL이나 계정 정보에서 고객 ID(숫자)를 확인하세요.
  4. 환경변수 설정
    .env 파일을 만들거나 터미널에서 설정하세요: 
    NAVER_API_KEY=발급받은_액세스키
NAVER_SECRET_KEY=발급받은_시크릿키
NAVER_CUSTOMER_ID=고객ID숫자
  5. 서버 재시작
    환경변수 설정 후 python dashboard.py를 다시 실행하세요.
