# WIWORD (위워드) — Word-style web document editor

Standalone, dependency-free browser word processor with a Korean Microsoft Word UI. Sibling of WIXEL (`../tabula`) and WIPOINT (`../wipoint`), built the same way. Rules for all agents: `AGENTS.md`. Handoff docs: `docs/`. Credits: `NOTICE.md`.

- Run: `npm start` → http://127.0.0.1:5180 ; test: `npm test` (set `WIWORD_CORPUS=<folder>` to also open a folder of real .docx/.hwp/.hwpx/.doc/.pdf files) ; build: `npm run build` (dist/index.html, single file + `dist/assets/iconlib.json.gz` copied from `../tabula/assets`) / `npm run build:cloud`.
- build.mjs allows only `import {…} from './x.js'` and `export const|let|function|class|async function`; no `export { }` lists, no bare `import './x.js'` (write `import { } from './x.js'`), no dynamic import, no `../` imports, no cycles.
- Units: px at 96 dpi. twip = px × 15, EMU = px × 9525, HWPUNIT = px × 75 (HWP 5 paragraph margins are stored × 2), HWP charPr height = pt × 100. Font sizes in runs are pt.
- Model (`model.js`, DOM-free): `doc = { version, props, styles, defaults{rPr,pPr}, themeFonts, lists, section, body, notes{foot,end}, comments, media{id: dataURL}, settings{track, defaultTab, evenOdd, pageColor, watermark, hyphenate, protect} }`. Blocks: paragraph `{type:'p', id, style, pPr, runs, mark?, secBreak?{kind, sec}}` (`secBreak` ends a section; `kind` is that section's start type, docx semantics) and table `{type:'tbl', id, style, tblPr{look, align, ind, borders, cellMar, shd}, grid:[px], rows:[{h, hRule, header, cantSplit, cells:[{span, vMerge:'restart'|'cont', shd, borders, vAlign, mar, dir, blocks}]}]}`. Runs are text `{text, ...rPr}` or objects `{obj:'tab'|'br'|'img'|'shape'|'field'|'note'|'mark'|'sym'|'eq'}` (img/shape may carry `float{wrap, relH, relV, x, y, alignH, alignV, side, dist}`; shape has its own `blocks`; eq keeps `latex`). Positions are `{p:[path], o}`; `walkParas` visits table cells too. Theme fonts `+mj`/`+mn` → `fontName(doc, f, ea)`.
- Line spacing: `pPr.spc = {before, after, line, rule:'auto'|'pct'|'exact'|'atLeast'}`; `rule:'pct'` is HWP percent (line 1.6 = 160%).
- Layout (`layout.js`, browser): `render.js` (DOM-free) turns blocks into HTML (`blockHtml`, `tableHtml`, `DOC_CSS`); `Layout` measures them in hidden per-section column boxes and paginates (pages/columns, headers/footers, footnotes, keep-with-next, paragraphs split at line boundaries and drawn clipped on both pages, table rows split with repeated header rows, floating objects via `floatObjects`: behind/front/none drawn absolutely). Measured block elements are cached per block object, so typing re-measures only changed blocks. `pageNode` builds a page; the editor, page thumbnails, print and backstage previews use it.
- App structure: `state.js` (S, `change()` with undo history, `register/run` commands + `COMMAND_INFO`, `on/emit`) ← `editor.js` (caret, selection, IME, typing, clipboard with styles/lists/media), `view.js` (relayout, page DOM, mail-merge preview), `ribbon.js` + `menus.js` (TABS, galleries), `commands.js` + `dialogs.js` + `features.js` + `extras.js` (actions), `panels.js` (status bar, rulers with indents/tab stops, nav pane, side panes: styles, comments, revisions, markdown, spelling, accessibility, AI 연결, help), `backstage.js` (파일 tab), `fileio.js` (open/save/print/autosave/recent/drag-drop), `bridge.js` (live MCP link), `app.js` (boot, shortcuts, context menu, mini toolbar). Modules never import app.js.
- Formats (`formats.js`, DOM-free): `detectKind(bytes, name)` → pdf/docx/hwpx/odt/hwp/doc/rtf/wiword/md/html/csv/txt; `readBytes(bytes, name, opts)` → `{doc, warnings, kind, jobs?}`; `docBytes(doc, kind)` writes docx/dotx/hwpx/md/html/txt/wiword. `decodeText` handles UTF-16/UTF-8/EUC-KR.
  - DOCX (`docx.js`): full reader/writer (styles by name, numbering, sections + header/footer inheritance, fields, bookmarks, comments + replies, footnotes/endnotes, track changes, drawings/anchors/text boxes, VML, OMML ↔ LaTeX, tables with gridSpan/vMerge). Our own files carry `word/wiword.json` (custom rel `http://wiword.app/relationships/source`), used only while the document text hash still matches (edited in Word → normal read).
  - HWPX (`hwpx.js`): OWPML reader/writer (refList pools, sections, header/footer/footnote ctrls, tables with cellAddr/cellSpan, pictures, text boxes, equations `hwpEqToLatex`/`latexToHwpEq`). `mimetype` must be the first zip entry.
  - HWP 5.0 (`hwp.js`): CFB + raw-deflate records → DocInfo (faces, charShape, paraShape, borderFill, numbering, bullet, styles) + BodyText; table captions are separate LIST_HEADERs before the TABLE record; picture captions are the LIST_HEADER directly under the gso; grouped drawings (SC_CONTAINER) keep every text box's text. `gridTable(cells, rows, cols, grid, tblPr)` (addressed cells → table block) is shared with HWP 3. DRM files are refused. Saving is HWPX/DOCX.
  - HWP 3.0 / 한글 97 (`hwp3.js`): single stream (30-byte signature + DocInfo 128 + summary 1008 + info block + raw-deflate body: fonts × 7 languages, styles, paragraph lists, then additional-info blocks where #1 = embedded pictures by name). Text is 2-byte hchar: Johab Hangul (bit-split), Johab symbols/hanja → KS X 1001 → `TextDecoder('euc-kr')`, Hancom private area via `extra()`. Units hunit = 1/1800 in (px = × 4/75), char size ÷ 25 = pt. Inline char shapes are changes from position i on (carry forward). Tables come from cell geometry (left/top edges = grid lines). Paper direction 1 = landscape (sizes stored portrait). Password docs: DES-ECB with `desKey`, body inflated, first 256 bytes skipped.
  - Encrypted Hangul docs: readers throw `e.code = 'PASSWORD'` (`e.wrong` on a wrong password); `readBytes(bytes, name, { password })` retries. HWP 5 password = EncryptVersion 4 (SHA-1 key, AES-128 CFB-1 per stream), distribution docs (배포용) = `ViewText/SectionN` (LCG-XOR 256-byte header → AES-128 ECB key), HWPX = ODF manifest encryption (SHA-256 start key, PBKDF2 SHA-1/256, AES-256-CBC, deflate, 1 KB SHA-256 check). Crypto is hand-written in `crypto.js` (SHA-1/256, HMAC, PBKDF2, AES, DES). The app asks with `askPassword` (fileio.js); MCP `open_document`/`convert` take `password`.
  - Word 97 `.doc` (`doc97.js`): FIB + piece table over all stories (main, footnotes, headers, comments, endnotes, text boxes; story CP starts from the FibRgLw ccp* counts), CHPX/PAPX FKPs, `build(cp0, cp1, story)` turns any CP range into blocks. Sections from PlcfSed/SEPX (page, margins, columns, titlePg, break kind → `secBreak`), headers/footers from PlcfHdd (6 separator stories, then 6 per section: even/odd header, even/odd footer, first header/footer; empty ones inherit the previous section), footnotes/endnotes from Plcffnd/Plcfend Ref+Txt, lists from PlfLst/PlfLfo (nfc → fmt, level text placeholders 0–8 → `%1`…), table column widths from sprmTDefTable. Inline pictures: char 0x01 + sprmCPicLocation → PICF in the Data stream → OfficeArt BLIP (`findBlip`; EMF/WMF are inflated and WMF gets a placeable header). Floating pictures/text boxes: char 0x08 + PlcSpaMom FSPA → spid → OfficeArt shape (`readArt`: BStore blips, pib, lTxid → PlcftxbxTxt). Word 6/95 (nFib < 0xC1) is refused. Password docs: RC4 (MD5) and RC4 CryptoAPI (SHA-1), 512-byte blocks re-keyed, first 68 bytes of WordDocument and lKey bytes of the table stream stay plain.
  - Encrypted .docx (`officecrypt.js`): CFB with EncryptionInfo + EncryptedPackage; Agile (XML, spinCount hashing, AES-CBC per 4096-byte segment, IV = hash(keyData salt + segment)) and Standard (SHA-1 × 50000, AES-ECB). Detected as kind `ooxmlEnc`, decrypted, then read again as a ZIP.
  - PDF (`pdfdoc.js` on WIPOINT's `pdf.js`): `mode:'flow'` (default, lines → paragraphs, headings by size) or `'layout'` (absolute text boxes/images per page). Flow mode finds tables from ruling lines (`rulings`: thin rects/lines/path segments, merged per row; `findTables`: H/V segments joined by intersection, grid = distinct edges, missing interior rules = merged cells, fills → cell shading) and splits table text by x using the per-piece positions `pdf.js` puts on text paragraphs (`pieces`, `cy`). `readingOrder` finds a column gutter (no narrow block crosses it, ≥ 20% of text on each side) and reads left column then right between full-width blocks. `listStart` treats 가. 나. as list items only after a sentence end.
  - PDF export (`pdfexport.js` → `pdfwrite.js`, browser): every page is built with `pageNode` offscreen and walked: text per character (Range rects, drawn per glyph with TJ), backgrounds, borders, images (JPEG passthrough, others canvas RGB + alpha mask; SVG/math rasterized), links and headings → outline. Fonts: TrueType (glyf) subsets embedded as CIDFontType2 Identity-H + ToUnicode (`ttfsubset.js`: glyph ids kept, unused glyphs emptied) from imported fonts or Local Font Access (`fontFileFor` in fontlib.js; `askLocalFontsOnce`), deduped by psName + size; otherwise the predefined `HYGoThic-Medium`/`HYSMyeongJo-Medium` (UniKS-UCS2-H). Latin text without a font file picks the fallback whose widths best match the measured positions (`chooseLatin`). CFF/OTF fonts are not embedded. Commands `exportPdf` (file) / `printPdf` (browser print); MCP `save_document` .pdf renders through the app (`render_pdf` bridge call), so it needs the app open.
  - Markdown (`md.js`): GFM (tables, task lists, footnotes, alerts, math `$$`/```math → eq) ↔ doc; `docToMd(mdToDoc(md)) === md` for canonical output. RTF (`rtf.js`), HTML (`htmlio.js`), CSV (`csv.js`).
- AI / MCP: `ops.js` (DOM-free) has pure tools `runTool(doc, name, args) → {doc?, result}` (`TOOLS`, `toolSchema`). `mcp.js` is a stdio MCP server (newline-delimited JSON-RPC: initialize, tools/list, tools/call, ping) with file tools (open_document, new_document, list_documents, switch_document, save_document, convert) + all ops tools with `target: 'file'|'app'`, + app-only execute/list_commands/get_selection. The live app is reached through server.js: `GET /api/bridge/events?c=` (SSE to the app), `POST /api/bridge/call` (MCP side, waits ≤ 60 s), `POST /api/bridge/reply`, `GET /api/bridge/status`. `WIWORD_URL` (default http://127.0.0.1:5180). Register: `claude mcp add wiword -- node <repo>/wiword/mcp.js`.
- Storage: IndexedDB `wiword` (autosave + 20 recent documents); options in localStorage `wiword:opts`.
- Shared code copied from WIPOINT/WIXEL (keep in sync by hand): zip.js, xml.js, cfb.js, pdf.js (uses a local `newPresentation`), emf.js, wmf.js, tiff.js, fonts.js, fontlib.js, webfonts.js, fontarchive.js, symfont.js, math.js, icons.js, keytips.js, ui.js. The icon library is `../tabula/assets/iconlib.json.gz`.
