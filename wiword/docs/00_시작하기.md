# WIWORD (위워드) 시작하기

Word 처럼 쓰는 브라우저 문서 편집기입니다. 설치할 것 없이 HTML 한 파일로 돌아가고, 한글(HWP · HWPX) · Word(DOCX · DOC) · PDF · 마크다운 문서를 열고 고쳐서 저장합니다.

## 실행
```bash
cd wiword
npm start          # http://127.0.0.1:5180
```
`npm run build` 하면 `dist/index.html` 한 파일이 만들어집니다 (아이콘 모음은 `dist/assets/iconlib.json.gz`).

## 화면
- **리본**: 파일 · 홈 · 삽입 · 디자인 · 레이아웃 · 참조 · 편지 · 검토 · 보기 · 도움말 (+ 표 · 그림 상황별 탭). Alt 를 누르면 키 팁.
- **탐색 창**(Ctrl+F): 제목 끌어서 옮기기 · 쪽 미리 보기 · 검색 결과.
- **오른쪽 창**: 스타일 · 메모 · 변경 내용 · 마크다운(양방향) · 맞춤법 · 접근성 · AI 연결(MCP) · 도움말.
- **눈금자**: 들여쓰기 표식 끌기, 클릭하여 탭 추가, 끌어내어 삭제.
- **상태 표시줄**: 쪽 · 단어 수 · 언어 · 변경 내용 추적 · 보기 단추 · 확대/축소.

## AI 연결 (MCP)
Claude 같은 AI 가 문서를 읽고 고칠 수 있습니다.

1. Claude Code 에 등록
   ```bash
   claude mcp add wiword -- node /경로/revinchu/wiword/mcp.js
   ```
   Claude Desktop 은 `claude_desktop_config.json` 의 `mcpServers` 에 `{"command": "node", "args": ["/경로/wiword/mcp.js"]}` 를 넣습니다.
2. 파일만 다룰 때: AI 가 `open_document` → `replace` / `set_markdown` / `apply_style` … → `save_document` 로 디스크의 문서를 고칩니다. 브라우저가 없어도 됩니다.
3. 열려 있는 창을 고칠 때: `npm start` 로 WIWORD 를 열면 창이 자동으로 연결을 기다립니다 (오른쪽 [AI 연결] 창). 도구에 `target: "app"` 을 주면 그 창의 문서가 바로 바뀌고, 실행 취소(Ctrl+Z)도 됩니다. [AI 가 문서를 고치기 전에 물어보기]를 켜면 바꿀 때마다 확인합니다.

도구: get_text · get_markdown · set_markdown · insert_markdown · inspect · list_paragraphs · edit_paragraph · delete_blocks · find · replace(정규식, 변경 내용 추적) · apply_style · format_text · insert_table · add_comment · comments · track_changes · page_setup · set_properties · header_footer · insert_toc, 그리고 open_document · new_document · list_documents · switch_document · save_document · convert · execute · list_commands · get_selection.
