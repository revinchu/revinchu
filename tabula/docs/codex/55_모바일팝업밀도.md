# 55. 모바일 팝업 공간 절약

2026-10-03. 기준 커밋 `bd6e0a0f1fc442e4bfb8a0aea149a0cfacf6490f`.

## 적용 범위

모바일 작업 모드가 활성화된 경우 공통 우클릭·리본 하위 메뉴, 셀/그림/차트 미니 서식, 글꼴 목록, 색/도형/스타일 갤러리, 일반/피벗 필터와 대화상자의 글자·아이콘·여백을 줄인다. 화면 너비에 따른 자동 모드와 상단 모바일 아이콘으로 켠 강제 모드에 모두 적용한다.

- 셀 우클릭의 스마트 조회, 윗주 필드 표시, 윗주 편집 항목을 메뉴 구성에서 제외한다. 데스크톱 모드로 돌아가면 다시 구성된다. 모드가 바뀔 때 열린 메뉴를 닫아 이전 모드의 항목이 남지 않게 한다.
- 오른쪽 Ctrl/Shift 단축키 안내는 숨긴다. 하위 메뉴 화살표는 별도 `mi-submenu` 클래스로 유지하고, 단축키 안내만 `mi-shortcut`으로 구분한다. 실제 키보드 조작과 레이블 접근 문자는 유지한다.
- 작은 밀도의 셀 미니 도구 모음은 322px에서 280px로 축소하고 글꼴·크기 목록 및 두 번째 줄의 13개 서식 아이콘을 유지한다.
- 공통 팝업 치수는 CSS 변수로 통일한다. 기존 compact 규칙과 중복되는 큰 높이 규칙을 정리한다. 데스크톱 치수에는 적용하지 않는다.
- 검색·입력·선택 상자의 실제 글꼴은 16px를 유지한다. iOS 포커스 자동 확대를 다시 유발하지 않도록 전체 팝업 zoom/transform 방식은 사용하지 않는다.
- 가상 필터 목록의 행 높이는 기존 26px를 유지한다. 렌더링 좌표/스크롤 계산을 바꾸지 않고 레이블·아이콘·내부 여백을 줄인다.
- 빠른 분석·무늬 선택은 공통 화면 경계 추적으로 가로·세로 잘림을 막고, 내용/화면/키보드 크기 변경에 재배치한다. 그리기 팔레트도 강제 모바일 모드에 맞춰 줄인다. 수식 자동완성은 격자와 실제 가시 영역의 교차 영역 안에 두고 아래 공간이 부족하면 위로 연다.
- 모바일 격자 자체에 포커스가 있는 경우 Ctrl+1, Shift+F10 등 기존 키보드 메뉴 경로를 연결한다. 에디터/자식 컨트롤 키는 중복 처리하지 않는다.
- 문서 값·셀 서식·선택·Undo·파일 형식은 이번 변경 대상이 아니다. 레이아웃 전환 및 메뉴 탐색 동안 합성 문서 불변을 검사한다.

## 검증

`tools/mobile-popup-density.mjs`로 실제 모바일 버튼 OFF→ON→OFF, 320×740 세로/844×390 가로 화면에서 메뉴 구성, 작은 미니 서식, 글꼴/크기 선택과 Undo, 하위 메뉴 키보드 이동, 셀 서식 6탭·확장 찾기, 빠른 분석 5탭·무늬 18개·그리기 8도구를 검사한다. 격자 Ctrl+1/Shift+F10/한 칸 이동과 Ctrl+B→Undo도 확인한다. `WIXEL_MOBILE_DENSITY_OUT`은 D: 출력 폴더, `WIXEL_MOBILE_DENSITY_FILTER`는 부분 검사 이름이다.

1366px의 실제 모드 전환 측정: 메뉴 항목은 데스크톱 12px/32px에서 작은 모바일 11px/26px로, 대표 우클릭 폭은 266.6px에서 195.7px로 줄었다. 대화상자 본문 여백은 18px에서 6px, 버튼 높이는 32px에서 28px가 되었으며 모드를 끄면 기존 치수가 복구된다. 입력 필드의 16px는 유지한다.
