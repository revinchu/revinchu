## 구현

- src/web-font-catalog.js: 버전·공식 출처·배포 주소·제공 굵기/기울임·원문 라이선스를 기록한 정적 레지스트리. tools/update-font-catalog.mjs로 공식 메타데이터/라이선스 검증 및 재생성. 폰트 바이너리나 업무 문서는 저장소에 넣지 않는다.
- src/fonts.js: 목록과 이름 처리는 순수 조회. 선택/실제 표시/미리보기 글꼴만 비동기 다운로드한다. 동일 글꼴의 동시 요청을 공유하고 오류와 명시적 재시도를 지원한다. Google CSS2는 실제 제공된 variant 조합만 요청한다. 문서 텍스트를 text= 쿼리로 외부 전송하지 않는다.
- src/view.js: 원본 글꼴 이름을 보존하면서 한글/영문/웹 CSS 별칭을 연결한다. 늦게 로드된 글꼴은 너비·미설치 판정·수직 정렬·개체 레이아웃 캐시를 무효화하고 화면만 갱신한다. 이 완료 콜백은 Workbook/Undo/행 높이/문서 선택을 변경하지 않는다.
- 글꼴 메뉴의 문서 사용 목록은 기본·행·열·희소 셀·열 블록·도형 텍스트를 포함하고 문서 revision별로 캐시한다. 블록 데이터/빈 행 전체를 확장하지 않는다.
- src/font-export.js: HTML/SVG/PNG/JPEG/PDF에 실제 사용한 글꼴 굵기와 Unicode 범위의 원본 font-face 파일을 data URL로 내장한다. 라이선스 전문을 동봉하며 문서의 문자를 서버 쿼리로 보내지 않는다. 폰트 다운로드/라이선스 확보 실패는 대체 글꼴 경고로 표시한다. 출력 파일의 font-src data: 정책은 유지한다.
- 출력용 글꼴 파일은 검증된 HTTPS 출처·리디렉션·바이너리 서명을 검사한다. 한 번에 4조각까지 받고 바이너리 캐시는 16MiB 이내로 제한한다. CSS·원문 라이선스는 문서 사용자 입력 URL이 아니다.
- 추가 발견 오류: 초기 자동 저장이나 보관 사본 생성으로 storage docId만 바뀌면 같은 우클릭 도구의 후속 글꼴/크기 명령을 막았다. 셀/도형 텍스트 편집 유효성을 열린 문서 요청·Workbook·시트 객체로 검사하여 저장 후 연속 편집을 허용하되 다른 문서로의 지연 적용은 차단한다.

## 호환성 경계

처음 사용할 무료 웹 글꼴은 인터넷 연결이 필요하다. 기기 전용 글꼴의 바이너리를 무단 복사하거나 공개 CDN인 것만으로 사용권을 추정하지 않는다. XLSX/WIXEL은 원본 글꼴 이름과 서식을 보존하지만 XLSX 파일에 글꼴 프로그램을 내장하는 기능은 없다. Excel에서 같은 모양을 보려면 해당 글꼴이 PC에 설치되어 있어야 한다. iPad 실기기/Bluetooth 키보드 전수검증과 브라우저 WebKit 자동검사는 구분한다.
