# 37. 팝업 UI와 옵션 정렬

2026-10-02

## 문제와 적용 범위

기존 공통 폼은 체크 항목에도 90px 너비의 설명 칸을 사용했다. ‘숫자 (상수 · 수식)’과 시트 보호 권한처럼 긴 항목이 여러 줄로 잘리고 체크박스가 뒤에 떨어져 보였다. 폼 전용 레이블과 체크 행을 분리하여 일반 입력은 두 칸으로 정렬하고, 확인란은 설명 앞에 배치한다. 작은 화면에서는 일반 입력도 위아래로 쌓는다.

`ui.js`의 `openDialog`/`formDialog`와 `styles.css`의 공통 규칙을 정리했다. 제목·닫기·입력·탭·버튼의 행 높이와 여백을 통일하고, 헤더·푸터는 줄어들지 않게 하며 긴 본문만 스크롤한다. 오류 설명, 설정 그룹, 선택 항목과 키보드 포커스를 구별한다. 원래 필드 값, `onChange(inputs)`, `onSubmit`, 비동기 처리, 중첩 창과 접근키 계약을 유지한다.

셀 서식의 분류·미리보기·탭, 옵션의 범주 탐색, 차트·도형 서식의 접이식 그룹, 그림 서식의 미리보기, 찾기/바꾸기와 드롭다운 메뉴에 같은 간격·색·윤곽 기준을 적용했다. 모바일 입력 글자 크기는 기존 확대 방지 규칙을 유지하며, 작은 화면의 옵션 범주 탐색은 옆으로 스크롤할 수 있다.

## 개별 개선

- **이동 옵션**: 11가지 선택 종류를 라디오 목록으로 표시한다. 상수/수식에서만 숫자·텍스트·논리값·오류 하위 선택을 활성화한다. 기본값은 빈 셀이며 실제 셀 선택 로직은 바꾸지 않는다.
- **빠른 실행 도구 모음 설정**: 모바일에서 두 목록을 세로로 배치한다. 목록에 제목을 붙이고 선택한 명령 전체 이름을 별도로 표시하여 긴 이름도 읽을 수 있게 한다. 기존 추가·제거·순서 변경과 실행 키를 유지한다.
- **창 위치와 스크롤**: 찾기 창의 확장, 서식 창의 가장자리 드래그와 브라우저 크기 변경 시 제목뿐 아니라 창 전체가 화면 안에 머물도록 한다. 창을 닫으면 드래그 이벤트와 크기 관찰자를 해제한다. 좁은 화면의 여러 줄 서식 탭은 본문과 함께 스크롤하여 입력칸을 덮지 않는다.
- **이전 알림 정리**: 새 창을 열면 직전 작업의 토스트만 즉시 숨겨 확인/취소를 가리지 않게 한다. 시작 후 늦게 도착하는 새 버전 소개 알림도 설정 창이 열려 있으면 생략한다. 새 창 안에서 발생하는 안내와 입력 검증 오류, 자동 숨김은 유지한다.
- **레이블과 키보드**: 공통 입력에 고유 id/name과 label 연결, 안내와 제목에 접근성 연결을 추가한다. 자동 고침 입력칸과 셀 서식 분류/서식 코드의 이름을 명확히 한다. Tab 이동은 실제 보이고 사용할 수 있는 컨트롤을 대상으로 한다.

## 회귀 검증

`tools/dialog-layout.mjs`는 실제 명령으로 연 대표 옵션·서식 창을 데스크톱/좁은 화면/모바일에서 검사한다. 창 테두리와 제목·닫기·확인/취소 위치, 본문 넘침, 긴 레이블과 QAT 목록 폭, Tab·Escape·접근키·확인/취소를 확인한다. 합성 문서만 사용하며 사용자 작업 창에 접근하지 않는다. 기존 `tools/dialog-access-keys.mjs`와 모든 리본 명령 스모크도 함께 검사한다. 접근키 도구는 `/src/ui.js`를 가져오는 소스 전용 검사이므로 배포 번들에서 실행한 결과와 혼동하지 않는다.

- 단위 테스트: 750개 통과. 일반 빌드와 Cloudflare 빌드 성공.
- 레이아웃: 소스와 Cloudflare 로컬 번들 각각 11종 × 4개 화면 크기 = 44그룹, 세부 검사 2,700개 이상 통과. 본문 스크롤·탭 탐색·긴 설명·모델리스 이동/크기 보정·선택과 취소 결과를 확인했다.
- 번들 리본 스모크: 324명령, 오류 0.
- 소스 전용 공통 접근키 22개 및 이전 토스트/새 안내 보존 8개 검사 통과.
- 개별 기능: 이동 옵션 11종과 빠른 실행 목록 추가·제거·순서 변경, 시트 보호 실행 취소, 셀/그림 서식 초안 취소를 확인했다. 도형 검사는 범주와 입력칸 접근성 범위이며 모든 서식 값을 바꾼 검사는 아니다.

공통 스타일 적용이 모든 업무 상황이나 모든 장치에서의 외관 검증을 뜻하지는 않는다. 개별 도구의 데이터별 미리보기나 동적으로 추가되는 항목은 후속 회귀 범위로 확장한다. 이번 변경은 팝업 구성과 조작 개선이며, 수식·파일 입출력·셀 렌더러의 기능을 바꾸지 않는다.
