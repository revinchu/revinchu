# 글꼴 표시 이름과 Excel 설치 이름

## 문제와 재현

기준 88e07d72c93e749c8a4ced9c8bfedcdd5ec7058c에서 G마켓을 검색하면 일반 이름 두 개만 보이고 굵기별 선택이 없었다. 실제 메뉴로 선택한 뒤 XLSX를 저장하면 styles.xml에 Gmarket Sans가 기록됐다. 공식 Windows 설치용 TTF의 name ID 1은 Gmarket Sans TTF Light, Gmarket Sans TTF Medium, Gmarket Sans TTF Bold로 나뉘므로 공통 웹 이름과 매칭되지 않는다.

## 구현

- font-identity-data.js는 공식 설치 파일에서 확인한 48개 계열(CDN 43개·Google 나눔 5개)의 100개 설치 이름과 구형 나눔스퀘어 네오 웹 별칭 10개를 담는다. tools/font-identity-sources.json에 바이너리 139개의 출처·ZIP 항목·SHA256·Windows name table 증거를 기록한다. 글꼴 바이너리는 저장소에 포함하지 않는다.
- font-identity.js는 표시용 별칭과 실제 설치 이름을 분리한다. G마켓 공통 별칭의 기본값은 TTF Medium, 굵게는 TTF Bold다. 별도 Bold 가족을 선택한 경우 합성 굵게를 중복 적용하지 않는다. 명시적인 TTF/OTF 설치 이름, 유효한 한글 설치 이름, 알 수 없는 기업 글꼴은 보존한다.
- 실제 이름 여부는 공백을 유지해서 판정한다. 따라서 Nanum Gothic 웹 이름은 NanumGothic으로 교정하면서 이미 유효한 나눔고딕과 NanumGothic은 유지한다.
- 글꼴 목록에는 실제 설치 가족별 굵기를 제공하고 한글 별칭으로 모두 검색한다. 굵기별 가족의 웹 파일은 그 가족 안에서는 CSS Regular로 등록한다. 예를 들어 Gmarket Sans TTF Bold는 실제 Bold WOFF2를 CSS 400으로 사용한다.
- Pretendard/SUIT/Wanted 및 Google의 이름 변경 가족은 원본 CSS의 굵기와 한글 unicode-range를 유지해 필요한 가족으로 등록한다. Google ExtraBold 원본 요청에는 800을 보내고 반환 얼굴을 별도 가족의 400으로 등록한다. Wanted ExtraBlack의 CSS 원본 선택은 1000이다.
- 셀·행·열·기본 글꼴·이름 서식·조건부 서식·표/피벗/슬라이서 DXF·도형 부분 서식·차트/ChartEx·테마·머리글/바닥글·ODS 저장에 같은 이름 매핑을 적용한다. DXF 읽기에서 글꼴명·크기·명시적 false를 버리던 누락도 수정한다.
- 기존 위셀 문서를 열어 XLSX로 저장해도 별칭을 변환한다. 원본 문서 모델과 실행 취소 이력을 저장 도중 수정하지 않는다. 새 글꼴 선택은 평소와 같이 실행 취소/다시 실행된다.
- SVG/HTML/PDF 글꼴 내장도 동일한 실제 얼굴을 사용하며 기존 라이선스 동봉·요청 주소 제한을 유지한다.

## 범위와 제한

카탈로그 전체의 표시 별칭은 일관된 이름으로 처리하되, 1,900여 계열 전체의 모든 버전·설치 파일을 조사했다고 주장하지 않는다. 설치 파일 내부 이름을 검증한 범위는 위 48개 계열이다. 확인하지 못한 사용자 지정 글꼴은 임의로 바꾸지 않는다. Excel에서 같은 글꼴 모양을 보려면 해당 TTF/OTF가 그 PC에 설치되어 있어야 하며 XLSX 자체에 웹폰트가 내장되는 것은 아니다. 브라우저 엔진 검사는 실제 iPhone/iPad 하드웨어 검사를 대신하지 않는다.
