구형 XLS fixture의 F27은 `=CHOOSE(2,"a","b","c")`지만 BIFF8 FORMULA 레코드의 저장 캐시는 숫자 `0`입니다.
재계산 결과 `"b"`와 다르므로 검사 스크립트가 정확하게 차이를 보고합니다.
이전 `0a479d7`의 리더도 같은 캐시 `0`을 읽는 것을 확인했으며, 리더·fixture·판정 기준을 바꾸지 않았습니다.
이 차이를 검증 성공이나 이번 수정의 회귀로 집계하지 않습니다. 근거는 `xls-cache-analysis.log`에 기록했습니다.

추가한 테스트는 표 열 변동과 참조·실행 취소·저장 왕복, XLSX 문자열·행 높이,
1904 경고, 잘못된 날짜, 15만 행 CSV·스파크라인, 클라이언트 HTTP 상태,
서버 인증·경로·저장·중계 방어와 UI 실제 조작을 다룹니다.
