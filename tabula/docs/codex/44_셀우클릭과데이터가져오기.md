# 셀 우클릭과 데이터 가져오기

## 동작

셀 우클릭, 메뉴 키, Shift+F10에서 Excel식 셀 메뉴를 연다. 선택 범위 안의 우클릭은 범위를 유지한다. 행/열 머리글은 기존 전용 삽입·삭제·크기·숨기기 메뉴를 유지한다.

- 잘라내기/복사/붙여넣기 옵션/선택하여 붙여넣기, 스마트 조회, 삽입/삭제/내용 지우기, 빠른 분석.
- 필터: 선택 셀 값·채우기·글꼴 색, 현재 열 조건 해제, 모든 조건 지우기, 다시 적용, 고급 필터. 다른 열 조건과 수동 숨김은 유지한다.
- 정렬: 값 오름/내림, 선택 셀 채우기·글꼴 색 우선, 사용자 지정. 표의 머리글·합계는 데이터 정렬에서 제외한다.
- 메모 삽입/편집/삭제/표시, 셀 서식, 드롭다운 목록에서 선택, 윗주 표시/편집, 이름 정의, 링크.
- 행·열 크기와 숨기기는 하위 메뉴로 묶고 표/피벗 메뉴도 유지한다.
- 작은 미니 서식 도구 모음의 상시 접근키 글자 겹침을 제거했다. Alt 키팁·키보드 접근은 유지한다. 모바일에서는 탭으로 하위 메뉴를 열어 터치 호환 hover가 메뉴를 다시 닫지 않게 한다.

## 목록 선택

`cell-pick-list.js`는 같은 열에서 위·아래로 이어진 기존 문자 항목을 중복 없이 정렬한다. 빈 셀 경계에서 중단하고 숫자·수식 결과는 일반 입력 제안에서 제외한다. 유효성 검사 목록은 해당 규칙의 원본을 사용한다. Alt+아래쪽은 필터 머리글·표 합계에선 기존 메뉴, 그 외에는 목록 선택으로 연결된다.

검색, 방향키, Home/End, Enter, Escape를 지원한다. 일반 문자 제안은 숫자처럼 보이거나 =로 시작해도 문자열 그대로 저장한다. 최대 50,000개 인접 셀을 검사하고 5,000개 고유 항목을 모으며, 화면에는 검색 결과 1,000개까지 표시한다. 열린 동안 문서·시트·대상 셀·유효성 규칙·권한이 바뀌면 쓰기를 거부한다.

## 윗주

`phonetic.js`/`phonetic-ui.js`가 원문, 읽는 법 구간, 표시 상태, 글꼴·크기·정렬을 관리한다. `workbook.js`의 표준 셀 메타로 Undo와 직렬화, PHONETIC 수식 갱신을 지원한다. `xlsx.js`는 sharedStrings와 inlineStr의 표준 rPh/phoneticPr 및 셀 ph를 읽고 쓴다. 같은 원문에 서로 다른 윗주가 있을 때도 셀별로 보존한다.

실제 입력 문자열 셀만 편집하며 수식·배열 결과를 덮지 않는다. 원문을 변경할 때는 서식 권한뿐 아니라 셀 편집 권한도 다시 검사한다. 숨기기/표시만 바꾸어도 원문과 읽는 법은 유지한다. 기본 높이 행은 글자 높이에 맞추고 사용자 지정 높이는 유지한다.

자동 발음 생성은 제공하지 않는다. XLS/XLSB 바이너리 윗주 해석과 회전 셀의 화면 윗주는 아직 미지원이며, 회전 셀도 XLSX 메타는 보존한다. 한 번에 표시를 바꾸는 범위는 50,000개 텍스트 셀 이하이다.

## 표/범위에서 데이터 가져오기

`range-query.js`와 `range-query-ui.js`가 원본 계산값의 사본을 변환한다. 열 선택, 머리글 여부, 자료형, 여러 AND 필터, 여러 정렬 기준, 빈 행·중복 제거를 미리 보고 새 시트의 표로 로드한다. 표 합계는 제외하고 숨겨진 원본 데이터는 포함한다. 기존 시트는 바꾸지 않으며 새 시트와 표 생성은 한 번의 Undo로 취소한다.

숫자/정수/날짜/논리값/텍스트/원본 유지 형식, 날짜 체계, 0·FALSE·앞자리 0·= 문자·오류 셀을 구분한다. 변환 실패를 빈 값으로 지우지 않고 오류 행·열을 알린 뒤 로드를 차단한다. 문서·시트·버전·구조 보호·최종본 상태를 확인 시점에 다시 검사한다. 처리 상한은 100,000행, 1,000열, 500,000셀 중 먼저 도달하는 제한이다.

이 기능은 로컬 범위 변환 및 로드이다. Microsoft Power Query M 엔진, 외부 커넥터 전체, 저장된 쿼리의 자동 새로 고침과 동일하다고 표시하지 않는다. Excel의 원본 기능은 [Microsoft 안내](https://support.microsoft.com/en-us/excel/create-load-or-edit-a-query-in-excel-power-query)를 참고한다.

## 검증

- 전체 Node 검사 897/897, 두 빌드 성공, 컴파일 앱 리본 명령 377개 오류 0.
- 셀 메뉴 소스·컴파일 각각 21개 시나리오 186개 확인 통과: 선택 보존, 값·색 정렬/필터, 메모·서식·링크·이름, 목록·윗주, Undo, 보호, 모바일.
- 최종 목록 규칙 변경 차단·미니 도구 모음·모바일 변경분 4개 시나리오 33개 확인 통과. 셀 메뉴 검증 도구는 총 22개 시나리오를 제공한다.
- 범위 가져오기 단위 13개, 소스·최종 컴파일 앱 각각 10개 시나리오 45개 확인 통과. 1040px 대화상자와 390px 모바일을 시각 검사했고 페이지 오류·원격 쓰기 0건이다.
- 윗주 신규 7개 및 관련 입출력/서식 29개 통과. 별도 Excel 인스턴스에서 합성 파일 정상 열기·재저장 후 구간 2개·표시·글꼴/색·정렬 및 PHONETIC 계산값 보존 확인.
- 실제 쿠첸 정산 29,369셀/8,545수식, 여행 월간 보고서 932,457셀/698수식의 기존 배포본 대비 계산 및 왕복 차이 0. 피벗은 두 파일에 0개라 이 결과를 피벗 호환성 확대 근거로 사용하지 않는다.
- 실제 업무 파일은 읽기만 하며 저장소에 포함하지 않는다. 브라우저 검사는 합성 문서·메모리 클립보드·외부/API 요청 차단 환경이다.
