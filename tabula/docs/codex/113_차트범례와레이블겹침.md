## 구현

- `plotLayout`의 inner 좌표/크기를 표준 OOXML에서 읽고 쓰며 실제 그림 영역에 적용한다. outer 배치도 저장하지만 해당 배치의 자동 여백 계산은 기존 동작이다.
- 수동 범례의 가로/세로 배치는 상자 크기를 따른다. 데이터가 모두 빈 가져온 차트도 계열 범례와 축은 유지한다.
- `plotVisOnly`를 `visibleOnly`로 보존한다. 화면에서는 숨긴 행/열과 필터를 반영하고 저장용 데이터 캐시는 원래 순서를 유지한다. 점별 서식 인덱스를 보존한다.
- 접힌 차트는 높이 0과 원래 셀 앵커를 보존한다. 화면에는 그리지 않으며 숨기기 해제·행 삽입/삭제 시 앵커를 따라 복원한다. 이동/크기 변경 후에는 오래된 앵커를 사용하지 않는다.
- 자동 데이터 레이블은 공간 버킷으로 이웃 충돌을 찾는다. 안쪽/가운데 위치 옵션은 그대로 유지하고 빈 범주 글자는 만들지 않는다.
