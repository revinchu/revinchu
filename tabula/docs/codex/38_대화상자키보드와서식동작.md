# 대화상자 키보드와 서식 동작

작성일: 2026-10-02

## 사용자 문제와 변경

텍스트 나누기에서 Enter가 단계와 무관하게 마침을 실행했다. 1·2단계는 다음(N), 3단계는 마침(F)에 초점을 두고 입력 중 Enter도 같은 기본 동작을 실행한다. 탭만 기본 구분 기호로 선택하고 열 서식은 일반(G)으로 시작한다. 단계 이동·옵션 재구성 후 초점이 셀로 빠지지 않는다. 고급 설정은 소수/천 단위 구분 기호, 뒤쪽 음수 기호, 원래대로, 확인/취소를 지원한다.

공통 대화상자와 하위 메뉴는 실제 배정된 접근키를 괄호 문자로 항상 표시한다. 명시 키를 우선하고 자동 키는 같은 컨트롤에서 안정적으로 유지한다. 기존 괄호 표기는 중복하지 않으며 disabled 명시 키도 안내한다. 자동 키는 Excel과 일치한다고 보장하지 않는다. 모달의 외부 초점을 복구하고 바깥으로 향한 Enter/Escape/Tab이 격자를 조작하지 않게 한다. 모델리스 창·범위 선택·소유 하위 메뉴는 별도 동작을 유지한다. 비활성 기본 버튼은 Enter로 실행하지 않는다.

차트 데이터 원본은 범위 변경을 초안에만 적용하여 취소 시 원본 시트 참조를 보존한다. 입력 후 바로 Enter를 눌러도 최신 범위를 검증한다. 계열 목록은 방향키/Home/End/F2/Delete로 조작하고 불가능한 이동 버튼은 비활성화한다. 긴 이름을 자르되 전체 이름을 툴팁으로 제공한다. 미리 보기는 접을 수 있다. 차트 이동은 새 시트/현재 워크시트 라디오와 종속 입력을 사용하고, 동일 시트 선택은 아무 변경 없이 닫는다. 이동 시 데이터 참조를 유지하고 실행 취소할 수 있다.

차트 서식은 원형에 적용되지 않는 간격·겹침·누적·표식 등을 숨긴다. 서식 재구성 시 접힘 상태·입력 초점·스크롤을 유지한다. 도형 서식은 도형 옵션(채우기 및 선/효과/크기 및 속성)과 텍스트 옵션(텍스트 및 글꼴/텍스트 상자)으로 분리한다. 지원하는 채우기와 선 종류는 라디오로 선택하며 선 종류·화살표는 실제 렌더러로 미리 본다. 도형 선택이 A에서 B로 바뀌면 현재 범주를 유지하며 B에만 적용한다.

## 코드 계약

- `openDialog({initialFocus, defaultAction})`: 초기 대상은 요소·선택자·함수를 받는다. 반환 `focus()`는 유효한 마지막 초점 또는 초기 대상을 복구한다. `defaultAction`은 창을 자동으로 닫지 않으며 일반 확인/취소 계약과 구분한다.
- `.access-key-hint`: 실제 실행 키와 같은 `data-access-caption`을 CSS 의사 요소로 표시한다. `aria-hidden`으로 원래 접근성 이름을 보존한다. 동적 감시기는 생성한 표기를 무시하여 반복 갱신을 피하고 창 종료 시 해제한다.
- 도형 패널의 `getSelectedTab()`은 현재 세부 범주를 반환한다. 앱은 선택 대상과 문서/시트가 같은지 다시 검사한 후에만 변경한다.

## 검증

사용자 파일 대신 합성 문서·격리 Chromium을 사용한다. 브라우저 도구는 API·외부 요청·원격 쓰기를 차단한다. 관련 단위 검사와 전체 단위 검사, 표준/Cloudflare 빌드, 명령 스모크와 아래 UI 회귀를 실행한다. 최종 결과는 배포 기록과 각 도구 로그에 남긴다.

- `dialog-keyboard-parity.mjs`: 로컬 소스 전용. 외부 초점, 본문 재구성, 기본 동작 API, disabled 버튼, 중첩/모델리스, 상시 표기·작은 화면 닫기·키 안정성·감시기 반복 여부.
- `text-to-columns-ux.mjs`: 로컬 소스/번들. Alt A E, Enter 세 번, 기본값, 명시 접근키, 고급 설정, 변환/덮어쓰기/Undo, 320/390px, 합성 한글 물리키·지연 조합 이벤트.
- `chart-dialog-ux.mjs`: 소스/번들. 데이터 원본 취소와 즉시 Enter 확인, 계열 키보드, 차트 이동/검증/Undo, 유형별 서식, 작은 화면.
- `shape-format-parity.mjs`: 소스/번들. 두 단계 범주, 실제 적용/Undo, 선택 대상 전환, 선 미리 보기, 재구성 초점·접힘·스크롤, 320px.
- `dialog-layout.mjs`: 4개 화면 크기×11개 팝업의 레이아웃·모델 동작. 기존 도형/텍스트/서식 회귀의 선택자는 새 범주 구조에 맞춘다.

## 범위와 남은 한계

이번 변경은 위 동작과 지원 중인 서식 구성의 개선이다. Excel의 모든 서식과 완전한 동등성·전체 화면 픽셀 일치를 의미하지 않는다. 새 차트 시트는 차트를 크게 배치한 워크시트이며 네이티브 차트 전용 시트가 아니다. 도형의 그림/질감 채우기, 그라데이션 선, 텍스트 그라데이션·텍스트 윤곽선 등 미지원 렌더링 기능을 동작하지 않는 옵션으로 노출하지 않는다. 실제 OS 한글 IME·모바일 소프트키보드·화면 읽기 프로그램 검증은 합성 이벤트 및 화면 크기 회귀와 별개다.
