# 15. 차트·그림·피벗·필터·설정 확장

2026-10-01 후속 작업입니다. 현재 범위는 Excel의 전 기능 100% 복제 또는 실물 Excel과의 표시 일치 보장이 아닙니다. 이전 17유형·50변형의 검증은 [14번 문서](14_차트와표시검증.md)에 있으며, 아래는 그 이후 변경입니다.

## 차트

22개 모델 유형과 61개 갤러리 형태를 제공합니다. 3D/3D 효과 15개는 이 61개 안에 포함됩니다. 구형 Excel의 원통·원뿔·피라미드 막대나 모든 조합을 각각 지원한다는 뜻은 아닙니다.

- 선버스트: 다단계 범주 → 마지막 수치 열. 숫자 범주도 계층으로 취급하고 부모·자식 각도를 합계에 맞춰 배치합니다. 트리맵도 같은 계층 자료를 읽습니다.
- 표면형: 3차원 표면·3차원 골격·등고선·골격 등고선 4종. 행/열 머리글과 2차원 수치 행렬을 읽고 높이 구간을 보간합니다. 서식 창에서 색 구간 수와 회전을 조정합니다.
- 보조 원형/막대형: 위치·값·백분율·직접 지정 항목으로 분리하고 보조 차트 크기·간격을 조정합니다.
- 주식형: 고가-저가-종가, 시가-고가-저가-종가, 거래량이 붙은 두 형태를 제공합니다. 부족한 계열로 썸네일을 그려도 오류가 나지 않으며, 적용 시 열 배치와 필요 계열 수를 안내합니다.
- 거품: 3차원 구면 효과·크기·음수 표시 설정. 실제 3차원 깊이 축을 가진 산점도가 아닙니다.
- 지도: 한국어·영어 국가명과 ISO 코드를 인식하는 오프라인 색칠지도. 같은 국가 값은 합산하고 미인식·비수치 항목을 알립니다. 경계 데이터와 제한은 [16번 문서](16_지도데이터.md)에 있습니다.
- 차트 갤러리: 한글 이름 검색, 하위 유형 이름, 실제 데이터 미리보기, 잘못된 데이터 배치 안내, 방향키/Home/End 이동, 편집 시 기존 하위 유형 복원. 검색 결과가 없으면 이전 차트를 실수로 확정하지 않습니다.
- 서식 창: 요소·계열 선택, 범주별 키보드 이동, 숨긴 계열의 원래 번호 보존, 기본 축 0의 명시 저장, 보조 축 표시·반전·단위, 폭포 합계·연결선·색, 지도 3색, 거품 옵션. 색 선택 한 번을 불필요하게 여러 실행 취소 기록으로 쌓지 않습니다.

지도는 국가/지역 단위이며 도시·시군구·우편번호 지오코딩은 없습니다. 3D 엔진은 브라우저 SVG 표현이고 Excel의 조명·재질·효과·3D 투영과 동일하다고 검증하지 않았습니다. 모든 종류 혼합, 모든 레이블/추세선/오차막대/효과 옵션의 완전한 호환도 남은 범위입니다.

## XLSX 저장·열기

보조 원형/막대형, 표면형 4종, 거래량 주식형은 표준 OOXML 차트 요소로 기록합니다. WIXEL 전용 확장을 제거한 왕복 검사도 수행합니다. 기존 표식 크기 고정 저장과 분산·방사형 스타일 저장도 수정했습니다.

폭포·깔때기·히스토그램·파레토·트리맵·선버스트·상자수염·지도는 Office 2016+ `chartEx` 어댑터를 사용합니다. 앞서 현대 차트를 기본 막대형으로 대체 저장하던 경로를 개선하며, 원자료·계층·계열 참조 및 해당 종류의 옵션을 저장합니다. 앱별 추가 서식은 WIXEL 확장 속성에 보존합니다.

단위 왕복 검사, 표준 XML 구조 검사, Microsoft Open XML SDK 스키마 검증과 실제 Microsoft Excel 실행 검증은 서로 다릅니다. 이번 환경에서는 실제 Excel 365에서 복구 안내 없이 열리는지 또는 픽셀 단위로 같은지 확인하지 않았습니다. 사용자 업무 파일의 수식·피벗 전후 비교도 수행하지 않았습니다.

## 그림

`picture.js`는 크기·비율·자르기·원본 크기 계산, `picture-ui.js`는 편집 초안과 실시간 미리보기를 담당합니다. 너비/높이/위치, 회전, 가로세로 대칭, 네 면 자르기, 원래 크기, 셀에 따른 이동·크기 동작, 대체 텍스트를 제공합니다.

확인 시 한 번의 실행 취소로 적용하고 취소는 원본을 바꾸지 않습니다. 비율 고정과 Shift 드래그를 구분합니다. 저장된 그림의 회전·대칭을 읽을 때 놓치던 문제를 수정하고 XLSX picLocks/descr/transform/crop으로 보존합니다. 밝기·예술 효과·배경 제거 등 미구현 효과 메뉴를 지원한다고 표시하지 않습니다.

## 피벗·슬라이서·표·필터

- 일반/피벗 필터의 검색 중 체크 선택을 보존하고, 검색 결과를 기존 필터에 추가할 수 있습니다. 빈 검색 결과는 무심코 전체 필터를 바꾸지 않습니다.
- 피벗 필드를 변경한 뒤 검색어와 검색 포커스를 유지합니다. 필드 영역 이동, Space/방향키/Enter/Esc의 동작을 확인합니다.
- 슬라이서 삽입의 필드 선택 창에 검색·보이는 필드 선택/해제·선택 개수를 추가합니다. 이것은 슬라이서 내부 항목 검색의 신규 구현과는 다릅니다.
- 표 생성·범위 조정 시 다른 시트, 병합 셀, 피벗 결과, 배열 결과와 충돌하는 범위를 거절합니다.

## 설정

9개 범주의 설정 검색과 일치 항목 강조, 위/아래/Home/End 범주 이동, 빠른 실행 명령 검색을 제공합니다. 검색하며 초안과 기존 도구 순서를 유지하고 취소하면 저장하지 않습니다. 고급 옵션의 소수 자릿수 0이 -10으로 바뀌는 오류를 수정했습니다.

## 검증 실행

새 브라우저 도구는 합성 문서와 별도 브라우저 컨텍스트를 사용하고 서버 쓰기를 차단합니다.

```powershell
node tools/chart-upgrade-ux.mjs

```

### 저장 보존과 화면 표시의 구분

ChartEx의 기본 종류·원자료·계층·범위 참조·표준 축·주요 옵션은 표준 요소로 기록합니다. 축 반전, 데이터 표, 일부 계열 서식 등 표준 변환에 포함하지 않은 위셀 설정은 자체 확장에 보존하며 Excel에서도 같은 화면이 된다는 뜻은 아닙니다. 가져오는 확장 값은 허용 키·배열 번호·기본 타입을 검사하고 프로토타입 키를 제거합니다.

지도는 `regionMap` 종류·국가 범주·값·3색을 저장하지만 Excel용 geoCache와 주소 지오코딩을 만들지 않습니다. Excel에서 지리 정보의 온라인 조회가 필요할 수 있습니다. 트리맵 화면은 최상위 그룹과 말단 중심이며 중간 계층 데이터는 표준 파일에 보존합니다. 상자 수염형의 배타적 사분위수·모든 내부 점 등 일부 옵션은 읽기/보존과 화면 구현 범위가 다릅니다.

최종 8787 번들에서도 `#fileInput`으로 ChartEx 합성 XLSX 8종을 열어 종류·계열·값·SVG를 확인했습니다. 8/8 통과, 페이지 오류·서버 쓰기·소스 모듈 요청 0이며 트리맵 상위 그룹·범례 중복 제거도 확인했습니다.

공개 배포 `528eaab6-7edd-491e-8733-ba8acaf11155`와 차트 9항목(탐색 timeout 재시도 포함)의 확인 결과는 [12번 문서](12_공개배포와운영검증.md)에 기록했습니다. 공개 서비스의 최신 자산은 `wixel-6ef4c366d5655051.js`입니다.
