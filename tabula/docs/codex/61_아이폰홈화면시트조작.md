# 61. 아이폰 홈 화면 앱의 시트 조작

기준: `dfe630c`. 사용자가 iPhone 홈 화면에 추가한 위셀에서 시트 숨기기·숨기기 취소·목록 취소 중 OS 앱 화면으로 나간다고 보고했다. Safari 탭이나 위셀 시작 화면으로 이동하는 문제와 구분한다.

## 확인한 배치 오류

기존 모바일 footer는 `safe-area-inset-bottom - mobile-footer`만 하단 패딩으로 남겼다. 안전영역 34px, 시트 행 24px인 390×844 모사 환경에서 시트 탭의 bottom은 834px이고 안전한 경계는 810px이었다. 즉 버튼이 홈 제스처 영역을 침범했다. 844×390/21px에서도 같은 결함을 재현했다.

앱은 이제 네 방향 안전영역 전체를 별도 패딩으로 확보한다. 시트·보기·배율의 한 줄 구성과 작은 글자 크기는 유지한다. 공통 메뉴 위치는 visual viewport와 안전영역의 교집합으로 제한하고, 모바일 대화상자의 최대 크기·패딩도 같은 안전영역을 제외한다. 실제 OS 홈 복귀의 직접 원인이라고 입증한 것은 아니며, 독립적으로 확인된 배치 결함을 수정한 것이다.

## 취소·이동 경로 조사

시트 메뉴·목록 경로에 `window.close`, 외부 URL 이동, history 뒤로 가기는 없었다. 현재 목록은 HTML 버튼으로 되어 있고 native select를 쓰지 않는다. 격리 WebKit의 반복 취소에서 문서 버전·Undo·DOM 개수는 유지되고 포커스 재귀도 없었다. 모사 standalone 실행 역시 실제 iOS 프로세스 수명이나 OS 제스처를 재현하지 못한다.

## 시트 상태만 바꿀 때의 저장 부담

기존 대용량 자동 저장은 `state`만 바뀌어도 30만 셀을 15개 청크로 다시 JSON 직렬화·압축했다. 현재 `Workbook.propSnap()`은 표시 상태에 한해 셀 데이터 편집 번호 `_ev`를 올리지 않고 문서 `version`과 Undo 기록은 유지한다. `big-storage.js`는 이전 `_ev`가 같고 `state`를 제외한 모든 메타가 같을 때만 기존 불변 셀 청크·블록·분할 청크를 재사용해 새 메타 레코드를 만든다. 기존 v3 저장 형식과 CAS 교체 방식은 유지한다.

실제 IndexedDB 합성 검사에서 숨김·Undo·Redo 모두 셀 직렬화와 압축이 **15청크에서 0청크**로 줄었다. 30만 셀 숨김 저장은 한 계측에서 681.7ms→14.4ms, Undo는 673.7ms→10.7ms였으나 시간은 기기·병행 부하에 따라 달라진다. 셀이나 다른 메타가 함께 바뀌면 기존 저장 경로를 사용한다. 실패 시 이전 세대 보존, 동시 변경 거부, CAS 충돌, 16MB 분할 청크 GC, Web Locks 없는 환경도 검사했다.

최근 문서 보관용 `libraryFlush()`의 전체 snapshot 및 이미지가 포함된 메타 복제 부담은 이번 변경에 남아 있다. 이 최적화가 모든 메모리 사용을 제거하거나 iOS Jetsam 종료를 해결했다고 주장하지 않는다.

## 업데이트 안내

기존 새 버전 알림은 모바일에서 숨겨진 제목줄 중앙에만 붙어 있었다. 모바일 작업 도구에도 앱 버전·홈 화면 앱 여부·새 버전 안내 진입을 제공한다. 문서를 저장하라는 기존 안내를 재사용하며 강제 새로고침하지 않는다. 실행 파일 식별자는 진단 상세 정보로 표시한다.

재현 가능한 도구는 `tools/mobile-sheet-actions.mjs`, `tools/mobile-release-notice.mjs`, `tools/sheet-state-storage.mjs`다. 로컬 증거는 `.local/ios-sheet-*.log`, `.local/mobile-sheet-actions-pwa-*.log`, `.local/mobile-release-notice-compiled-*.log`, `D:/Codex/Temp/wixel-mobile-sheet-actions/`, `D:/Codex/Temp/wixel-sheet-state-storage/`에 있다. 배포 후 Git/Cloudflare 식별자와 공개 자산 바이트 검증은 `.local/ios-sheet-release.json`에 기록한다.

실제 iPhone 기기에서 OS 홈 화면 복귀가 없어졌는지는 이 환경에서 확인할 수 없다. 이번 결과를 iOS 종료 원인 확정 또는 전체 Excel 동등성 검수 완료로 해석하지 않는다.
