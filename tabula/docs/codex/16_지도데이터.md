# 16. 오프라인 국가·지역 지도 데이터

## 구현 범위

WIXEL의 `map`은 **국가·지역 단위 색칠지도**입니다. 첫 번째 항목 열의 한국어·영문 이름 또는 ISO 2자리/3자리 코드와 첫 번째 숫자 계열을 연결합니다. 예: `한국`, `KR`, `KOR`, `미국`, `US`, `USA`, `영국`, `GB`, `GBR`, `UK`.

- 같은 국가·지역으로 연결되는 여러 행은 합산합니다. 음수와 0을 유지하며, 빈 셀·문자열·오류를 0으로 바꾸지 않습니다.
- 국가명 연결 실패, 숫자가 아닌 값, 합계가 유한수 범위를 넘는 경우를 지도 아래에 표시합니다. 해당 안내의 툴팁에 항목 이름이 나옵니다.
- 여러 숫자 계열이 있으면 첫 계열을 사용한다는 안내를 표시합니다. 같은 지역의 합산값 툴팁에는 행 수를 표시합니다.
- 음수·양수가 함께 있으면 0을 중간색으로 삼는 색상을 사용합니다. 나머지는 최솟값~최댓값의 연속 색상을 사용합니다. 회색은 데이터 없음입니다.
- 작은 국가·지역의 점은 대략적 위치를 나타내며, 그 점의 크기가 실제 국토 면적을 나타내지는 않습니다.
- 지도 렌더링은 외부 지도 API, 위치 검색 API, 네트워크 요청이나 API 키를 사용하지 않습니다.

시·도/구·군, 우편번호, 주소, 임의 좌표 검색은 지원하지 않습니다. 205개 데이터 항목은 모든 ISO 국가·지역을 완전히 포함한다는 의미가 아닙니다. 목록 밖의 이름은 인식 실패로 표시합니다. Natural Earth 원본은 실제 통제 상태에 따른 경계를 사용하며, 해외 지역의 구분은 ISO 목록과 다를 수 있습니다. Excel의 온라인 지도 서비스와 같은 행정구역 검색 또는 동일한 지도 표현을 주장하지 않습니다.

## 출처와 이용 조건

Natural Earth는 지도 데이터를 public domain으로 공개하며 수정·전자 배포·상업적 사용을 허용합니다. 앱에는 출처를 계속 표시하고 원본 URL·버전·SHA-256을 생성 모듈에 기록합니다.

## 파생 데이터와 좌표

`src/chart-map-data.js`는 177개 경계와 37개 위치 점을 `ADM0_A3` 기준으로 합쳐 205개 국가·지역 항목으로 저장합니다. 경계는 Polygon/MultiPolygon 및 내부 구멍을 유지하며 SVG `fill-rule="evenodd"`로 그립니다. 경도+180, 90−위도의 등거리 원통 좌표를 사용하고 소수 둘째 자리로 반올림합니다. 이는 세계 개요도용 일반화 경계입니다.

- 파생 모듈: **180,441바이트**, gzip 기준 **62,678바이트**. 앱 빌드 시 함께 포함되므로 실행 중 다운로드가 필요하지 않습니다.
- 프랑스·노르웨이의 일부 원본 `ISO_A2/ISO_A3`는 `-99`이므로 `ISO_A2_EH/ISO_A3_EH`를 우선 사용합니다.
- 작은 지역 레코드의 상위 국가 코드가 기존 국가를 덮어쓰지 않게 합니다. 예를 들어 Ascension 레코드의 GBR 값으로 영국이 바뀌지 않습니다.
- 원본의 한국어·영문 이름을 포함하고, 이용 가능한 환경에서는 `Intl.DisplayNames` 이름을 보완합니다. 이름 충돌은 추측해 연결하지 않습니다. 코드와 명시적인 한국/미국/영국 별칭이 우선합니다.

재생성 명령은 `cd tabula && node tools/update-map-data.mjs`입니다. 이 개발 도구만 고정 원본을 내려받고 SHA-256을 계산합니다. 변경된 결과의 원본 해시·항목 수·지역 연결을 검토한 뒤 커밋해야 합니다. npm 의존성은 추가하지 않습니다.

## 모델·렌더 계약

- 타입: `type: 'map'`
- 데이터: `categories: string[]`, `series[0].values: (number|null)[]`
- 선택 색상: `mapLowColor`, `mapMidColor`, `mapHighColor` (`#RRGGBB`)
- `legend: 'none'`은 연속 색상 범례를 숨깁니다.
- `data-country`는 데이터 내부 지역 ID, `data-s`는 원래 계열 번호, `data-p`는 해당 지역에 합산된 첫 항목 번호입니다.
- 지도 합산과 이름 연결은 `mapValues`/`mapCountry`, 본문 렌더는 `MAP_CHARTS.map.draw(ctx)`에 분리되어 있습니다.

XLSX의 지도 데이터·차트 저장 호환 범위는 통합 차트 검증 문서에서 별도로 확인해야 합니다. 지도 데이터 모듈이 존재한다는 사실만으로 Excel에서 지도 차트가 같은 모양으로 열린다고 판단하지 않습니다.

## 검증

`node --test test/chart-map.test.js`에서 7개 테스트가 통과했습니다. 205개 항목의 모든 내부/ISO 코드 자기 연결, 한국어·영문 별칭, 중복 합계, 음수·0·결측, 합계 overflow, 작은 지역 점, SVG 경계·툴팁·범례·안내 및 HTML 이스케이프를 검사합니다.

브라우저 회귀 도구는 `node tools/chart-map.mjs`이며 `WIXEL_URL`, `PLAYWRIGHT_MODULE`, `PLAYWRIGHT_BROWSERS_PATH`를 받습니다. 앱을 불러온 뒤 브라우저를 오프라인으로 바꾸어 합성 데이터를 그립니다. `WIXEL_MAP_SCREENSHOT`으로 캡처 저장 경로를 지정할 수 있습니다. 실제 사용자 업무 파일은 사용하지 않습니다. source5180에서 브라우저 오프라인 상태로 18개 검사가 통과했고, 177개 경계·37개 점·실제 합산값·0과 결측의 구별·안내·범례 표시를 확인했습니다. 페이지 오류와 서버 쓰기는 0건입니다. 캡처는 `D:\Codex\Temp\wixel3-country-map.png`, 로그는 `.local/chart-map.log`입니다.

최종 Cloudflare 번들을 제공하는 로컬 주소 http://127.0.0.1:8787/에서도 19개 검사가 통과했습니다. 이 실행에는 낮은 값·중간 값·높은 값의 세 색상 옵션이 실제 SVG 국가 영역의 채움색에 적용되는 검사 1개를 추가했습니다. 오프라인 지도 경계 177개·위치 점 37개가 유지되었고 페이지 오류와 서버 쓰기는 0건입니다. 최종 로그는 .local/chart-map-final.log, 캡처는 D:\Codex\Temp\wixel3-country-map-final.png입니다.
