# 23. 리본 키팁과 셀 스타일 (2026-10-02)

## 수정한 동작

홈 탭의 셀 스타일·채우기 색·글꼴 색은 해당 갤러리나 팔레트를 연다. 글꼴 이름과 크기는 입력 칸으로 이동한다. 마지막 색을 적용하는 단추와 색을 고르는 화살표는 서로 다른 조작으로 등록한다. 기존 Alt 경로는 별칭으로 유지하고, 기존 `Alt → N → S → H`도 도형 목록을 열도록 연결했다.

`src/ribbon-keytips.js`가 `TABS`의 실제 조작 정의에서 등록표를 만든다. 일반 단추, 메뉴 전용 단추, 분할 단추의 두 동작, 입력 칸, 글꼴 목록, 체크박스, 대화상자 실행 단추, 리본 축소 단추를 포함한다. `app.js`의 실행·배지와 `ribbon.js`의 DOM 표시는 같은 `controlId`를 사용한다. 숨겨진 상황별 탭의 키가 다른 개체에 잘못 적용되지 않도록 활성 탭을 확인한다.

## 등록 범위

정적 등록표의 **297개 조작 모두에 대표 경로가 있다.** 기존 별칭을 포함한 경로는 **335개**이며, 경로 중복·실행 경로 간 접두어 충돌·누락된 조작은 0이다. 명령 및 입력 대상은 실제 `COMMANDS`, 메뉴 대상은 실제 `MENUS` 또는 `fn:` 함수 메뉴 분기로 확인했다. 이 검사는 이름과 연결의 검사이며 모든 기능의 계산 결과가 검증됐다는 뜻은 아니다.

각 탭의 리본 축소 단추 1개가 위 수에 포함된다. 파일 화면은 기존 `Alt → F`, 검색은 `Alt → Q`로 접근하며, 이 둘과 빠른 실행 도구 모음은 위 297개 리본 본문 조작 수에 포함하지 않는다. 현재 그림·도형의 상황별 리본은 공통 개체 서식 탭을 사용한다. 갤러리 내부의 개별 색·차트 스타일 견본은 갤러리 진입 뒤 키보드로 고르는 항목이며, 별도의 최상위 리본 경로로 세지 않는다.

## Excel 경로와 WIXEL 보충 경로

Microsoft 공식 문서는 Excel Windows의 홈·삽입·페이지 레이아웃·수식·데이터·검토·보기 탭, 파일·검색, `Alt → H → H` 채우기 색 경로를 설명한다. 문서의 키 표기는 미국식 키보드 기준이며 버전과 환경에 따라 화면·키가 다를 수 있다. [Microsoft Excel 바로 가기 키](https://support.microsoft.com/en-us/accessibility/excel/keyboard-shortcuts-in-excel)

| 경로 | WIXEL 동작 | 등록 근거 |
|---|---|---|
| Alt → H → H | 채우기 색 팔레트 | 공식 Excel 문서, `source: excel` |
| Alt → H → J | 셀 스타일 갤러리 | 사용자 요청 호환 경로, `source: user` |
| Alt → H → F → C | 글꼴 색 팔레트 | 사용자 요청 호환 경로, `source: user` |
| Alt → H → F → F | 글꼴 이름 입력 | 호환 경로, `source: user` |
| Alt → H → F → S | 글꼴 크기 입력 | 호환 경로, `source: user` |
| Alt → H → F → P | 서식 복사 | 호환 경로, `source: user` |
| Alt → H → F → G / K | 글꼴 확대 / 축소 | 이번 공식 자료에서 세부 경로 미확인, `source: wixel` |
| Alt → W → V → G | 눈금선 표시 전환 | 사용자 요청 호환 경로, `source: user` |
| 기존 등록 경로 | 기존 명령·메뉴 실행 | 유지한 별칭, `source: legacy` |
| 탭 키 → Z → 0 → 1 등 | 기존 경로가 없는 리본 조작 | WIXEL 보충 경로, `source: wixel` |

보충 경로는 두 자리 숫자를 사용하여 `Z1`이 `Z10`을 먼저 실행하는 문제를 피한다. 기존 경로와 충돌하면 다른 보충 접두어를 사용한다. 화면 배지에 표시된 글자를 순서대로 누른다. `J`는 상황별 탭으로 이어지는 기존 접두어로 유지한다. 도움말·상황별 탭의 전체 세부 경로까지 모든 Microsoft 365 버전과 같다고 주장하지 않는다.

색 팔레트는 방향키·Home/End로 이동하고 Enter/Space로 적용할 수 있다. 셀 스타일은 검색, 방향키 이동, 검색 결과 적용을 지원한다. 한글 입력 중 키팁 글자가 셀 편집 내용으로 들어가지 않도록 기존 IME 입력 차단과 연결한다. 메뉴를 여는 동작과 셀 값을 바꾸는 동작의 보호·읽기 전용 검사는 기존 실행 경로에서 유지한다.

## 보고서 셀 스타일 24개

`src/cell-style-presets.js`에 WIXEL 보고서용 스타일을 6개씩 네 구역으로 추가했다.

- 제목과 머리글: 보고서 네이비·인디고·청록, 머리글 블루·슬레이트·플럼
- KPI와 합계: KPI 블루·그린·퍼플, 합계 네이비·청록, 소계 스톤
- 입력과 계산: 입력 블루·민트·크림, 계산 슬레이트·라벤더, 참고 블루그레이
- 검토 상태: 검토 완료·진행·대기, 수정 필요, 검토 보류, 참고 사항

새 스타일은 글꼴·채우기·테두리만 적용한다. 값·수식, 숫자 표시 형식, 맞춤, 잠금과 수식 숨김은 유지한다. 기존 Excel 기본 스타일·테마·사용자 지정 스타일과 함께 표시하며 같은 이름의 저장된 정의를 우선한다. 적용한 스타일 이름과 포함 항목은 XLSX에 저장된다. 이 24개는 WIXEL의 보고서용 프리셋이며 Excel 기본 제공 스타일 추가분으로 설명하지 않는다.
