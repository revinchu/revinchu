# 112. 보고서 표와 차트 Excel 표시 (2026-10-15)

## 실제 파일 비교

사용자가 제공한 0527/0530 광고 보고서의 첫 번째 Total Summary, 두 번째 Schedule 시트를 비교했다. 원본은 수정하지 않고 D: 임시 사본을 사용했다. Excel의 별도 읽기 전용 COM 인스턴스에서 차트 PNG, 시트 PDF, 열 너비·행 높이·차트 좌표·축 정보를 추출하고, 로컬 위셀에서 같은 파일을 열어 PNG와 DOM 좌표를 수집했다. 업무 원본·파생 XLSX·이미지는 저장소 및 공개 서버에 올리지 않는다.

네이티브 화면 캡처 API는 시간 초과되어 사용하지 못했다. 아래 수치는 Excel 자체 차트 PNG 내보내기와 브라우저 캡처 비교이며 모든 운영체제에서의 화면 픽셀 일치를 뜻하지 않는다.

- 돋움 11pt의 최대 숫자 폭이 7px로 계산되어 보고서가 좁아졌다. Excel 측정값 9px를 열 너비 변환과 편집용 치수 계산에 적용했다. Schedule의 조사한 13개 열 너비는 Excel 값과 일치한다. 숨긴 열은 저장된 폭과 표시 폭을 구분한다.
- 첫 차트 폭은 Excel 569px, 수정 전 448px, 수정 후 568px. 두 번째 시트 차트 폭은 Excel 1,232px, 수정 전 964px, 수정 후 1,228px였다. PNG 정수 영역과 Excel 내보내기 배율, 셀 앵커 반올림이 포함된 측정이다.
- 원본의 기본/명시 gapWidth를 읽고 묶은 막대 간격을 개별 막대 너비 기준으로 계산한다. 범주 클러스터 전체에 간격을 곱해 막대가 지나치게 가늘어지던 오류를 수정했다.
- 날짜 축 종류와 sourceLinked 숫자 서식을 보존한다. 날짜 중간 줄바꿈 대신 필요 시 회전하며, 한국어 기본 날짜 구분자를 사용한다. 명시한 로캘, 따옴표·이스케이프 슬래시, 숫자 분수 서식은 구별한다.
- 단일 보조 계열의 자동 범위, 주·보조 축 눈금, 숨긴 선/눈금선, 개별 점의 레이블과 숨김, 범례의 실제 수동 상자 크기 및 항목 배치를 보정했다. 회계 서식의 빈칸은 축 여백 측정에서 제외한다.
- 수식 결과 `""`는 숫자 차트 계열에서 0으로 이어지고 실제 빈 셀은 기존 빈 셀 처리를 유지한다. 원본 셀 및 계열 이름 값은 변경하지 않는다.
- 빈 차트가 다른 차트 아래에 있는 원본 구성에서는 안내 문구를 그리지 않는다. 바깥 CSS 테두리가 SVG 테두리와 중복되지 않게 했다.

## 배율 전환 시 글자 잘림

85% 시트를 한 번 그린 다음 80% 시트로 이동하면 Chromium이 SVG 텍스트의 이전 페인트 배율을 재사용했다. DOM 좌표는 정상인데 PNG의 범례는 아래로 밀리고 보조 축은 잘렸다. SVG를 재삽입하면 해결되는 것으로 원인을 분리했다. `GridView.setZoom`에서 개체 DOM 캐시를 갱신하되 생성한 SVG 문자열 캐시는 유지한다. 시트 전환과 사용자 배율 조정에 함께 적용한다.

`tools/report-chart-fidelity.mjs`는 합성 31일 보고서를 사용한다. 먼저 다른 배율의 시트를 실제로 캡처한 뒤 전환하고, 각 날짜·보조 축·범례·개별 레이블의 DOM 범위 안에 글자 픽셀이 실제 존재하는지 확인한다. 원격 쓰기는 차단한다.

동일 검사에서 배율 캐시 수정만 제거하면 첫 80% 화면의 `0.00%` 레이블 영역에 글자 픽셀이 0개로 실패한다. 정상 DOM 좌표만 검사해서는 놓치는 오류를 회귀 검사로 고정했다.

## Excel 재저장 검증에서 발견한 수식 오류

수정 전 내보내기도 Excel의 정상 열기에 실패했다. 복구 로그는 Schedule의 수식/공유 수식 제거를 기록했다. 다른 시트를 참조하는 D/E/G 열 93개 수식이 공유 수식으로 바뀌면서 제거되었다. ASCII/한글 및 인용한 시트 이름의 최소 재현 파일 모두 같은 오류였고, 개별 수식으로 쓰면 복구 없이 열렸다.

`xlsx-shared-formulas.js`에서 다른 시트 참조가 있는 식을 공유 그룹에서 제외한다. 같은 시트의 반복 수식 최적화는 유지한다. 두 실제 파일을 다시 저장한 전체 XLSX가 이제 Excel의 일반 읽기 전용 열기에서 성공한다. 표준 차트 XML만 원본 패키지에 넣은 별도 검사도 통과했다. 브라우저에서 실제 통합 문서 테마를 적용한 Blob 저장 경로도 별도로 검사한다.
