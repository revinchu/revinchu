## 수정한 점

- 빌드 단위 테스트에서 URL의 `.pathname` 대신 `fileURLToPath()`를 써 Windows에서도 실행되게 했습니다.
- `check.mjs`·`pvcmp.mjs`는 입력과 실행 오류를 한국어로 알리고 종료 코드 2를 반환합니다. 비교 차이는 1입니다.
- `pvcmp.mjs`는 피벗이 사라지거나 출력 영역이 변한 경우도 차이로 보고합니다.
- 브라우저 검사 도구는 `finally`에서 브라우저를 닫고, 검출한 실패를 종료 코드에 반영합니다.
- 브라우저 도구는 `TABULA_STATIC=true`로 서버 보관 문서의 자동 복원·저장 영향을 차단합니다.
  단축키 검사의 초기 5개 실패는 이전 스모크 실행이 서버에 저장한 문서를 자동 복원하면서 발생했으며,
  격리 후 66개가 모두 통과했습니다. 실패 실행에서 종료 코드 1도 확인했습니다.
- 단축키의 한국어 숫자 서식 기대값을 교정하고, 메모 셀 선택과 목록 선택을 실제 조작으로 검증합니다.
- 첫 지시문에 후속 구현 범위·검증 기준을 명시하고 Windows/D: 안내, 의존성 설치·전후 비교 절차를 정리했습니다.

전달 폴더 `전달정보.txt`에 원격 커밋 확인 결과와 최종 상태를 기재합니다.
