# 86. 도형과 텍스트 상자 직접 편집

2026-10-05. 이전에는 도형의 F2·더블클릭·문자 입력이 서식 패널을 열었고, 홈 리본 글꼴 명령은 셀 서식을 참조했다. 도형 안의 글자를 직접 선택하고 수정하는 경로를 추가했다.

## 동작과 설계

- F2, 더블클릭, 우클릭 `텍스트 편집`으로 내부 편집을 시작한다. 도형 선택 상태에서 문자를 입력하면 기존 내용을 대체한다. 새 텍스트 상자를 그린 직후에도 입력한다. 선·그룹·SmartArt는 기존 전용 편집 경로를 유지한다.
- 마우스로 커서·글자 범위를 선택하고 Enter로 줄을 나눈다. Ctrl/Cmd+B·I·U, 홈 리본의 글꼴·크기·색·맞춤, Alt/F10 키팁을 같은 선택에 적용한다. 혼합 글꼴·크기는 리본에서 빈 값으로 표시한다.
- 내부 우클릭과 리본의 복사·잘라내기·붙여넣기는 선택 텍스트만 대상으로 한다. 붙여넣기는 일반 텍스트이며 현재 입력 서식을 사용한다. 권한 실패나 선택·초안·문서가 바뀐 뒤 도착한 클립보드 응답으로 다른 내용을 지우지 않는다.
- Esc·Tab·Ctrl/Cmd+Enter 또는 밖을 클릭하면 확정한다. Enter는 줄바꿈이다. 편집 중 Undo/Redo는 초안 내 기록, 종료 후 Workbook Undo는 전체 편집 1회를 되돌린다. 명시적 취소 API는 초안을 버린다.
- `shape-text-editor.js`는 문단/run과 DOM Range를 별도로 관리한다. IME 조합 중 DOM을 재생성하지 않고 완료 후 차이를 반영한다. Ctrl/Cmd+S·Shift+S는 조합 완료 후 저장 또는 다른 이름으로 저장한다.
- `app.js` 세션은 Workbook·docId·sheet·원본 shape identity와 보호 상태를 검증한다. `wb.transact`와 `setSheetProp('shapes')`로 한 번 기록한다. 문서 교체·삭제·외부 교체 시 오래된 초안을 폐기한다. 스크롤·배율·틀 고정·개체 회전 위치를 추적하고 원래 글자를 잠시 숨긴다. 모바일 키보드 설정도 적용한다.
- `shape-text-format.js`는 전체 도형 서식을 바꿔도 다른 run 속성과 문단을 유지한다. 실제 내용 변경에만 평문으로 전환한다. `view.js`는 run의 명시적 false를 부모 강조보다 우선하고 부모 밑줄을 각 run으로 옮겨 일부 글자의 해제가 가능하도록 한다.
- `xlsx.js`는 DrawingML 문단/목록 기본 글꼴, 명시적 b/i/u/strike 해제, 줄바꿈과 빈 문단 크기를 읽고 쓴다. WIXEL 메타데이터 없는 표준 XML 왕복도 검사한다.
