# 66. iPad·iPhone·Android의 일반 화면 배치에서 마우스 이동

2026-10-03. 기준 릴리스 `1854660eb866f1bb89dc22a875802cd074ba8b33`.

## 요청과 설계

모바일 최적화가 꺼져도 iPad·iPhone·Android에서는 모바일 작업 모드와 같은 메뉴 드래그와 손바닥 시트 이동을 제공한다.

`mobile-work.js`의 레이아웃 상태 `active`와 입력 기능 `pointerNavigation`을 분리했다. 후자는 모바일 최적화 ON이거나 Apple 터치 기기·Android일 때 활성화한다. iPadOS의 Mac 플랫폼 표기와 touch points도 기존 키보드에서 사용한 공통 `appleTouchDevice` 판정으로 인식한다. Android는 userAgent 또는 userAgentData의 플랫폼 표기로 인식한다. 기존 `appleTouchKeyboard` 이름을 기기 공통 의미로 바꿨으며 키보드 판정 내용은 동일하다.

- 초록 메뉴 탭, 리본, 아래쪽 빠른 실행 도구, 시트 탭: 기존 마우스 끌기와 휠 가로 이동을 재사용한다. 넘치지 않는 줄과 입력란의 기본 조작은 유지한다.
- 아래쪽 빠른 실행 도구는 모바일 기기의 일반 화면 배치에서 줄바꿈 대신 가로 스크롤을 제공한다. 버튼과 글자 크기는 축소하지 않는다.
- 상단 작업 도구와 손바닥 버튼을 모바일 최적화 OFF에서도 표시한다. 손바닥 버튼을 켜면 왼쪽 버튼으로 시트를 상하좌우 이동하고 다시 누르거나 Esc로 종료한다. 마우스 양쪽 버튼 이동도 같은 조건으로 허용한다.
- 모바일 기기에서 최적화를 ON→OFF해도 손바닥 도구 선택을 유지한다. 일반 데스크톱은 기존대로 OFF 시 손바닥 도구를 해제한다.
- 셀 선택/입력, 대화상자, 보호·실행 취소, 저장된 셀 서식·배율은 기존 경계를 유지한다. 손바닥 이동은 보기 조작이며 문서 쓰기 명령이 아니다.

## 검증

실제 iPad·iPhone·Android와 Bluetooth 마우스 하드웨어는 직접 검증하지 못했다. 브라우저에 전달된 실제 자동 마우스 입력과 Apple·Android 플랫폼 속성 모의로 기능·상태 보존을 검사한다. OS가 양버튼 입력을 앱에 전달하지 않는 기기에서는 명시적인 손바닥 버튼을 사용한다.
