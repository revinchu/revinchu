# 69. 차트 축 레이블 표시 개선

## 원인과 수정

기존 범주축은 최대 14자의 항목 길이를 전체 표시 간격 계산에 사용했다. 작은 차트나 보조축이 있는 콤보에서는 항목 6개 중 2~3개만 남고, 한글 실제 폭보다 작은 추정값 때문에 남은 이름도 겹쳤다. 가로 막대는 16자로 고정 축약하면서 왼쪽 여백은 최대 140px여서 글자가 차트 밖으로 잘릴 수 있었다.

- `chart-axis-labels.js`는 한글·영문 폭을 구분하고 단어 경계를 우선하여 줄바꿈한다. 자동 배치는 가로쓰기, 기울임, 세로 회전을 순서대로 검토한다. 필요한 경우 첫/마지막 항목의 여백과 아래쪽 높이를 확보한다.
- 표시 간격은 긴 이름 하나가 아니라 읽을 수 있는 최소 줄 높이에서 정한다. 공간이 부족하면 해당 이름만 말줄임하고 `aria-label`에 원문을 유지한다. 많은 항목이나 아주 작은 차트에서 모든 이름을 겹쳐 표시하도록 강제하지 않는다.
- 일반 막대·꺾은선·영역·콤보와 공통 직교축을 쓰는 폭포·히스토그램·파레토·상자수염·주식 차트가 같은 배치를 사용한다. 가로 막대는 실제 행 간격에 맞춰 이름을 줄바꿈하며 3D 깊이도 반영한다.
- 다단계 항목 축의 상위 그룹 이름은 새 레이블 높이 아래로 이동한다. 축 숨김, 데이터 표, 역순, 원본 데이터 및 개체 크기를 보존한다.

## 설정과 파일 연동

- 축 직접 선택과 전체 차트 서식 패널 모두 `레이블 간격 → 자동 / 간격 단위 지정` 및 `텍스트 방향 → 자동 / 사용자 지정 각도`를 제공한다. 간격 1은 모든 항목, 2는 한 항목씩 건너뛰기다. 각도는 -90~90°이다. 숫자 가로축에는 범주 간격 옵션을 노출하지 않는다.
- 모델: `axes.x.labelInterval` 양의 정수, `axes.x.labelRotation` SVG/OOXML 방향의 각도. `undefined`가 자동이고 명시적인 1과 0°를 자동값으로 치환하지 않는다.
- 일반 차트 XLSX는 표준 `c:tickLblSkip`, `c:txPr/a:bodyPr@rot`(각도×60000)으로 읽고 쓴다. 확장 정보를 제거한 XML에서도 설정 왕복을 검증한다. ChartEx는 기존 WIXEL 보완 확장으로 해당 값을 보존한다.
- 날짜 축의 제목·글꼴·명시 회전 읽기도 누락되지 않게 했다. 날짜축 눈금 단위 엔진, ChartEx의 해당 표준 속성 쓰기 전체 및 모든 Excel 레이아웃의 동일성을 구현했다고 보지 않는다.

## 검증 범위

검증 도구: `test/chart-axis-labels.test.js`, `test/chart-axis-xlsx.test.js`, `tools/chart-axis-labels.mjs`, `tools/chart-axis-settings.mjs`.

브라우저 검사는 합성 한글 광고 이름을 사용하여 실제 SVG 글자의 변환된 사각형, 글자 수, 겹침과 차트 경계 밖 잘림, 자동/수동 설정, Undo/Redo 및 파일 저장을 확인한다. 사용자 업무 파일은 사용하거나 커밋하지 않는다. 실제 Microsoft Excel 앱의 자동 배치 수치는 비공개이며 이 개선은 픽셀 단위 동등성을 주장하지 않는다.

공식 참고: [Microsoft 축 표시 변경](https://support.microsoft.com/en-us/office/change-the-display-of-chart-axes-422c97af-1483-4bad-a3db-3a9ef630b5a9), [Open XML TickLabelSkip](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.charts.ticklabelskip?view=openxml-3.0.1).
