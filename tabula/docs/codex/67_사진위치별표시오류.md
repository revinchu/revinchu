## 수정 설계

`pictureMarkup`이 HTML 요소에 참조하는 SVG 필터의 영역을 `objectBoundingBox`로 정의한다. 위치에 종속되지 않도록 기존 픽셀 여유를 각각 그림 너비·높이로 나눈 비율로 지정한다. `primitiveUnits`는 `userSpaceOnUse`로 유지하여 흐림·그림자 반경이 변하지 않게 한다. 같은 마크업을 쓰는 격자와 그림 서식 미리보기·스타일 견본에 함께 적용된다.

SVG·그룹·그림 내보내기 및 픽셀 보정용 SVG는 기존 SVG 좌표 영역을 유지한다. 원본, 자르기, 크기, 위치, 보정 설정, Undo와 XLSX 모델은 변경하지 않는다.

온라인 삽입의 사전 로드는 이미 `no-referrer`를 사용했으나 실제 그림 표시와 편집용 로드는 달랐다. Referer가 있는 요청만 거부하는 합성 서버에서 WebKit 사전 로드 성공 후 그림 표시 실패도 재현했다. 실제 이미지·원본 크기 조회·픽셀 편집 요청을 같은 정책으로 맞췄다. 픽셀 편집의 CORS 검사는 유지한다.

표준 좌표 의미: [filterUnits](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Attribute/filterUnits), [primitiveUnits](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Attribute/primitiveUnits). 브라우저 오류 판단 근거는 위셀 코드로 수행한 전후 픽셀 비교다.
