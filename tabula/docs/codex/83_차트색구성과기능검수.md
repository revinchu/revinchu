## 사용자 기능

- 차트 색 구성 21개를 유지하고 18개를 추가해 39개로 확장했다. 테마·보고서·선명·파스텔·짙은·단색·대비의 7분류, 이름과 색 견본, 검색을 제공한다.
- 리본·차트 옆 색 버튼·요소 서식·차트 전체 서식에서 같은 색 변경 경로를 사용한다.
- 사용자 지정 색 편집은 1~32색 HEX 입력, 색 선택, 추가·삭제·순서 이동·역순·여러 색 붙여넣기·실제 차트 미리보기를 제공한다. 잘못된 입력은 적용하지 않는다. 취소는 문서를 변경하지 않으며 적용은 한 번의 실행 취소로 복원한다.
- 기존 문서의 팔레트 ID와 테마 연동, 32색을 초과하는 가져온 팔레트는 보존한다. 편집기의 새 입력 한도와 파일 렌더링 범위를 혼동하지 않는다.
- 작은 화면에서는 미리보기를 아래에 배치하고, 색 행의 자동 접근키 문구를 생략한다. Tab 탐색과 각 버튼의 접근성 이름은 유지한다.

처음 Excel 파일을 여는 단계에서는 저장된 피벗 항목 순서를 유지한다. 사용자 명령과 초기 불러오기를 구분한다. 피벗 공유 캐시 인덱스를 재작성하지 않고, 개별 피벗 항목 순서만 기록한다. 자동 정렬에서 일부 항목만 포함한 오래된 순서는 렌더러와 동일하게 처리한다.

정렬 후 필터는 기존 `recomputeFilter`를 재사용한다. 지원하지 않는 가져온 Excel 필터 조건이 있으면 기존 보호 동작을 유지하며, 잘못된 숨김 상태로 정렬을 확정하지 않는다. 복합·색·가로·부분 정렬을 기존 단일 열 정렬 속성으로 잘못 저장하지 않도록 오래된 단일 열 정렬 표시를 지운다.

## 설계와 검증 경계

UI → 공용 변경 패치 → `wb.transact` / `setSheetProp` → 렌더러 → 표준 XLSX 저장·재열기 순서로 확인한다. 팔레트 목록/검증은 `chart-palette-options.js`, 편집 UI는 `chart-palette-ui.js`, 정렬 범위/필터 갱신은 `sort-filter-state.js`, 피벗 명시 정렬 패치는 `pivot-sort-state.js`에 둔다. 차트 저장은 `chartModelData(..., {sample:false})`로 원본 순서 전체 캐시를 만들고, 범위 레이아웃 판정에서 이미 읽은 행을 재사용한다. 전체 행/열 참조의 빈 꼬리는 사용 범위와 동적 배열 범위로 제한하고 XML 참조는 유지한다. npm 의존성은 추가하지 않았다.

새 회귀 도구:

- `tools/chart-palette-upgrade.mjs`: 색 선택 경로, 검색·분류, 사용자 편집, 입력 검증, 취소/Undo/Redo, 보호, 문서 전환, 모바일.
- `tools/functional-options-audit.mjs`: 방사형 실제 SVG와 snapshot 계열/범주 필터, 비연속 계열 번호.
- `tools/functional-data-options.mjs`: 정렬 후 필터, 표 슬라이서 조건과 원본 시트, 3,000행 차트 원본·표준 XLSX.
- `tools/pivot-sort-options-ui.mjs`: 가져온 피벗 정렬과 사용자 지정 목록 옵션의 실제 메뉴 동작.

검사는 새 브라우저 컨텍스트의 합성 문서를 사용하고 API 및 외부 쓰기를 차단한다. 실제 업무 파일은 로컬 읽기와 메모리 내 왕복 검사만 수행하며 원본 크기·수정 시간·SHA256 보존을 확인한다. 사용자 파일을 GitHub나 공개 서버에 업로드하지 않는다.

이 기록은 전체 Excel 기능의 완전한 동등성이나 모든 파일·기기에서의 무오류를 뜻하지 않는다. Chromium·Firefox·WebKit 자동화는 실제 iPad/iPhone Safari와 Bluetooth 입력 장치 검증을 대신하지 않는다. 리본 명령 일괄 검사는 예외/시작 실패 검사이며 각 명령의 모든 기능을 증명하지 않는다. 원형·도넛 테두리의 추가 감사도 실제 UI 실패 재현 후 이번 수정에 포함했다.

피벗 표준 속성 근거: [Microsoft Open XML customListSort](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.pivottabledefinition.customlistsort).

공통 메뉴·대화상자 진입 시 셀/행/열 선택·채우기·이동 드래그를 취소한다. 포인터 취소, 창 포커스 이탈, 버튼이 눌리지 않은 이동도 정리한다. 드래그 완료 함수를 호출하지 않아 테두리 그리기·채우기·링크 열기를 실수로 확정하지 않는다. 우클릭 명령·미니 서식·채우기/글꼴/무늬 팔레트는 처음 선택과 불연속 선택을 캡처한다. 늦은 기본 색 선택기 응답에는 문서·시트 동일성과 현재 편집 보호를 다시 확인한다. 모바일 손 이동은 메뉴가 열린 동안 격자 입력을 시작하지 않는다.
