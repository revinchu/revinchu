# 26. 온라인 그림 검색

## 구현 범위

`삽입 → 그림 → 온라인 그림...`과 `온라인 그림을 셀에 배치...`에서 Openverse(Flickr·박물관 등), Wikimedia Commons, iNaturalist, NASA를 개별 또는 함께 검색합니다. **Creative Commons만은 기본 해제**입니다. 검색 카드에 제목·사이트·라이선스·`출처 보기`를 표시하며, 다음 페이지와 여러 그림 선택을 지원합니다. 썸네일과 삽입용 원본 주소를 구분합니다. 별도 API 키와 npm 의존성은 추가하지 않았습니다.

- **CC 해제:** 제공 사이트에 라이선스 제한을 추가하지 않습니다. Openverse 자체는 CC·공공영역 중심이며, 인터넷 전체 검색이나 자유로운 재사용을 뜻하지 않습니다.
- **CC 체크:** 개별 사진의 CC BY 계열 6종 및 CC0만 허용합니다. URL이 있으면 Creative Commons 공식 호스트·경로도 검사합니다. PDM, 일반 Public domain, GFDL, 미확인 라이선스와 NASA 자체 조건은 제외하며 NASA에는 요청하지 않습니다. CC BY-NC·BY-ND도 포함하므로 상업적 이용 가능 여부는 원문에서 확인해야 합니다.
- iNaturalist는 관찰 기록이 아닌 **사진별 라이선스**를 검사합니다. `q`는 생물 이름·태그·설명·장소 검색입니다. 실제 `고양이`는 Felis catus, 임의 문자열은 0건이었습니다. `moon`의 줄나비고기는 공식 별칭 `New-moon Coral-fish`에 일치합니다.
- 검색어를 지운 상태에서 CC/사이트를 바꾸면 이전 카드와 선택을 비웁니다. 요청 취소·순서 검사로 늦은 응답이 최신 결과를 덮지 않게 합니다. 일부 사이트 실패는 나머지 결과와 함께 표시합니다.

## 외부 서비스의 제한

Openverse 익명 요청은 `page_size=20`을 사용합니다. Commons는 이미지 MIME과 파일 라이선스를 확인하고, iNaturalist는 공식 이미지 호스트의 사진 ID 경로에만 원본 크기 규칙을 적용합니다. NASA는 canonical → 큰 alternate → preview 순으로 원본 주소를 고릅니다. 인증이 필요한 Flickr 직접 API·Unsplash·Europeana를 연동했다고 표시하지 않습니다.

검색 API의 CORS와 그림 원본 다운로드는 별개입니다. 실제 NASA 검색 API는 CORS를 허용했지만 확인한 이미지 원본에는 허용 헤더가 없어 브라우저 `fetch`가 실패했습니다. 이런 그림은 웹 연결로 삽입되어 XLSX 안에 이미지가 포함되지 않을 수 있음을 UI에 안내합니다. 외부 주소 만료·접근 제한과 라이선스 메타데이터 정확성도 제공처에 의존합니다. 한국어 결과는 사이트별로 다르며, NASA의 `달`은 0건이었지만 `moon`은 결과가 있었습니다.
