# 31. 도형 버튼과 하이퍼링크 (2026-10-02)

## 수정한 문제

엑셀 보고서의 ‘바로가기’, ‘맨위로’ 버튼은 매크로가 아닌 DrawingML 도형 하이퍼링크였다. `cNvPr/a:hlinkClick`과 drawing relationships에 저장된 목적지를 가져오지 않아 클릭해도 이동하지 않았다. 이제 도형·연결선·그림·그룹의 링크 주소, 화면 설명, action 값을 읽고 표준 XLSX로 다시 저장한다. 표준 근거: [Microsoft Open XML HyperlinkOnClick](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.hyperlinkonclick?view=openxml-3.0.1).

## 사용 방법

- 링크가 있는 버튼·그림을 클릭하거나 모바일에서 한 번 탭하면 목적지 시트·셀로 이동한다.
- Ctrl+클릭으로 개체를 선택하면 이동·크기·서식을 편집할 수 있다. 선택 상태에서 Ctrl+Enter는 링크 열기, Ctrl+K는 링크 편집이다.
- 우클릭 메뉴의 하이퍼링크 삽입/편집/제거를 사용할 수 있고, 변경은 실행 취소할 수 있다.
- 공백·작은따옴표가 있는 시트명, 셀 범위·전체 행/열, 정적으로 정의된 이름을 해석한다. 링크 이동은 수식을 실행하거나 문서 내용을 변경하지 않는다.
- 시트 이름 변경과 행·열 삽입/삭제 시 내부 링크를 함께 갱신한다. 외부 웹 주소는 유지한다.
- 끌기 동작은 링크를 열지 않는다. 보호·읽기 전용 상태에서도 탐색은 가능하며 개체 변경은 기존 보호 규칙을 따른다.

## 실제 파일 검증

제공된 두 원본은 로컬의 격리 브라우저에서만 읽었다. 원본과 사용자 브라우저 탭을 수정하지 않았고 서버로 업로드하지 않았다. 파일명·내용·링크의 업무상 목적지는 저장소에 포함하지 않는다.

| 항목 | 두 파일 합계 |
|---|---:|
| 원본 XML의 도형 링크 | 70 |
| 가져온 링크 / XLSX 왕복 보존 | 70 / 70 |
| 존재하는 표시 시트로 정상 이동 | 30 |
| 원본에 목적지 시트가 없어 오류 안내 | 36 |
| 원본에서 목적지 시트가 숨김이어서 안내 | 4 |

70개 중 50개는 원본의 숨김 시트에 놓인 버튼으로, 검사할 때 보기만 전환하여 링크를 확인했다. 평소 표시되는 시트의 버튼 20개 중 18개는 정상 이동하며, 2개는 원본부터 목적지가 없다.

없는 시트를 임의로 만들거나 비슷한 이름으로 연결하지 않는다. 숨겨진 시트도 자동으로 노출하지 않는다. 끊어진 링크는 우클릭에서 올바른 주소로 고칠 수 있다. 원본에 실제 시트 12개와 외부 수식 캐시용 숨김 시트 17개가 있어 읽기 후 시트 모델은 29개이며, 이는 이번 변경으로 생긴 추가 시트가 아니다.

## 구현

- `hyperlink.js`: 문서 내부 주소의 읽기 전용 해석, 정적 이름·퍼센트 인코딩·순환 참조 검사, 구조 변경 시 주소 재작성.
- `xlsx.js`, `smartart-xlsx.js`: `obj.hyperlink` 읽기/쓰기, relationship 원문 보존, 링크 변경을 포함하는 그룹 메타데이터 무결성 검사.
- `app.js`, `view.js`, `object-group.js`: 클릭·터치·우클릭·키보드 동작과 그룹 자식별 링크.
- `workbook.js`: 내부 링크 구조 변경과 실행 취소.

## 검증과 범위

전체 Node 검사 702개 통과. 합성 단위 검사에는 도형·그림·연결선·그룹의 표준 XLSX 왕복, 외부에서 바뀐 그룹 링크의 반영, 내부 주소 해석과 구조 변경·Undo를 포함한다. 브라우저 합성 링크 검사 소스·Cloudflare 번들 각각 14/14 통과(누름 후 Esc 취소, 전체 행·열 선택, # 생략 내부 주소·그룹 자식·같은 시트 이동 후 개체 선택 해제 포함). 기존 그룹 6/6, 모바일 터치 10/10, 단축키 114/114, 리본 명령 324개 오류 0. 단일 HTML·Cloudflare 빌드 모두 성공했다.

실제 두 파일의 수정 전후 `check.mjs`는 각각 수식 차이 0, 왕복 차이 0이다(수식 698개/639개). `pvcmp.mjs`는 두 파일 모두 피벗 0개이므로 피벗 호환성 검증으로 계산하지 않는다. 소스와 Cloudflare 번들에서 링크 70개 클릭·원본 해시 불변·페이지 오류 0·원격 쓰기 0을 확인했다.

별도 숨김 Excel 16.0(build 14334) 인스턴스에서 합성 도형·연결선·그림·그룹의 내부 링크 6개/외부 링크 1개를 정상 열기·주소 검사·별도 파일 재저장했다. Excel 재저장본의 WIXEL 재읽기에서도 7개 주소 유지, 가져오기 경고 0이었다. 외부 링크를 실제로 열거나 매크로를 실행하지 않았다.

이번 지원은 XLSX DrawingML의 개체 클릭 링크다. VBA·ActiveX 실행, XLS/XLSB의 도형 링크, 도형 텍스트 일부에만 연결된 링크, 외부 통합 문서 열기, 수식으로 계산되는 이름 목적지를 완전히 구현했다는 의미는 아니다. 외부 URL은 기존 프로토콜 검사를 통과한 경우에만 격리된 새 창으로 연다. 실제 기기 전체와 모든 엑셀 파일에 대한 보장은 아니다.
