# WIXEL 3.0 구현과 검증

작업 브랜치: `codex/wixel-3-cloudflare`
기준: `codex/wixel-quality-improvements`의 `e7fa630`
작업 경로: `D:\위셀\wixel-3` (기존 `D:\Codex\Workspaces\wixel` 보존)

이 문서는 이번 변경의 범위와 검증 기록입니다. 기존 인계에 적힌 실사용 파일 수와 테스트 수를 이번 검증 결과로 재사용하지 않습니다. 전체 Excel 기능과 픽셀 단위의 동일성을 보장하는 구현은 아닙니다.

## 사용자 작업

- 새 문서의 기본 가로 맞춤은 가운데입니다. 가져온 Excel의 일반 맞춤과 명시된 맞춤은 유지합니다.
- Ctrl+Space는 활성 열을 선택합니다. 행 전체 선택 뒤 Ctrl+Space를 눌렀을 때 시트 전체가 선택되던 오류를 고쳤습니다. 일반 다중 셀 선택에서는 해당 열 범위를 유지합니다.
- 파일 화면에서 새 문서, 최근 문서, 파일 열기, 서식, 공개 Google Sheets 연결과 저장 위치를 선택합니다.
- 브라우저 보관, Excel 다운로드, 지원 브라우저의 원본 파일 저장, Node 서버 저장, Cloudflare 개인 보관함을 구분합니다.
- 빠른 실행 도구 모음의 리본 위/아래 위치와 명령 순서를 지정하고 Alt+1~9, Alt+09~01 순서의 키팁을 사용합니다. 피벗 필드의 이동·집계·키보드 조작과 셀 서식 탭·맞춤 미리보기를 보강했습니다.
- 개인 보관함은 사용자가 명시적으로 연결합니다. 사이트를 열거나 파일을 가져온 것만으로 업무 문서를 온라인에 전송하지 않습니다.

## 계산과 Google Sheets

`IMPORTRANGE("공개 시트 URL 또는 ID","시트명!A1:C10")` 형식으로 공개/게시된 Google Sheets CSV를 읽습니다. 공유 URL의 gid, 시트 이름, A1 범위를 처리하며 HTML 로그인/오류 페이지를 셀 값으로 오인하지 않습니다. 외부 데이터 캐시와 새로 고침을 지원합니다. 이름으로 다른 WIXEL 개인 문서를 읽는 참조는 기본 차단하며 데이터 › 문서 참조 권한에서 현재 세션에만 허용할 수 있습니다. 공개 읽기 전용 문서에는 이 권한을 주지 않습니다.

QUERY는 혼합 자료형과 null 비교, 집계·피벗의 열 순서, label, format 및 잘못된 구문 판정을 보강했습니다. format을 적용해도 숫자를 문자열로 바꾸지 않고 결과 범위의 표시 형식으로 전달합니다. 자세한 지원 구문은 함수 설명과 `test/google-query.test.js`를 참고하세요.

실제 공개 Google Sheets의 IMPORTRANGE가 Node 서버와 로컬 Cloudflare workerd 프록시에서 정상 CSV를 가져오는 것을 확인했습니다. 로그인 전용 Google Sheets에 접근하는 Google OAuth 앱은 포함하지 않습니다. QUERY의 전체 Google Visualization/ICU 문법이 완전히 동일하다는 의미도 아닙니다.

## 차트와 도형

세로/가로 막대의 묶은·누적·100% 누적, 원형/쪼개진 원형, 영역의 일반·누적·100% 누적, 꺾은선 등 3D 하위 종류 12개를 추가했습니다. SVG의 깊이 면, 원형의 측면, 회전·깊이·원근 옵션을 제공합니다. 3D 차트를 표준 bar3DChart, pie3DChart, area3DChart, line3DChart와 view3D로 저장하고 WIXEL 확장을 제거한 XLSX도 다시 읽는 검사를 추가했습니다.

차트 서식은 차트 옵션, 채우기 및 선, 텍스트 및 범례, 3차원 회전으로 나눕니다. 연속해서 축·계열 옵션을 바꿀 때 이전 값이 사라지는 문제, 100% 누적의 단일 계열·음수 값 축, 원형 요소 색 저장을 수정했습니다. 도형 서식은 채우기/선, 효과, 크기/위치, 텍스트 옵션을 직접 조정하고 실행 취소합니다.

도형의 그라데이션과 중지점 투명도, 채우기/선 투명도, 그림자, 네온, 부드러운 가장자리, 글꼴, 굵게/기울임/밑줄, 여백과 줄 바꿈을 표준 DrawingML로 읽고 저장합니다. 차트 제목의 크기·색·굵기도 표준 XML에 기록합니다.

브라우저의 3D 표현은 투영 렌더러이며 Excel의 모든 카메라·재질·조명·곡면 차트와 동일한 엔진은 아닙니다. 기존 신형 통계 차트 중 일부는 Excel 저장 시 호환 차트와 WIXEL 확장을 사용합니다. 경로형 그라데이션은 선형 대체 경고가 있으며, 실제 Excel 365에서 열어 복구 메시지가 없는지 확인하는 수동 검증은 아직 별도입니다.

## 인터넷 저장

Cloudflare Workers의 정적 자산과 SQLite Durable Objects를 사용합니다. API 계약과 한도는 [cloudflare/API_CONTRACT.md](../../cloudflare/API_CONTRACT.md)에 있습니다.

- 복구키마다 개인 보관함을 분리합니다. 키는 브라우저에서 생성하고 요청 헤더에만 실어 보내며 URL·문서·서버 로그에 넣지 않습니다.
- 문서 버전(If-Match)을 확인하므로 다른 기기의 저장을 조용히 덮어쓰지 않습니다.
- 읽기 전용 공유는 별도 게시 사본입니다. 전체 통합 문서를 선택하면 숨김 시트도 포함합니다. 시트 하나를 선택하면 해당 시트의 계산값과 표시 차트만 고정해 내보내고 다른 시트·이름·매크로·피벗 원본 캐시를 제외합니다. 실제 셀/분산 결과 25만 개까지 지원하며 피벗 재분석·슬라이서·스파크라인·조건부 서식 막대/아이콘은 제외됩니다.
- 다른 기기에서도 같은 복구키로 게시 목록을 보고 링크를 복사하거나 게시를 중지할 수 있습니다.
- 문서당 20MiB, 개인 문서 50개·합계 100MiB입니다. 게시물은 별도 20개까지이며 각각 20MiB입니다.
- 키를 잃으면 이메일로 복구하는 기능은 없습니다. 복구키를 안전하게 별도 보관해야 합니다.
- 서버 저장은 종단간 암호화가 아닙니다. 실시간 다중 사용자 공동 편집 대신 버전 충돌 보호를 제공합니다.
- IP/보관함 요청 제한은 있지만 전 세계 합산 비용 상한이나 회원 가입 기반 남용 차단을 보장하지 않습니다.

## 운영 CPU 검증 범위

[Workers 공식 제한](https://developers.cloudflare.com/workers/platform/limits/)의 일반 무료 Worker HTTP CPU 한도는 10ms이고, [SQLite Durable Object 제한](https://developers.cloudflare.com/durable-objects/platform/limits/)은 DO 요청당 기본 30초를 별도로 명시합니다. 큰 문서의 JSON 검증·청크 복사·SQLite 저장은 DO에서 수행하며 Worker는 인증·라우팅과 스트림 전달을 담당합니다.

로컬 workerd에서 정확히 20MiB를 저장하고 내려받아 SHA-256 일치를 확인했지만, 이는 실제 Cloudflare 계정의 CPU·무료 한도 검증은 아닙니다. 같은 저장 코드의 로컬 Node CPU 참고치는 긴 문자열 203ms, 60만 셀 구조 437ms였습니다. 운영 배포 후 합성 1/5/20MiB 문서를 순서대로 확인하고 Metrics의 1102/exceededCpu를 점검해야 합니다. 현 단계에서 유료 플랜으로 변경하거나 문서 한도를 자동 축소하지 않았습니다. 상세 CSP·요청 제한·로그 점검은 [배포 전 독립 점검](../../cloudflare/DEPLOYMENT_REVIEW.md)에 기록했습니다.


## 문서 렌더링 방어

HTML/SVG 삽입 경로는 허용 목록 정제 후 DOM 조각으로 옮깁니다. 가져온 차트의 서식 문자열로 이벤트 속성을 주입한 재현은 실행 1회에서 0회로 바뀌었습니다. 브라우저 CSP를 우회한 테스트에서도 정제가 차단하는지 별도로 확인했습니다. Cloudflare 빌드는 외부 해시 스크립트와 엄격한 스크립트 CSP를 사용합니다. 이는 전체 보안 감사나 모든 공격에 대한 보장을 뜻하지 않습니다.
