# 브라우저 행·열 삽입과 삭제 단축키

사용자 요청에 따라 행·열/셀 구조 명령을 브라우저 확대·축소 조합과 구분했다.

| 키 | 동작 |
|---|---|
| Ctrl+Shift++ (주 키보드 Ctrl+Shift+=) | 선택한 행·열 삽입; 셀 선택은 삽입 옵션 |
| Ctrl+Shift+- | 선택한 행·열 삭제; 셀 선택은 삭제 옵션 |
| Ctrl+= / Ctrl+- (Shift 없이) | 브라우저 화면 확대·축소 |
| Ctrl+숫자패드 + / - (Shift 없이) | 브라우저 화면 확대·축소 |
| Ctrl+Shift+숫자패드 + / - | 행·열/셀 삽입·삭제 |
| Ctrl+Alt+= / Ctrl+Alt+- (Shift 없이) | 기존 위셀 시트 배율 변경 |
| Alt → H → B → N | 테두리 없음 |

주 키보드의 +와 =는 같은 물리 키다. Shift 포함 여부로 삽입과 브라우저 확대를 구분한다. Ctrl+Shift+-가 기존 테두리 없음으로 빠지던 경로와 Shift 없는 Ctrl+-가 삭제로 처리되던 경로를 제거했다. 새 순수 `browserStructureCommand`는 Ctrl/Meta+Shift와 허용한 물리 키만 판정한다. 편집·실제 조합·IME Process/229·AltGr·native 입력·대화상자·메뉴·선택한 개체는 구조 명령을 실행하지 않는다. 리본과 빠른 실행 버튼의 초점은 해당 컨트롤 키 처리 뒤 버블 단계에서 격자로 연결한다.

기존 `insertMenuKey`/`deleteMenuKey`를 사용하여 행/열 선택 수·셀 밀기 옵션·복사한 행 삽입·F4 반복·Undo/Redo와 시트 보호를 유지한다. 워크시트 탭의 추가/삭제 명령은 이번 요청의 행·열 삽입/삭제와 별개이며 키를 바꾸지 않았다. 리본 툴팁·단축키 도움말·새로운 기능 및 기존 키 감사 도구도 같은 조합을 사용한다.
