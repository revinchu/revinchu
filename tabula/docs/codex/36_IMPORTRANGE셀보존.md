# 36. IMPORTRANGE 셀 위치와 표시 보존

2026-10-02

## 확인한 문제와 변경

기존 Google Visualization CSV(`gviz/tq`)는 한 열의 대표 자료형을 추론하면서 문자·숫자가 섞인 열의 일부 값을 빈칸으로 바꾼다. 제목과 빈 행도 응답에서 생략되어 이후 셀의 위치가 달라질 수 있다. 일반 공유 문서는 시트 CSV 내보내기(`/export?format=csv&range=...`)로 변경했다. CSV 파서는 쉼표 구분을 명시하며 따옴표·셀 안의 줄바꿈·앞뒤 공백·0·FALSE·중간 빈 행과 열을 유지한다.

Google IMPORTRANGE는 두 번째 인수에 시트 이름이 없으면 **첫 번째 탭**을 읽는다. 문서 URL의 `gid`는 이 선택을 바꾸지 않는다. 일반 공유 URL과 문서 ID에서는 `gid`를 생략한다. 특정 탭은 `"'매출 현황'!A1:Z1000"`처럼 이름을 지정한다. `/htmlview` 탭 목록의 이름과 gid를 확인한 뒤 내보내기에 적용하며, 없는 이름을 첫 탭으로 대체하지 않는다. 게시된 `/d/e/.../pub` URL은 WIXEL 확장으로, 명시한 gid를 계속 지원한다.

CSV 내보내기는 마지막 빈 행을 생략할 수 있다. `A1:Z1000`처럼 끝이 정해진 범위는 빈칸으로 채워 요청한 크기를 유지한다. `A:C`, `A1:C`처럼 열린 범위는 받은 행 수를 따른다. 게시 CSV는 전체 응답을 한 번만 잘라 적용하며, 일반 내보내기 결과는 다시 자르지 않는다. 요청 전과 최종 배열 생성 전에 100만 셀 제한을 검사한다.

금액의 쉼표·소수 자릿수·백분율은 셀별 `Range.cellFormats` 표시 힌트로 전달한다. 숫자는 문자열로 굳히지 않아 SUM·참조·QUERY에서 계산할 수 있다. 열이 좁으면 표시를 축소하며, 명시한 셀·행·열·시트 숫자 서식과 축소 해제는 사용자 설정을 우선한다. QUERY의 기존 `format` 절은 기존 우선순위를 유지한다. 1셀 가져오기에서도 힌트를 잃지 않는다. 새로 고침·결과 축소·수식 삭제 시 이전 힌트를 제거한다.

분산 배열의 자식 셀은 `raw`가 없어도 값을 가진다. 격자 텍스트 넘침 판단에 실제 값을 사용하여 제목이 옆의 숫자·0·FALSE를 덮지 않도록 수정했다. 일반 셀의 명시적 축소 표시도 숫자에서 적용한다.

XLSX 저장에는 힌트가 반영된 표준 숫자 서식을 기록한다. 사용자가 선택한 일반 서식과 `shrinkToFit="0"`을 구별해 다시 읽으며, 서식을 따로 지정하지 않은 셀에 일반 서식을 새로 추가하지 않는다.

## 안전성과 범위

- 탭 목록은 제한된 문자열 문법만 데이터로 해석한다. 내려받은 JavaScript는 실행하지 않는다. HTTPS·호스트·문서 ID·탭 번호 일치와 중복을 검사한다.
- 일반 주소의 자격 증명을 거부하고 임의 쿼리·해시를 내보내기 주소에 복사하지 않는다. 기존 문서별 외부 데이터 허용과 서버 요청 제한을 유지한다.
- 로그인 화면·HTML 오류 응답은 셀 데이터로 가져오지 않는다. 비공개 Google 문서용 OAuth 기능을 추가한 변경은 아니다.
- CSV는 원본의 전체 셀 서식·색·글꼴·병합·열 너비·날짜 자료형을 전달하지 않는다. 표시된 숫자의 원본보다 높은 정밀도나 사용자 지정 숫자 서식 전체도 복원할 수 없다. 숫자처럼 보이는 텍스트와 로캘별 표기는 추가 호환 작업이 필요하다. 이 변경은 CSV가 제공하는 셀 배치와 통상적인 숫자 표시를 보존한다.
- 이름 정의·표 참조는 지원하지 않으며 오류로 안내한다. Google 내보내기·htmlview 형식이 바뀌면 재검증이 필요하다. 탭 목록을 확인할 수 없을 때 임의 탭을 가져오지 않는다.

## 검증

- `test/import-range-fidelity.test.js`: 혼합형 셀·제목·빈 행/열·CSV 인용·게시 범위·유한 범위 보정·크기 제한.
- `test/google-sheet-tabs.test.js`: 정확한 탭 이름, 이스케이프, URL/문서/gid 검증, 중복·누락·비정상 응답.
- `test/import-range-format.test.js`: 숫자값·SUM·QUERY·명시 서식·실행 취소·갱신·1셀·XLSX 왕복.
- `tools/importrange-fidelity.mjs`: 합성 응답으로 첫 탭/명시 탭/게시 주소, 분산 위치, 표시, 다시 계산, 오류와 좁은 열 넘침을 검사한다. 공개 서버에서도 업무 자료 전송 없이 실행할 수 있다.
- 사용자 제공 수식의 실제 응답은 저장소 밖 D: 임시 경로에서만 비교했다. 원본 데이터·문서 ID·캡처를 테스트나 배포 산출물에 포함하지 않는다.
