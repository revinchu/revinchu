## 변경

- 전체 내용이 유효한 두 연월일로 구성된 기간은 화면에서만 셀 너비에 맞춰 축소한다. 셀 원본, 수식, 저장 글꼴 크기와 열 너비는 바꾸지 않는다. 일반 문장과 제목에는 적용하지 않는다.
- 명시적인 축소 맞춤에는 옆 셀 넘침을 허용하지 않는다. 들여쓰기, 아이콘과 필터 단추의 여백을 실제 가용 너비에서 뺀다. 작은 크기의 글꼴 측정을 다시 확인해 소수 반올림 오차를 줄인다.
- 격자에 `text-size-adjust:100%`를 적용한다. 지원하는 Safari의 자동 텍스트 확대가 셀 측정과 달라지는 것을 방지하며 시트 배율과 브라우저 확대는 유지한다.
- 줄바꿈, 회전, 선택 영역 가운데 정렬, 일반 텍스트의 빈 셀 넘침은 기존 설정을 따른다.
