# 00. 시작하기 — WIXEL(위셀) 인수인계 (Claude Code → OpenAI Codex)

## 한 줄 요약
엑셀 한국어판과 같은 화면 · 단축키 · 계산 결과를 내는 **의존성 0 의 브라우저 스프레드시트**.
xlsx/xlsm/xlsb/xls/ods/csv 를 열고 xlsx/xlsm 로 저장하며, 피벗 · 슬라이서 · 차트 · 조건부 서식 · 표 · 동적 배열 수식(523개 함수)까지
엑셀 파일의 저장값과 맞춰 왔습니다. 퍼포먼스 마케팅(광고 리포트) 기능과 템플릿 58종이 들어 있습니다.

## 5분 안에 돌려 보기
```bash
git clone <저장소> && cd revinchu/tabula
git checkout claude/offsro-excel-implementation-zmro3r
node -v            # 18 이상 (22 권장)
npm test           # 176 pass
npm start          # http://localhost:5178 접속 → 파일 › 새로 만들기 에서 템플릿 열어 보기
```
브라우저 콘솔에서 `window.tabula` 로 내부에 접근할 수 있습니다 (테스트 스크립트가 사용):
`tabula.wb()`(통합 문서), `tabula.run('명령')`, `tabula.selectCell(r,c)`, `tabula.selectRange(rg,'cells',active)`,
`tabula.switchSheet(i)`, `tabula.commands()`(명령 목록), `tabula.menus()`, `tabula.gv()`(격자 뷰), `tabula.sel`, `tabula.si`, `tabula.active`, `tabula.chartSel`, `tabula.exportXlsx`, `tabula.templates`.

## 작업 방식 (지금까지 지켜 온 것)
1. 엑셀 동작을 정답으로 봅니다. 애매하면 "한국어판 엑셀 365에서 어떻게 보이는가"로 결정합니다.
2. 계산 · 파일 형식 로직은 DOM 없는 모듈에 두고 Node 테스트로 고정합니다. `app.js` 에는 UI 연결만.
3. 사용자 실제 파일로 수정 전/후 비교(`tools/`)를 돌려 나빠진 파일이 없을 때만 커밋합니다.
4. 기능을 하나 마칠 때마다: 테스트 → 스모크 → `CLAUDE.md` 노트 한 줄 → `WHATS_NEW` → 커밋 · 푸시 → 빌드.
5. 커밋 메시지는 영어 요약 + 목록 (기존 로그 형식 참고: `git log --oneline`).
