# 28. 모바일 작업 모드

## 사용

- 제목줄 맨 왼쪽 휴대전화 아이콘으로 모바일 작업 모드를 켜거나 끕니다. 좁은 화면과 터치 태블릿은 자동으로 감지합니다. 선택은 이 브라우저에 기억됩니다.
- 옆 ☰ 버튼은 화면 맞춤·배율·셀 편집·전체 메뉴 탭·저장·공유·인쇄·설정·빠른 실행 도구를 모은 모바일 작업 도구입니다. 리본과 시트 탭은 좌우로 스크롤합니다.
- 셀 한 번 누르기는 선택, 두 번 누르기는 편집, 길게 누른 뒤 끌기는 범위 선택, 두 손가락 벌리기/오므리기는 시트 확대/축소입니다. 행·열 머리글 선택, 확인란, 서식 복사와 기존 보호 규칙을 유지합니다.
- 화면 높이가 작으면 리본을 한 줄로 펼치며, 소프트키보드가 화면을 줄이면 도구 영역을 잠시 접어 입력 공간을 확보합니다. 대화상자는 화면 안에 맞추고 본문을 스크롤하며, 하위 메뉴에는 이전 메뉴 버튼을 제공합니다. 파일·최근 문서·서식·저장 화면도 상단 탐색과 한 열 본문으로 재배치합니다.
- 자동 화면 맞춤과 모바일에서 지정한 배율은 기기의 보기 상태에만 적용됩니다. 원본 시트의 저장 배율은 바뀌지 않으며 데스크톱 모드로 돌아가면 원래 배율이 복원됩니다.

## 구현

`src/mobile-work.js`(기기 설정·viewport), `src/mobile-tools-ui.js`(모바일 도구), `src/mobile-grid.js`(DOM 독립 제스처 상태 머신), `styles.css`의 모바일 전용 규칙. `app.js`와 `view.js`는 기존 명령·보호·선택·편집 경로를 연결합니다. `ui.js`는 visualViewport 경계에 메뉴를 재배치합니다. 새 런타임 의존성은 없습니다.

## 검증

- 전체 Node 테스트 649개, 기존 명령 스모크 324개 오류 0, 기존 키보드 114개 통과. 두 빌드와 Cloudflare 배포 사전 검사 통과. 모바일 모드 7개·터치 10개·팝업 26개는 소스와 배포용 번들에서 모두 통과했습니다.
- `tools/mobile-work-mode.mjs`: 자동/수동 모드, 설정 기억, 전체 기본 탭 이동, 검색·서식·편집·배율, 원본 배율 보존, 키보드 viewport, 회전·태블릿·데스크톱 회귀 7개.
- `tools/mobile-touch.mjs`: 실제 Chromium 터치 이벤트와 CDP로 탭/두 번 탭, 스크롤, 범위, 핀치, Undo, 확인란, 서식 복사, 보호/읽기 전용, 필터, 문서 교체/취소 10개.
- `tools/mobile-popups.mjs`: 320px/390px에서 셀 서식·찾기·필터·차트·피벗·표·선택하여 붙여넣기와 키보드 viewport 축소/이동, 파일 메뉴 및 인쇄/PDF 다운로드 26개.
- `tools/mobile-layout.mjs`: 320×568, 360×740, 390×844, 768×1024, 844×390, 568×320에서 전체 15개 리본 탭의 90개 배치, 실제 앱 5개 화면 × 8개 탭 및 키보드 통합 검사.
- 모든 브라우저 검사는 새 격리 컨텍스트와 합성 문서로 실행합니다. 실제 사용자 문서나 열려 있는 작업 화면은 조작하지 않습니다.

## 실제 기기 검증 범위

Chromium 모바일 화면·터치 에뮬레이션과 visualViewport 축소 모의 검증입니다. 실제 iOS Safari/Android 키보드·브라우저 바·관성 스크롤의 하드웨어 검증은 남아 있습니다. 차트/그림/도형의 정밀 터치 드래그와 채우기 핸들의 모바일 전용 조작은 이번 변경에 포함하지 않았으며, 해당 기능은 기존 메뉴·서식 창에서 접근합니다. 휴대전화의 파일 저장 위치 선택 등은 브라우저가 제공하는 기능 범위를 따릅니다.
