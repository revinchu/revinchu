# 42. 인쇄 영역과 페이지 나누기 미리 보기

## 문제와 동작

인쇄 영역 모델은 있었지만 격자에는 표시하지 않았고, 파일의 저장된 `sheetView.view` 또는 BIFF 보기 플래그를 버렸습니다. Excel에서 페이지 나누기 미리 보기로 저장한 문서를 열어도 기본 화면으로 보이던 원인입니다.

- 보기 리본 및 상태 표시줄의 기본/페이지 나누기 미리 보기 전환.
- 인쇄 영역 밖의 셀·개체를 회색으로 덮고, 파란 바깥 경계·자동 점선·수동 실선·페이지 번호 표시. 확대/스크롤/틀 고정/숨김과 같은 축 좌표 사용.
- 페이지 레이아웃 → 인쇄 영역 설정/추가/해제. 새 영역 설정은 사용자 요청에 따라 즉시 미리 보기로 전환합니다. 파일 열기는 저장된 모드를 따릅니다. 기본 보기로 저장된 문서는 인쇄 영역이 있어도 기본 보기를 유지합니다.
- 파란 인쇄 영역 경계 드래그, 페이지 나누기 삽입/이동/제거/모두 원래대로. 자동 맞춤에서는 수동 나누기를 무시하며, 사용자가 수동 나누기를 삽입/드래그하면 자동 맞춤을 해제하고 안내합니다.
- 페이지 설정의 쉼표로 나눈 복수 영역, 전체행/열, 반복 행/열, 아래/오른쪽 우선 쪽 순서. 일반 유한 영역은 선택한 빈 셀까지 보존합니다.
- XLSX 정의된 이름과 sheetView, XLS WINDOW2/PLV, XLSB XLView에서 보기·영역·나누기를 복원합니다. XLSX 내보내기는 표준 속성으로 저장합니다.

## 구조

`print-layout.js`는 축의 누적 위치와 이분 탐색으로 페이지를 계산하고 개별 셀 전체를 순회하지 않습니다. `view.js`의 각 고정 창에는 화면 크기의 SVG만 생성합니다. 인쇄는 영역별 테이블과 동일한 페이지 계획으로 페이지를 구성하여 화면과 출력이 다른 경계 계산을 사용하지 않습니다. `print-area-edit.js`는 이웃 사각형 확장 및 드래그 범위를 처리합니다.

인쇄 설정·보기는 계산 중립 시트 속성으로 변경하며 undo/redo를 보존합니다. 행·열 삽입/삭제 시 복수 영역과 수동 나누기도 함께 이동합니다.

## 검증

- 전체 Node 단위 853/853 통과. 인쇄영역 합치기/끌기, 공통 페이지 계획, 삽입·삭제 Undo/Redo, 표준 파일 I/O 포함.
- 최종 배포 번들의 브라우저 화면·조작 18개 통과: 회색 실제 픽셀, 확대10%(렌더러)/25~400%(UI), 틀 고정·숨김·스크롤, 복수영역, 모바일320/390, 경계 끌기·취소, 시트전환 중 드래그 취소 및 원자적 Undo.
- 최종 배포 번들의 페이지 설정 대화상자 6개 통과: 복수영역·따옴표 시트명·전체열·반복행열·유효성검사·취소·보기 좌표 보존.
- 최종 배포 번들의 실제 출력 8개 통과: 복수영역 페이지 순서·반복행열·숨김·병합·개체·HTML 본문·4쪽 PDF·여백·고정 행 높이와 큰 글꼴. 페이지 계획과 출력 본문을 대조.
- Excel 16.0 합성 XLSX/XLS/XLSB, 보기3종에서 가져오기/위셀 저장/재읽기 108개 검증. Excel에서 위셀 산출물3종을 다시 열고 SaveAs 후 9시트의 보기·두 인쇄영역·반복제목·수동 나누기 보존 확인. Excel 재저장 파일의 재읽기54검사도 통과.
- 실제 `언론보도_매체리스트_.xls`: 파일Input으로 열 때 페이지 나누기 미리 보기·영역 자동복원, 원본 SHA 동일. 인쇄 맞춤·여백 누락 수정으로 출력4쪽→Excel과 같은3쪽. 283셀의 값+서식,132행 높이,4열 너비는 원본과 동일.
- 기존 업무 파일2개 읽기 전용 회귀: 쿠첸 정산8,545개 수식, 헬로우트래블698개 수식. 이전 대비 수식 불일치0→0, 저장·재열기문제0→0. 두 파일에 피벗0개여서 실제피벗 계산을 검증한 것은 아님.
- 리본 명령344개 스모크 오류0. 업무 파일과 생성된 업무 데이터는 커밋하지 않음.

## 한계와 판정 기준

- Excel의 페이지 나누기 미리 보기에서 회색 표시를 제공한다는 기준은 [Microsoft 인쇄 영역 안내](https://support.microsoft.com/en-us/excel/set-or-clear-a-print-area-on-a-worksheet)를 따릅니다. 기본 보기와 페이지 레이아웃 보기의 전체 화면 구현을 동일한 기능이라고 주장하지 않습니다.
- 프린터 장치별 인쇄 가능 여백·드라이버 글꼴 측정·모든 문서의 픽셀 단위 일치까지 검증한 것은 아닙니다. 실제 XLS에서 Excel 자동 경계는 46·90행 앞, 위셀은 46·91행 앞으로 두 번째 경계에 1행 차이가 남습니다(행·열 크기와 지정 여백은 동일). 따라서 100% 인쇄 동등성을 달성했다고 주장하지 않으며 원본 치수를 임의 보정하지 않았습니다.
- 인쇄 안전 한도(2,000쪽, 영역 128개, 출력 생성 20,000행·200열·500,000셀, 직접 이미지 PDF150쪽·HTML300쪽)를 초과하면 일부를 잘라 출력하지 않고 설정 조정을 안내합니다.
- 일반적으로 사용되는 인쇄 영역은 고정 A1 참조입니다. 계산식으로 동적으로 정해지는 정의된 인쇄 영역은 별도 호환성 범위입니다.

수동 나누기는 전체 행/열 경계로 모델링합니다. OOXML brk의 일부 열/행에만 적용되는 min/max span 전체 보존은 별도 호환성 범위입니다.
