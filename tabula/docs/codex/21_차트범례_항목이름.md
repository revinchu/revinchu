# 21. 차트 범례와 피벗 항목 이름 (2026-10-02)

## 원인과 수정

피벗의 숫자 열만 선택한 뒤 일반 원형/3차원 원형을 만들면 선택한 숫자 범위만 차트에 저장됐다. 범주 참조가 없어 범례에 항목 이름 대신 `1`, `2`가 나왔다. 피벗 차트 전용 명령이나 이름 열까지 포함한 선택에서는 같은 문제가 재현되지 않았다.

별도로 렌더러는 계열이 하나인 막대/꺾은선 차트의 범례를 무조건 숨겼다. 범례 위치를 명시해도 나타나지 않았다. 범례 없음 설정을 제외하고 항목이 있으면 표시하도록 고쳤다. 특수 차트의 기본 숨김 정책은 유지한다. 짧은 3자리 배경색의 대비 계산과 긴 범례 이름의 전체 이름 툴팁도 보강했다.

`chart-source.js`의 `inferPivotCategorySeries`는 실제 피벗 정의와 결과 메타데이터로 선택한 수치 계열과 항목 열을 연결한다. 선택한 값 범위를 다른 지표나 이웃 행으로 확장하지 않는다. 피벗 안의 연속된 항목을 확인할 수 있을 때만 참조를 만든다. 일반 숫자 표나 명시적인 차트 계열, 산점도 등에서는 이웃 셀을 임의의 범례 이름으로 추측하지 않는다.

새 차트에는 연결된 범주/값 참조를 저장한다. 기존 위셀의 해당 숫자 범위 차트는 표시할 때 원래 모델을 변경하지 않고 이름 참조를 보완한다. Excel 저장에도 같은 참조를 적용해 화면의 범례와 표준 차트 XML이 일치하도록 한다. 원형 차트 제목은 두 번째 열 고정값 대신 실제 수치 계열의 이름으로 만든다.

## 검증 방법

- `test/chart-legend.test.js`: 단일 계열의 기본/네 위치/없음, 특수 차트 정책, 3D 원형 항목/색, 대비, 긴 이름/이스케이프.
- `test/chart-source.test.js`: 피벗 숫자 선택의 항목 참조, 선택 값 보존, 추론 제외 조건, 모델 불변 및 XLSX 왕복.
- `tools/chart-legend.mjs`: 실제 일반 차트/갤러리/피벗 차트 생성, 미리보기와 확정 범례, 이전 범위 차트, 지표 선택/제목, Undo.
- 합성 피벗 XLSX를 새 숨김 Excel 인스턴스에서 일반 열기로 열고 원형 계열의 항목 이름과 값을 검사한다. 사용자 업무 파일이나 기존 Excel 세션은 사용하지 않는다.

## 검증 결과

- 전체 단위 테스트 **484/484**, 일반/Cloudflare 빌드 성공.
- 신규 범례 렌더 6개, 피벗 범주 연결 11개 테스트 통과(전체 수치에 포함).
- 브라우저 범례 회귀 **10/10**, 소스/배포용 번들 각각 페이지 오류·원격 쓰기 0.
- 기존 차트 편집 회귀 **8/8**, 리본 스모크 **307개 명령, bad 0**.
- 실제 Excel 합성 XLSX **2/2** 정상 열기: 기존 숫자 범위 차트와 새 참조 차트 모두 3D 원형, 범례 표시, 항목 이름 `광고 세트 A/B`, 값 `879/5379` 일치. 표준 SERIES 수식도 `Report!A2:A3` 항목/`Report!B2:B3` 값 참조를 유지했다. 비활성 시트의 Excel 문자열 차트 캐시는 지연 계산되므로 합성 보고서 시트를 활성화한 뒤 검사했으며 파일은 수정하지 않았다.

## 범위

알려진 피벗 메타데이터가 없는 일반 숫자 범위에는 이름을 자동 추측하지 않는다. 항목 이름 열을 함께 선택하거나 차트의 데이터 선택에서 항목 축 레이블을 지정해야 한다. 불연속 부분합을 끼운 범위나 여러 값 필드를 행에 배치한 피벗 등 안전하게 연속 참조를 만들 수 없는 경우도 이번 자동 보완에서 제외한다. 이 수정은 모든 파일·차트·피벗 조합의 동등성 보장을 뜻하지 않는다.
