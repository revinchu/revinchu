# 피벗 필터 검색과 선택

2026-10-02~03. 기준 `d1fb161`, 브랜치 `codex/pivot-filter-parity`. 사용자 승인 범위: GitHub 저장 및 기존 Cloudflare 공개 앱 업데이트.

## 구현과 선택 계약

- 행·열 필터는 오름/내림차순, 기타 정렬 옵션, 현재 필드 필터 해제, 레이블 14조건·값 8조건·상위/하위 필터, 날짜 필드의 날짜 조건을 제공한다. 기존 조건 동작을 실제 메뉴에서 점검하고 접근키, 메뉴 계층, 검색창·지우기·목록·확인/취소의 배치를 보강했다.
- 검색하면 목록 상단에 `(모든 검색 결과 선택)`과 `필터에 현재 선택한 내용 추가`를 표시한다. 추가 체크의 기본값은 꺼짐이다. 꺼진 상태로 확인하면 검색 중 선택한 항목으로 교체하고, 켜면 검색 전 체크 선택과 검색 결과 선택의 합집합을 적용한다. 원래 일부 선택이 겹치는 경우에도 이 합집합 계약을 사용한다.
- 검색 시작 시 일치 항목을 모두 선택한다. 검색어를 좁힐 때 사용자가 해제한 항목을 다시 켜지 않는다. 검색어를 지우면 검색 전 체크 선택으로 돌아간다. 확인 전까지는 임시 상태이며 취소는 문서를 변경하지 않는다.
- 검색은 대소문자를 구분하지 않는 부분 일치이며 `*`, `?`, `~` 이스케이프를 지원한다. 원시 값과 표시 문자열을 각각 검색하여 두 문자열 사이에서 생기는 잘못된 일치를 방지한다. 빈 항목은 피벗 목록에 `(비어 있음)`으로 표시한다.
- 검색 결과가 없거나 체크가 0개이면 확인을 비활성화한다. 추가 체크가 켜져 있어도 빈 검색을 원래 선택으로 적용하지 않는다. 상위/하위 항목 수에는 양의 정수, 백분율에는 0 초과 100 이하를 요구한다.
- 방향키/Home/End로 메뉴와 항목을 이동하며 오른쪽/왼쪽 키로 하위 메뉴에 들어가고 돌아온다. 검색창의 자동 초점은 동기적으로 처리하여 뒤늦은 예약 초점이 사용자의 메뉴 이동을 덮어쓰지 않는다. Enter는 현재 필터를 적용하고 Escape는 취소한다. 한글 조합 Enter와 keyCode 229는 적용으로 처리하지 않는다.
- 보고서 필터는 단일 선택 목록과 여러 항목 선택을 구분한다. 단일 목록은 방향키·Home/End·Enter·두 번 클릭을 지원한다. 검색으로 선택 항목이 숨겨지면 표시된 항목을 명시적으로 선택하기 전까지 확인할 수 없다.
- 목록은 보이는 구간만 DOM으로 만든다. 보호/읽기 전용 및 메뉴를 연 뒤 통합 문서·시트·피벗 대상이 바뀐 경우를 적용 시 다시 확인한다. 적용은 기존 피벗 트랜잭션과 Undo/Redo를 사용한다.

## 파일 보존

`pivot.js`의 `pivotPageMulti(def, field)`와 정규화된 `pageMulti[field]`가 여러 항목 선택 모드를 항목 수와 독립적으로 보존한다. 이전 JSON에 명시 값이 없으면 기존 항목 수 기반 동작을 사용한다.

XLSX는 표준 `pivotField@multipleItemSelectionAllowed`를 읽고 쓴다. 다중 모드에서는 `pageField@item`을 생략하며 단일 모드의 한 항목 선택에만 기록한다. 따라서 다중 모드에서 한 항목만 남기거나 전체를 선택해도 파일 저장·재열기에서 모드가 바뀌지 않는다. 이번 신규 속성 파싱은 XLSX에 적용하며 XLS/XLSB 파서를 확장하지 않았다.

## 검증

- Node 전체 952개 통과. 신규 선택 모델 10개 및 표준 피벗 모드 왕복 9개를 포함한다.
- 소스와 최종 Cloudflare 번들의 피벗 UI 회귀는 각각 29/29 시나리오·181검사를 통과했다. `tools/pivot-filter-menu.mjs`로 검사하며 최종 번들 키보드 반복 20/20·140검사도 통과했다. 검색 대체/추가, 행·열·보고서 필터, 검색 지우기·0개 선택·빈 결과, 조건 14/8개 연결, 상위 필터 검증, 키보드·조합 Enter, 단일/다중 선택, Undo/Redo, 보호·대상 변경, 320/390px 화면을 포함한다.
- 공통 필터 성능: 5만 항목, 20검사 통과, 목록 체크 DOM 24개. 소스와 번들에서 일반 필터 UI 8/8, 페이지 오류와 원격 쓰기 0.
- 최종 번들 명령 스모크는 379개 명령에서 오류 0건이다. 결과와 공개 배포 식별자는 무시 경로 `.local/pivot-filter-release.json`에 기록한다.
- 실제 Excel 16.0 build 14334에서 다중 한 항목/여러 항목/전체와 단일 한 항목/전체의 합성 XLSX 5종을 정상 열기·저장했다. `EnableMultiplePageItems` 및 WIXEL 재읽기에서 모드를 유지하며 OpenXML SDK 스키마 오류 0건이다.
- 사용자 업무 원본 2개는 이전 릴리스와 비교하여 수식 8,545개/698개 모두 불일치 0→0, 왕복 문제 0→0이다. 파일 SHA-256은 동일하다. 이 두 파일에는 피벗이 없어 피벗 검증 실적으로 세지 않으며 피벗 모드는 위 별도 합성 파일로 확인했다.

테스트는 격리 브라우저와 합성 문서를 사용하고 외부 요청·원격 문서 쓰기를 차단한다. 실제 업무 파일·캡처·검사 출력은 커밋하지 않는다. 한글 검사는 합성 조합 이벤트이며 실제 운영체제 IME 자동화가 아니다. 이번 캡처에 해당하는 동작과 명시된 회귀를 검증했으며 모든 Excel 파일과 모든 화면의 100% 동등성을 입증한 것은 아니다.
