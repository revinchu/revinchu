# 그림과 SVG 저장 (2026-10-03)

## 사용자 동작

- 사진·도형·아이콘 우클릭 → **그림으로 저장**. PNG와 JPEG를 선택한다.
- 도형·SVG 아이콘 우클릭 또는 **셰이프 형식 / 그림 형식 → 저장 → SVG로 저장**. 벡터 선과 글자를 SVG로 저장한다. 일반 사진에는 SVG 저장을 제공하지 않는다.
- 셀 범위 우클릭 → **선택 영역을 그림으로 저장**. PNG·JPEG·SVG를 선택한다. 홈의 **복사 화살표**에서도 접근한다.
- 여러 사진·도형을 선택하면 현재 배치와 쌓임 순서를 하나의 그림으로 저장한다. 기존 그룹과 SmartArt도 지원한다.
- 공통 미리보기에서 파일 이름·형식·배경·1/2/3배 해상도를 고른다. JPEG는 흰 배경이며, 셀 범위는 눈금선을 켜거나 끌 수 있다.

## 구현 계약

`object-image-export.js`는 기존 그림/도형/그룹 렌더러를 공유하고 회전·자르기·대칭·효과의 바깥 여백을 포함한다. `prepareImageSvg`는 외부 이미지를 명시적인 resolver로 포함하고 스크립트·이벤트·외부 참조를 거부하여 독립 SVG를 만든다. 안전한 SVG 아이콘은 내부 경로를 중첩 SVG로 펼치고 식별자를 분리하여 여러 아이콘의 그라데이션·잘라내기 참조가 충돌하지 않게 한다. SVG는 HTML `foreignObject`를 사용하지 않는다.

`range-image-export.js`는 화면 배율·스크롤과 독립적으로 행 높이·열 너비, 숨긴/필터 행·열, 병합, 숫자 표시, 셀·표·조건부 서식, 테두리, 줄바꿈·정렬·회전·체크박스·셀 그림을 출력한다. 부분 병합은 선택 범위로 자르고 굵은 테두리를 위해 사방 2px를 둔다. 수식·피벗 결과와 조건부 서식 계산은 출력용 캐시에서 처리하므로 원본 값·분산·계산 캐시·Undo를 변경하지 않는다.

`image-export-ui.js`는 같은 SVG를 미리보기와 파일 출력에 사용한다. 저장 파일 선택은 클릭 직후에 열어 브라우저의 사용자 동작 권한을 유지한다. 문서·시트·선택·버전을 준비 전후와 파일 쓰기 직전에 검사한다. 취소·권한 거절·쓰기 실패를 성공으로 표시하지 않으며, 파일 선택기 미지원 환경에서는 기존 다운로드 확인 흐름을 사용한다.

## 지원 범위와 제한

- 범위 저장은 연속된 사각형 셀 범위를 지원한다. 이동 옵션 등으로 선택한 비연속 셀은 중간 셀을 잘못 포함하지 않도록 안내 후 차단한다. 범위 저장은 셀 내용과 서식만 담는다. 떠 있는 차트·사진·슬라이서는 함께 담지 않는다. 사진·도형은 개체를 선택해 별도로 저장한다.
- 래스터 출력은 한 변 4,096px 및 총 1,600만 픽셀 이내다. SVG 한 변은 65,536px 이내이며 범위는 보이는 20,000행·2,000열·100,000셀까지다. 초과 시 자르거나 축소하지 않고 오류를 표시한다.
- SVG 글꼴은 파일에 포함하지 않으므로 다른 컴퓨터의 글꼴에 따라 배치가 달라질 수 있다. 도형 텍스트 줄바꿈은 기존 그룹 SVG 렌더러를 공유한다. 화면과 모든 글꼴 조합의 픽셀 일치를 보장하지 않는다.
- 셀 내부 일부 글자의 개별 서식은 기존 셀 모델처럼 보존하지 않는다. 셀 윗주 표시는 원문만 저장하며 미리보기에 안내한다. 영상은 재생 영상이 아닌 표시 이미지가 저장된다.
- XLSX/XLS 입출력과 수식 계산 규칙은 변경하지 않았다. 사용자 업무 파일은 검사·커밋에 사용하지 않았다.
