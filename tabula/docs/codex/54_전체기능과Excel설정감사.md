# 54. 전체 기능과 Excel 설정 감사

2026-10-03. 기준 커밋 `4d93d789cbc655db37cc67b8670ce477f1670ed3`. 사용자 요청은 메뉴·옵션이 실제 동작하는지, Excel 설정을 가져오고 재저장하는지, 직접 생성/가져오기 결과가 다른지 확인하고 수정하는 것이다.

## 검사 방법과 범위

- 등록 명령, 리본 컨트롤, 메뉴 및 키팁의 연결을 목록화한다. 존재 검사는 동작 검사를 대체하지 않는다.
- 기존 기능별 도구를 전체 목록으로 만들고 새 브라우저 프로필·합성 문서에서 실행한다. 클릭 이후 모델/화면 결과, 취소, 보호, Undo, 저장을 검사하는 도구와 단순 열기 검사를 구분한다.
- 실제 Excel 16.0의 **별도 숨김 인스턴스**에서 합성 파일을 만든다. 사용자가 열어 둔 Excel 세션을 조작하지 않는다. XLSX/XLSB의 표준 속성과 Wixel 모델/화면을 대조하고 다시 저장한 파일을 확인한다.
- 기존 업무 파일은 읽기 전용 검증에만 사용하고 SHA-256 불변을 확인한다. 사용자 문서, 셀 내용, 캡처는 저장소에 포함하지 않는다.
- 외부 서비스/API에 대한 실제 쓰기를 차단한다. 모의 API 검사는 실서비스 계정·쿼터·공유 권한 검증으로 세지 않는다.

이 문서는 검증한 기능과 미지원/미검증 영역을 구분한다. **Excel 100% 동등성, 모든 파일의 무손실 변환, 모든 기능 조합의 무결함을 인증하지 않는다.** 과거 문서의 테스트 숫자를 이번 실행 결과로 재사용하지 않는다.

## 직접 생성과 가져오기

피벗 보고서 필터의 기존 수정 경로를 다시 검사했다. 보고서 필터 15시나리오/147검사, 표시 옵션 8/226, 필터 검색·선택·조건 메뉴 29/181, 합계 52시나리오/554검사가 통과했다. 직접 생성/가져오기, 행·열 배치와 필터 전용 피벗, 검색 결과 선택 추가, 취소/Undo, 문서 변경 후 적용 차단을 포함한다.

피벗 값 표시의 독립 Excel 오라클은 오류/공란/숫자/0을 섞은 120설정이다. Excel 생성 원본을 WIXEL에서 읽기 및 WIXEL→XLSX→WIXEL로 재저장/읽기를 합친 240피벗/960값 차이는 0이다. 피벗 재저장본 120개를 실제 Excel에서 다시 계산한 결과를 뜻하지 않는다. 전체 임의 피벗 정의의 보장은 아니다.

실제 Excel 합성 `native.xlsx`/`native.xlsb`는 수동 계산, 저장 전 계산 끔, 반복 설정 77회·0.0025, 표시 정밀도, 머리글 숨김/수식 표시, 눈금선 색 #003366, 2행·1열 틀 고정, 75% 배율, 숨김 행/열, 가로 인쇄·85%, 정수 유효성 및 구조/시트 보호를 포함한다. 실제 파일의 100,000회 SHA-512 해시를 UI에서 확인하여 구조와 시트 보호를 각각 해제했다. 반복 계산/표시 정밀도는 실행 미지원 안내를 확인한 것이며, 계산 동등성으로 세지 않는다.

구형 Excel `.xls` 합성 파일은 8개 제한 유형을 포함한 유효성 규칙 10개, 3개 오류 스타일, 목록 이름, IME 설정, 상대참조 및 시트 보호 권한을 같은 원본의 XLSX와 대조했다. XLS→WIXEL→XLSX 결과를 별도 Excel에서 정상 열기, 규칙 10개 재확인, 잘못된 암호 거절·정상 암호 해제 및 재저장까지 확인했다. 바이너리 형식 자체로 다시 저장한 결과는 아니다.

기존 업무 파일 2개는 수식 8,545개와 698개(합계 9,243개)에서 수정 전/후 값 차이와 WIXEL XLSX 재저장 차이가 모두 0이었다. 두 원본의 SHA-256은 불변이다. 해당 업무 파일에는 피벗이 없으므로 실제 피벗 검증 수에는 합산하지 않았다.

| 파일 형식 | 이번에 검증·보강한 설정 | 범위 |
|---|---|---|
| XLSX | 계산 속성, 시트 보기·눈금선 색, 인쇄 눈금선, 통합 문서/시트 보호, 유효성 | 표준 XML 판독·저장, UI, 실제 Excel 재열기 |
| XLSB | 계산 속성, 보호 해시/권한, 인쇄·머리글/바닥글, 선택 셀, 유효성 | 바이너리 읽기 후 공통 모델 및 XLSX 저장, 실제 Excel 재열기 |
| XLS | 계산·보기, 시트 보호/권한, 유효성 유형·연산자·메시지·상대참조 | BIFF 읽기 및 XLSX 저장, 실제 Excel 재열기. FILEPASS 암호화는 미지원 |
| ODS/FODS | 숨김 행/열·시트 및 기본 셀/서식 왕복 | ODF 보호는 명시적 거부. 유효성·계산·필터·고급 인쇄/보기 미지원 설정은 발견 시 경고 |

## 남은 차이와 미검증

- 임의 눈금선 RGB는 WIXEL에서 원색을 유지하지만 Excel에서는 64색 기본 팔레트의 최근접색으로 표시된다. Excel 자체도 `GridlineColor` 입력을 팔레트로 양자화하는 것을 합성 COM으로 확인했다.
- 구형 XLS의 필터·피벗·차트 설정은 아직 복원하지 못한다. 해석하지 못한 구형 수식은 경고 후 결과값으로 가져오므로 XLSX에서의 원문 보존과 구분해야 한다.
- 공통 인쇄 모델은 6종 용지·여백·방향·배율/맞춤·인쇄 순서·영역/반복 제목·수동 나누기·일반 머리글/바닥글을 처리한다. DPI·매수·흑백·초안·오류 인쇄·첫쪽 번호·짝수/첫쪽 머리글 등 고급 옵션은 보존되지 않는다.
- ODS의 숨김 행 100,000개 초과는 현재 모델 한도로 명시적으로 가져오기를 거부한다. 마지막 행 하나만 숨긴 희소 문서는 빈 간격을 반복행으로 압축해 왕복한다.
- `iterate` 및 `fullPrecision=false`는 가져오기/재저장으로 **설정만 보존**한다. 반복 계산 및 표시된 정밀도로 계산하는 엔진 동작은 아직 지원하지 않으며 가져올 때 안내한다.
- 가상 분석 데이터 표는 현재 계산된 값을 입력하는 기능이다. Excel의 동적 TABLE 수식·자동 재계산과 동등하지 않다. `autoNoTable` 메타데이터 보존이 TABLE 엔진 구현을 뜻하지 않는다.
- 깔때기 데이터 레이블의 외부 파일 위치 값은 보존하지만 렌더링은 중앙만 지원한다. 효과 없는 위치 선택은 패널에서 제거했다.
- R1C1 같은 참조 설정, 외부 데이터 피벗/OLAP·DAX·Power Query 전체 엔진, VBA 실행, 차트 전용 시트, 임의 SmartArt 편집 등은 별도 범위와 제한이 남는다. [기존 범위 평가](30_재평가와품질개선.md)를 현재 수정과 함께 읽어야 한다.
- 온라인 이미지/영상 공급자, Google 비공개 권한, 클라우드 보관함 실제 계정은 합성 네트워크 응답으로 검사한 경로와 구분한다. 실제 서비스 계정 전체를 이번에 변경하거나 검증하지 않았다.
- Windows Chromium의 키보드·마우스·모바일 화면 모의 결과다. 실제 iPhone Safari/Android와 연결 마우스, VoiceOver/NVDA 전체 조합의 인증이 아니다.

## 표준 근거

계산 속성은 [Open XML CalculationMode](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.calculationproperties.calculationmode?view=openxml-3.0.1), 시트 보기 속성은 [Open XML SheetView](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.sheetview?view=openxml-3.0.1)에 대응시킨다. UI 설정이 있거나 파일 속성을 보존한다고 해서 엔진이 같은 의미로 실행한다고 판단하지 않는다.
