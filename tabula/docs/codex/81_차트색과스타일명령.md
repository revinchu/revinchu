## 원인과 수정

기준 커밋은 48a4ae9f7ae6fc306da544af09a2a10a89a44a89이고 작업 브랜치는 codex/chart-color-actions이다. 리본의 색 변경은 seriesFmt.color만 지웠고, 서식 창의 색 구성은 palette만 바꿨다. 가져온 그라데이션, 개별 점 색, 표식 색 등의 우선순위가 더 높아 화면에는 기존 색이 남았다.

| 확인한 문제 | 수정 |

색 변경은 원본 셀·수식·범위 참조·축 설정·숨김 필터·레이블·기하 배치를 보존한다. 명시적 전체 색 변경은 기존 개별 색도 교체하며 한 번의 실행 취소로 복구된다. 개별 계열 변경은 다른 계열을 유지하고, 점 변경은 다른 점을 유지한다. 스냅샷 차트와 필터로 숨겼던 원본 계열 번호도 처리한다.
