# 84. 색상표와 메뉴 갤러리 키보드 이동

2026-10-05. 기반 커밋 `45b4977b097d1f15a8daa6bc787ccccd388149e5`, 브랜치 `codex/palette-keyboard-navigation`.

## 제보와 재현

Alt → H → F → C 뒤 화살표로 글꼴 색을 선택하지 못하는 제보를 검사했다. 수정 전 합성 문서에서 Alt를 놓은 입력은 통과했지만 Alt를 유지하면 아래 화살표가 색 견본을 건너뛰었다. 데스크톱과 모바일 최적화 모두 재현했다. ‘자동’에서 오른쪽 화살표로 견본에 진입하는 경로도 없었다.

기존 색 팔레트 전용 처리기는 Alt/Ctrl/Meta를 누르면 종료했고, 공통 메뉴는 직접 자식 `.menu-item`만 탐색했다. 따라서 `{node}`로 삽입한 색·무늬·조건부 서식·표/피벗 스타일 등의 내부 버튼이 빠졌다. 숨긴 native 색 입력도 초기 초점 후보였다. 글꼴 검색과 차트 색 구성 검색은 화살표 전파를 차단했다. 글꼴 검색 결과 진입과 모바일 글꼴 목록 이동 실패도 수정 전 코드로 확인했다.

## 설계와 수정

- `ui.js`: 사용자 정의 메뉴 내용에 레이아웃을 바꾸지 않는 `data-menu-gallery`를 표시하고, 실제 보이는 활성 버튼을 공통 키보드 대상으로 삼는다. 숨김·비활성·음수 tabIndex는 건너뛴다. 검색은 `data-menu-search-target`의 결과 목록에 진입한다.
- `menu-navigation.js`: DOM 순서와 실제 표시 좌표로 행·열 이동을 계산한다. 모바일에서 열 수가 달라져도 고정 10열 같은 가정을 하지 않는다. 일반 메뉴의 좌우 하위 메뉴 동작은 유지하며, ‘자동’ 오른쪽은 첫 견본으로 연결한다.
- Alt를 유지한 화살표와 Enter, Space 적용, Tab/Shift+Tab 순환, Esc 취소, Home/End 현재 행, Ctrl/Command+Home/End 전체 메뉴 이동을 지원한다. 입력란의 편집키와 select 기본 동작은 보존한다.
- 기존 셀 스타일 Alt+↓ 수정/복제 메뉴와 하위 메뉴 ← 복귀를 보존한다. 전용 처리기의 `defaultPrevented`를 존중해 한 번 누를 때 두 칸 이동하지 않는다.
- `app.js`의 중복 색 팔레트 처리기를 제거하고 글꼴 검색·목록을 연결한다. 이미 이동한 초점을 되돌릴 수 있는 지연 검색 focus도 제거한다. `chart-palette-ui.js`는 검색 결과로 방향키를 전달한다. 메뉴 갤러리 버튼에 초점 테두리를 표시한다.
- 셀 서식은 기존 선택 범위 캡처·편집 보호·트랜잭션을 사용한다. 파일 형식·수식·저장 엔진은 변경하지 않는다.

## 검증 방식

`tools/palette-keyboard.mjs`는 실제 Alt 경로에서 시작하며 견본에 강제로 focus하지 않는다. 글꼴색/채우기색의 Alt 유지·해제, 모바일/데스크톱, 최초 초점, 행 경계, 적용·한 번 Undo, Tab, 글꼴/차트 색 검색, 우클릭 원래 범위를 검사한다. `WIXEL_PALETTE_BASELINE`은 수정 전 세 모듈을 요청 단계에서 교체한다.

`tools/menu-gallery-keyboard.mjs`는 무늬, 조건부 서식, 표·피벗·슬라이서 스타일, 차트 스타일·레이아웃, 테마, 도형, 셀 스타일의 실제 키팁 진입부터 검증한다. 모든 검사는 새 브라우저 컨텍스트의 합성 문서를 사용하며 API/외부 요청과 원격 쓰기를 차단한다.

기존 리본 coverage의 마지막 한글 fixture는 H/F/C에 `isComposing:true`와 `keyCode:229`를 넣어, 이미 존재하는 조합입력 차단 정책과 상충했다. 수정 전/후 모두 해당 fixture만 실패했고, 비조합 물리 키+한글 key 값으로 바꾸면 모두 통과했다. 키팁 진입 이벤트를 실제 비조합 물리 키로 정정하고, 조합 입력이 명령으로 해석되지 않는 별도 검사를 추가했다. 지연 composition·셀/선택 보존·다음 일반 입력 검사는 유지한다.
