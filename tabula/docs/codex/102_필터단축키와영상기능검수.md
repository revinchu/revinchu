# 필터 단축키와 영상 기능 검수

## 변경

선택한 셀의 모델 좌표에서 일반 자동 필터·표 필터·피벗 행/열/보고서 필터 버튼을 찾는다. 이전에는 일반 필터 DOM만 찾아 피벗 버튼에서 `pickFromList`로 빠졌으며, 가상화로 DOM이 없는 버튼도 찾지 못했다. 새 `cell-dropdown-target.js`는 모델 대상만 반환하고 `app.js`가 기존 필터 메뉴·피벗 컨텍스트 보호를 재사용한다. 틀 고정과 확대에서도 실제 버튼 또는 격자 셀 좌표를 메뉴의 기준으로 삼는다.

키보드로 연 메뉴는 첫 명령(보고서 단일 선택은 첫 항목)에 초점을 두고 `E`로 검색창에 이동한다. 검색어 입력 후 Enter 적용, 체크 목록 방향키·Space, Esc 취소, Undo/Redo를 유지한다. 마우스 메뉴는 기존 검색창 초점을 유지한다. 입력기가 유휴 상태에서 물리 ArrowDown을 Process/229로 보고해도 Alt+↓를 인식하며 실제 조합·셀/수식 편집·AltGr·기존 메뉴·대화상자·네이티브 입력은 해당 동작을 유지한다. 리본/QAT 초점은 해당 컨트롤의 키 처리 뒤 버블 단계에서만 격자로 연결한다.

리본 명령과 빠른 실행 도구 모음 명령을 우클릭하면 추가·제거·사용자 지정 메뉴를 표시한다. 등록 중복을 막고 기존 순서 설정 및 Alt+숫자 규칙을 그대로 사용한다. 일반 필터 조건 적용에도 읽기 전용·최종본·자동 필터 보호를 확인하고, 열린 메뉴의 문서/시트/버전이 달라지면 적용을 거절한다. 피벗은 기존 정의·버전·권한 컨텍스트 보호와 겹침 사전 검사를 유지한다.

## 확인한 요청 자료의 범위

- TikTok 원본과 YouTube `PDdwHw5X_d8`는 접근 제한/조회 오류로 영상·자막 전체를 확인하지 못했다.
- 사용자가 추가한 YouTube Shorts `W_SoOwFDjZM`과 같은 ID가 연결된 [제작자 공식 설명](https://www.oppadu.com/shorts/엑셀-필터-단축키/)에서 우클릭 셀 값/채우기/글꼴 색, 필터 해제, Ctrl+Shift+L, Alt→D→F→F, Alt+↓→E→검색→Enter, 빠른 실행 등록 및 Alt+숫자를 확인했다.
- 정렬·병합·자동합계·PDF는 공식 글의 추가 언급이다. 전체 영상에서 시연한 기능으로 단정하지 않는다. 인쇄/PDF 경로와 PDF 전용 빠른 실행 명령은 구분한다.
- [Microsoft 일반 필터 안내](https://support.microsoft.com/en-US/Accessibility/excel/use-a-screen-reader-to-sort-or-filter-a-table-in-excel)와 [피벗 필터 안내](https://support.microsoft.com/en-us/accessibility/excel/use-a-screen-reader-to-filter-data-in-a-pivottable-in-excel)를 기준으로 실제 필터 버튼 셀의 Alt+↓ 메뉴를 검증한다.

## 검증

수정 전 Git 기준은 `7cd961cedca9a6bd8ae18ed41fa82a6c1172d887`이다. 기준 UI에서 일반·표 헤더 4개는 정상이고 피벗 행/열/보고서 버튼 3개는 필터 대신 피벗 셀 편집 제한 창으로 빠졌다. 관련 공식 기능 감사 13개 중 11개가 통과했고 E 검색 및 리본 우클릭 QAT 등록이 실패했다. 모든 합성 UI 도구는 API·외부 요청 및 원격 쓰기를 차단한다. 실제 업무 원본은 로컬 읽기만 하며 Git/배포/검증 도구의 합성 공개 시나리오에 포함하지 않는다.

실제 파일에 열 필터 버튼 14종류와 보고서 필터 1종류는 없으므로 해당 15종류는 이유를 기록해 제외했다. 일반/표/열 필터와 배율·스크롤·틀 고정·DOM 없는 좌표·Σ 필드는 합성 UI에서 별도 검사했다. 실제 메뉴를 열고 닫은 뒤 피벗 정의·필터·범위·버튼·그림 배치 및 버전·Undo/Redo는 동일하고 원본 파일 해시·크기·수정 시간도 동일했다. 원본 계산 검사가 진행되는 동안 app의 알림/보호 표시를 추가했지만 Node 계산 모듈은 바뀌지 않았고 최종 소스 UI와 실제 파일 단축키는 별도로 검사했다.

공식 글의 추가 언급 중 정렬·병합·자동합계·인쇄 명령은 빠른 실행 등록 목록에 있다. PDF 전용 빠른 실행 저장 명령은 현재 없으며 인쇄에서 PDF 저장 경로를 사용할 수 있다. 이 네 가지는 이번 영상 기능 검수의 실제 실행 통과 수에 포함하지 않는다.
