# 01. 기술 상세 내역서 — WIXEL 3.0.0

> 이 문서는 구조와 큰 그림입니다. 엑셀과 맞추며 확인한 세부 규칙(수백 개)은 저장소 루트 `CLAUDE.md` 의 "Tabula" 절에 항목별로 있습니다.
> 고치려는 영역의 키워드(예: `pivot`, `spill`, `xlsb`, `CellMap`)로 그 절을 검색해 읽은 뒤 작업하세요.

2026-10-02 후속 개선은 모바일 기본 촘촘 배치와 여유로운 배치 전환, 16만 행 CSV 선택 오류 및 큰 UTF-16/CP949 CSV 인코딩 보존, 숨긴 행·열을 건너뛰는 격자·메모 렌더입니다. 결과와 평가의 한계, 최신 남은 작업은 [30. 재평가와 품질 개선](30_재평가와품질개선.md)에 기록합니다. 아래의 날짜별 변경 이력·모듈 수·과거 지원 제한은 해당 시점의 기록이며 최신 전체 상태와 구분합니다.

## 인쇄 영역과 페이지 나누기 후속 개선

- 시트별 `view.mode`의 `pageBreakPreview`를 표준 XLSX/XLS/XLSB 보기 정보에서 복원합니다. 인쇄 영역 밖은 회색, 인쇄 경계는 파란 실선, 자동 페이지 나누기는 점선으로 표시합니다. 기본 보기로 돌아갈 수 있습니다.
- `print-layout.js`는 축 크기·숨김·반복 제목·용지·여백·배율에서 화면/실제 인쇄/PDF/HTML이 공유하는 페이지 계획을 만듭니다. 복수 영역·수동 나누기·행열 삽입/삭제도 보존합니다.
- UI와 검증 범위, Excel과 남은 차이는 [42. 인쇄 영역과 페이지 미리 보기](42_인쇄영역과페이지미리보기.md)에 기록합니다.

## 홈 화면 아이콘

- 이미지 생성으로 제작한 WIXEL W 아이콘을 홈 화면과 파비콘에 연결했습니다. `manifest.webmanifest`, 아이폰용 `apple-touch-icon.png`, 192/512 PNG, maskable PNG 및 다중 크기 ICO를 두 배포 빌드에 포함합니다. 단독 HTML의 파비콘은 내장하고, 앱 등록용 파일은 함께 배포합니다. 세부 사항은 `29_홈화면아이콘.md`를 참고하세요.

## 모바일 작업 모드

- `mobile-work.js`가 기기별 자동/켜기/끄기와 visualViewport를 관리합니다. `mobile-tools-ui.js`는 숨긴 도구·전체 리본 탭·검색·저장·설정 진입을 제공하고, `mobile-grid.js`는 터치 선택·편집·범위·확대/축소를 담당합니다. 모바일 배율은 WeakMap에 보관하여 원본 시트의 zoom을 변경하지 않습니다. 검증 범위와 제한은 `28_모바일작업모드.md`에 기록합니다.

## 명시적 파일 저장 창

- 저장 버튼·Ctrl+S·파일 내보내기마다 시스템 저장 창에서 파일 이름과 폴더를 고릅니다. 이전 파일 핸들은 시작 폴더 힌트에만 쓰며 바로 덮어쓰지 않습니다. 취소·권한 오류는 파일 쓰기와 이름 변경 없이 끝냅니다.
- 미지원 브라우저는 파일 이름/다운로드 확인과 폴더 선택 제한을 안내합니다. 브라우저 자동 보관은 유지하고, 온라인 저장 위치 카드는 폴더와 이름을 먼저 묻습니다. `tools/save-dialog.mjs`의 합성 파일 핸들 검사와 실제 OS 창 수동 검증은 구분합니다.

## 리본 안내 영역 정리

- 사용자 요청에 따라 리본 아래의 큰 바로 가기 키 안내판과 상태 표시줄의 긴 키 목록을 제거했습니다. 버튼별 Alt 배지·하위 명령 메뉴·빠른 실행 도구 모음은 유지합니다.

## 차트·피벗 옵션·표시 후속 변경

- 차트는 17개 유형·50개 갤러리 변형(3D 12개 포함)을 제공합니다. 콤보 계열별 종류·주축/보조축 편집, 축별 누적·100% 계산, 다중 링 도넛과 XLSX 축 보존을 보강했습니다.
- 피벗의 오류 표시 플래그와 대체 문구를 구분하여 가져온 파일의 옵션 상태·계산·저장을 일치시켰습니다.
- `grid-lines.js`가 공유 셀 경계의 중복을 제거하고 장치 픽셀 두께를 계산합니다. `tools/grid-rendering.mjs`는 24개 테마·DPR·앱 배율 조합의 실제 PNG 픽셀과 숨김·고정·스크롤 좌표를 검사합니다.
- `tools/chart-ui.mjs`는 합성 차트 편집 동작, `tools/pivot-options.mjs`는 합성 XLSX의 옵션 UI·계산·재저장, `tools/keytips.mjs`는 등록표·입력 경로·대표 키 동작과 좁은 화면 배치를 검사합니다. 격자 픽셀 검증과 각 도구의 실제 범위·한계는 [14. 차트와 표시 검증](14_차트와표시검증.md)을 따릅니다.
- 실제 사용자 업무 파일과 Microsoft Excel 앱의 표시·복구 여부는 이번 합성 회귀로 검증한 범위에 포함되지 않습니다.

## 셀 스타일·지우기 후속 변경
- `cell-style.js`는 이름 있는 스타일의 6개 구성요소와 초기화·변경 규칙을 공유합니다. `Workbook`의 스타일 목록·표준·블록 서식 이력과 XLSX 부모 스타일 연결을 추가했습니다.
- 서식만 수정할 때 수식과 파일 계산값을 유지하며, 하이퍼링크 지우기/제거와 선택 영역에만 적용하는 조건부 서식 지우기를 제공합니다. 자세한 범위와 검증은 11 문서를 확인하세요.

## 3.0 추가 모듈과 변경
- `app-start.js`: 새 문서·열기·최근 문서·저장 위치 화면. 개인 보관함 연결은 명시적 사용자 선택이며 가져온 파일을 자동 업로드하지 않습니다.
- `cloudflare/`: Workers 정적 자산·프록시와 SQLite Durable Objects 개인 저장소. 복구키 격리, 버전 충돌 보호, 별도 게시본과 중지 API를 제공합니다.
- `chart-3d.js`: 12개 3D 차트 하위 종류의 투영 표현. `chart.js`와 `xlsx.js`는 3D 옵션과 표준 OOXML 입출력을 연결합니다.
- `safe-html.js`: 가져온 셀·차트·도형의 HTML/SVG를 허용 목록으로 정제하고 DOM 조각으로 삽입합니다. Cloudflare 빌드는 외부 스크립트와 CSP를 사용합니다.
- 셀 서식 키보드 탭·미리보기, 차트/도형 오른쪽 서식 창, QAT 위치·순서·Alt 번호, Ctrl+Space, 피벗 필드 이동·값 집계 메뉴를 보강했습니다.
- QUERY 자료형·집계·표시 형식과 공개 Google Sheets IMPORTRANGE를 보강했습니다. 새 문서의 셀 기본 맞춤은 가운데이며 가져온 서식은 유지합니다.
- 정확한 범위·지원 한계·검증 결과는 `09_WIXEL3_구현과검증.md`를 따릅니다.

## 2026-10-01 품질 개선본의 변경
- 서버는 `server.js` 진입점과 `server/app.js`·`server/network.js`로 분리했습니다. 로컬 기본값, 외부 수신 시 토큰 필수, DNS 전체 검사·IP 연결 고정·리디렉션별 검사·중계 제한을 적용했습니다. 운영 설정은 04 문서를 따르세요.
- 피벗 이동, 비연속 메모 셀 선택, 메뉴 키보드 탐색, 대화상자 포커스·한글 조합·비동기 제출, 중계 인증 재입력을 보강했습니다. `tools/ui-regressions.mjs`로 브라우저 동작을 검사합니다.
- 표 열 삽입·삭제의 구조적 참조, XLSX 행 높이·문자열 보존, 유효하지 않은 날짜 입력, 대용량 웹 데이터·스파크라인 오류를 수정했습니다. `quality-fidelity`, `web-scale`, `storage-client` 테스트가 회귀를 확인합니다.
- `moveRefsInFormula`의 선택적 `destinationSheet`는 시트 간 이동 참조를 만듭니다. 1904 날짜 체계는 감지·경고만 지원합니다.
- 아래 모듈 줄 수·규모는 원본 인계 기준입니다. 최신 실행 결과와 한계는 `07_품질개선결과.md`를 확인하세요.

## 1. 개요
- **무엇**: 엑셀 한국어판과 같은 UI · 단축키 · 계산 결과를 목표로 하는 웹 스프레드시트. 이름 WIXEL(위셀), 내부 폴더명 `tabula`.
- **런타임**: 브라우저(Chrome/Edge 기준, Safari/Firefox 동작) + 선택적 Node 서버(`server.js`, 문서 저장 · 웹 가져오기 중계).
- **언어 · 의존성**: 순수 JavaScript ES 모듈, HTML, CSS. **npm 의존성 0**. Node 18+ (테스트 · 서버 · 빌드).
- **배포 형태**: ① `dist/index.html` 단일 파일(정적 호스팅/더블클릭) ② `npm start` 서버(다기기 공유 · 웹 함수 중계 · 게시).

## 4. 데이터 모델
### 4.1 통합 문서 `Workbook`
- `wb.sheets[]`, `wb.names[]`(`{name, ref:'=…', sheet|null, comment, hidden}`), `wb.theme`/`themeXml`, `wb.baseStyle`(xf 0), `wb.cellStyles`, `wb.props`(문서 속성 · 보호 · 최종본), `wb.vba`, `wb.externals`, `wb.pivotSnapshots`.
- 변경은 `wb.transact(fn, meta)` — 실행 취소 기록 + 변경 큐(`pending`) → 끝에서 한 번에 dirty 전파.
- 계산 캐시: 시트별 `wb.caches[si]`. 파일에서 연 수식 칸은 `cell.cached`(엑셀 저장값)를 쓰다가 관련 셀이 바뀌면 다시 계산.

### 4.2 시트
`{ name, cells: CellMap, blocks: [], ...SHEET_PROPS }` — 시트 속성 목록(`workbook.js` `SHEET_PROPS`):
`colWidths, rowHeights, merges, cond, colStyles, rowStyles, allStyle, hiddenRows, hiddenCols, rowManual, freeze, filter, charts, pivot, validations, images, shapes, tables, slicers, pivotsExtra, state, noGrid, noZeros, outline, protect, sparklines, page, defRowH, defColW, zoom, view, tabColor, scenarios, external`
(`CALC_NEUTRAL` 에 든 속성은 바뀌어도 재계산하지 않음)

### 4.3 셀
저장 형태 `{ raw, style?, comment?, link?, cached?, image?, fx? }` → 계산용 셀(`makeCellRC`): `formula`, `ast`(공유), `dr/dc`(공유 AST 기준 오프셋), `maybeArray`, `v`.
- `raw` 는 사용자가 입력한 글자 그대로 (`=…` 수식, `'` 로 시작하면 글자 강제).
- `style` 은 **교체만** 하고 변경하지 않음(identity 비교로 빠른 경로). 서식 코드는 `numFmt`(내장 id) 또는 `numFmt:'custom'` + `code`.
- 테두리 `bt/bb/bl/br`(+`s` 종류, `c` 색), 채우기 `fill`/`pattern`/`gradient`, 글꼴 `font/size/bold/italic/underline/strike/color`, 맞춤 `align/valign/wrap/indent/rotate/shrink`, `checkbox`, `locked/hideFormula`.

### 4.4 큰 데이터
- 행 수 한도 `MAX_ROWS` = 2,000만 (xlsx 저장은 엑셀 한도 1,048,576 까지, 넘는 행은 알림 후 제외).
- CSV/큰 xlsx 는 열 블록(`sheet.blocks`)으로 저장, 정렬은 순열(`perm`)만 바꿈. 5만 칸 이상 문서는 IndexedDB 에 16MB 조각으로 자동 저장.

## 5. 계산 엔진
1. **파싱**: 같은 R1C1 모양의 수식은 AST 하나를 공유(`parseAt`/`shareKey`), 셀은 `dr/dc` 로 상대 참조 이동. 전체 열(`B:B`)/전체 행 참조도 공유.
2. **평가**: `evalAny`(참조 유지) / `evaluate`(값). 함수 플래그 `lazy`, `refFn`, `lift`(배열 확장). 오류는 반환값.
3. **동적 배열**: `evaluateArray` → `placeSpill`(막히면 `#SPILL!`), `ensureSpills(area)` 로 빈 칸 읽기 전 후보 평가.
4. **의존성**: `DepGraph` 가 셀 변경 시 영향 셀만 dirty. INDIRECT/OFFSET/TODAY/RAND 등 동적 함수는 항상 dirty. 10만 점 이상이면 시트 단위 무효화로 대체.
5. **엑셀 정합 규칙**: 15자리 유효숫자 비교, 1900 날짜 체계(1900-02-29 포함), 한국어판 정렬 · 비교 순서, 암묵적 교차(@), 순환 참조 시 저장값 유지 등 — `CLAUDE.md` 참고.

## 6. 피벗 · 슬라이서
- 정의(def)는 필드 **이름** 기준: `rows, cols, values[{field, agg, name, showAs…}], pages, filters, calcFields, calcItems, groups, sort, order, fieldFilters, layout, subtotals, grandRows/Cols, style, itemCaptions…`.
- 계산: `pivotSourceData`(원본 → 큐브, 파일의 캐시 레코드 스냅숏 우선) → `resolvePivot`(필터 · 그룹 · 측정값) → `computePivot`(격자 + role) → app.js `writePivot` 이 셀에 씀(스타일 프리셋 · 파일 서식 재적용).
- 그룹: 날짜(연/분기/월/일), 숫자 구간, **선택 항목 그룹**(`by:'items'`), 파생 필드(`월2`). 계산 필드(필드 합계 기반), 계산 항목(합성 레코드).
- 슬라이서/시간 표시 막대: 선택 상태는 표 필터 · 피벗 filters 에서 파생. 한 슬라이서가 여러 피벗 제어.
- xlsx: 실제 pivotCacheDefinition + pivotTableDefinition + slicerCache 를 쓰고 읽음. WIXEL 전용 정보는 extLst 확장(`wx:`)에 보관.
