# 차트 텍스트 선택과 홈 서식

## 원인과 수정

기준 커밋 891dcf58f3ff44136e0fe22e51f4a9d412d4f0d0에서 실제 SVG 제목·범례·축 눈금을 선택하고 홈 글꼴을 변경하면 차트는 그대로이고 선택되어 있던 원본 셀의 글꼴이 바뀌었다. applyStyle와 formattingStyle가 차트 요소를 편집 대상으로 인식하지 못했다.

- 홈 글꼴·글꼴 크기·크게/작게·색·굵게·기울임·밑줄·취소선을 선택한 차트 텍스트에 적용한다. 기본/보조 축의 눈금과 축 제목은 별도 대상이다.
- 계열의 데이터 레이블을 선택한 뒤 같은 계열의 레이블을 다시 누르면 개별 레이블에 서식을 지정한다. 전체 차트를 선택하면 모든 텍스트에 해당 속성을 적용한다.
- 홈 값과 차트 서식 창을 선택한 요소에 맞춰 동기화한다. Ctrl+1과 홈 글꼴 설정은 차트 서식 창으로 연결한다. 축 제목 삭제는 축 자체를 숨기지 않는다.
- 이름 상자 또는 이동(Ctrl+G)으로 같은 시트의 셀로 이동해도 차트 선택이 남던 문제를 재현하고 수정했다. 이후 글꼴 변경은 이동한 셀에 적용한다.
- 문서·시트·선택 요소가 바뀐 뒤 도착한 이전 글꼴/색상 메뉴 콜백은 무시한다. 보호된 차트는 원본 셀의 서식 변경으로 우회하지 않는다.
- 변경은 통합 문서 거래로 기록하여 실행 취소/다시 실행과 위셀 저장에 포함한다. SVG 생성 시 텍스트만 변경하고 범례의 색 표식과 계열 채우기는 유지한다. 웹 글꼴은 실제 사용하는 차트에 대해 지연 로딩한다.
- XLSX의 기본 차트 및 ChartEx에는 DrawingML 표준 텍스트 속성을 기록한다. 제목·범례·각 축·레이블·개별 레이블·데이터 표의 글꼴/크기/색/강조를 확장 정보 없이도 읽고 저장한다.

- 차트 서식 초기화와 CRTX 템플릿에도 새 텍스트 속성을 반영한다. 레이블 서식 초기화가 계열의 선·채우기를 지우던 문제도 수정한다.

## 구조

chart-text-format.js는 선택 대상 해석·속성 패치·SVG 텍스트 스타일을 담당한다. chart-text-xml.js는 표준 DrawingML 글꼴의 직렬화를 담당한다. app.js는 명령/권한/선택 수명을 연결하고 view.js는 선택 표시와 필요한 글꼴 로딩을 처리한다. chart-selection-ui.js의 공통 텍스트 서식은 홈과 같은 모델을 사용한다.

## 범위

차트 요소 전체의 서식을 변경한다. 제목 문자열 중 일부 글자만 서로 다른 글꼴로 바꾸는 리치 텍스트 편집은 이번 변경의 범위가 아니다. 브라우저 엔진 및 모바일 화면 검사는 실제 iPad/iPhone의 Bluetooth 입력 장치 검사를 대신하지 않는다. 해당 기기에 없는 로컬 글꼴은 설치 여부와 무료 웹 글꼴 제공 여부에 따라 대체 글꼴로 표시될 수 있다.
