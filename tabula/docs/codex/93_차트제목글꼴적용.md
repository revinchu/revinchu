# 차트 제목 글꼴 적용과 입력 목록 안정성

2026-10-05. 기준: `14a6ca3e1e879f534656068d685a90a85d8b8dec`.

## 재현과 범위

사용자가 제목을 선택한 뒤 홈 탭에서 글꼴을 변경해도 적용되지 않는 현상을 보고했다. 정상 제목 선택·Home 목록·직접 입력·XLSX 가져오기 경로에서는 값과 SVG가 바뀌었다. 한국어 제목도 Gmarket Light/Medium/Bold, NanumSquare Neo Heavy, NanumMyeongjo의 실제 폰트 로드·글자폭·화면 이미지 차이를 확인했다.

다음 두 UI 오류는 수정 전 Chromium과 WebKit에서 재현했다.

- 제목을 끌다가 `pointercancel`로 취소한 뒤 키보드로 Home과 글꼴 목록을 선택하면 모델의 titleFont만 바뀌고, 남은 드래그 미리보기가 화면의 옛 글꼴을 유지했다. 취소 후 버튼을 누르지 않은 마우스 이동도 드래그로 처리되어 잘못된 제목 위치가 저장될 수 있었다.
- 홈 글꼴 입력칸에서 값을 입력하고 Enter 없이 목록 화살표를 누르면, 새 목록을 열며 발생한 blur/change가 명령을 실행해 방금 연 목록을 닫았다.

사용자의 정확한 글꼴·파일 조합과 iPad 실기 원인은 아직 확인되지 않았다. 위 두 재현 조건을 고쳤으며 모든 글꼴 문제의 해결이나 iPad 실기 검증을 뜻하지 않는다.

## 변경

`app.js`는 pointercancel·버튼 해제를 놓친 이동·창 blur에서 차트 요소 드래그를 저장 없이 취소한다. 새로운 차트 서식 명령이 이전 미리보기에 가려지지 않게 updateChart에서 초안을 정리한다. 정상 mouseup은 기존처럼 위치 변경 한 번을 기록한다.

`format-value-picker.js`는 목록을 생성하기 전에 입력칸의 blur/change를 처리한다. 글꼴과 크기의 직접 입력·목록 선택이 같은 순서로 동작하며 새 메뉴가 이전 입력 확정으로 사라지지 않는다.
