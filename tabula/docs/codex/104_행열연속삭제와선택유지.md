# 행·열 연속 삭제와 선택 유지

기준 8ceab535의 행·열 삭제는 구조 변경 직후 selectCell을 호출하여 선택한 전체 행·열을 단일 셀로 바꿨다. 다음 Ctrl+Shift+-는 일반 셀의 삭제 옵션을 열고, 여러 행·열의 F4 반복도 한 줄로 줄어들었다. 이전 103번 검사는 F4 전에 대상을 다시 선택하여 연속 사용 결함을 잡지 못했다.

행·열 삭제 후 단일 셀 선택을 제거하여 삽입과 같이 기존 선택 범위·선택 종류·활성 셀을 유지한다. 한 번 선택한 같은 개수의 행·열을 Ctrl+Shift+- 또는 F4로 즉시 반복 삭제할 수 있다. 기존 명령의 트랜잭션·시트 보호·피벗/그림 이동·브라우저 배율 키 매핑을 그대로 사용한다. 일반 셀 선택에서는 삽입과 삭제 모두 기존 셀 이동 옵션을 사용한다.

아래나 오른쪽에 있는 병합 셀이 삭제 후 선택 구간에 들어오면, history 복구의 selectRange가 병합 전체로 범위를 다시 확장하여 3줄을 5줄로 바꾸는 경우도 확인했다. selectRange/setSel의 병합 확장 옵션은 기본 true이며 history의 전체 행·열·전체 시트 선택을 복구할 때만 false로 사용하여 저장한 범위를 그대로 유지한다. 셀 선택의 병합 확장과 도형 텍스트 편집 종료 뒤 지연 실행의 옵션 전달은 유지한다. before와 after 선택이 같아 별도의 selectionAfter 메타데이터는 필요하지 않다.
