# 19. 피벗 표시와 팝업 접근키 — 2026-10-02

## 피벗 표시 옵션

기존 UI는 `showValuesRow`를 바꿨지만 계산 엔진은 `valuesHeadRow`만 읽어 체크 상태가 표에 반영되지 않았습니다. 클래식 옵션도 표시 엔진과 파일 설정에 연결되지 않았습니다.

- 클래식을 처음 켜면 표 형식으로 전환하고 격자 안에 필드 이동 버튼을 표시합니다. 버튼을 끌면 행·열·필터·값 드롭 영역이 나오며 오른쪽 필드 창과도 이동할 수 있습니다. 클릭 메뉴는 Alt 접근키를 지원합니다. Σ 값도 행/열로 이동합니다.
- 이동은 한 번의 실행 취소를 지원하며, 보호·읽기 전용·문서 전환·오래된 드래그를 차단합니다. 값의 집계 방식은 이동 중 보존합니다.
- 클래식 끄기는 현재 표 형식을 유지합니다. 가져온 클래식+압축 형식도 다른 옵션만 편집하면 그대로 유지합니다.
- 값 필드가 둘 이상이고 열 필드가 없을 때 ‘값 행 표시’가 값 머리글 행을 조절합니다. 클래식 상태에서는 Excel과 같이 이 행이 강제 표시됩니다. 그 경우에도 사용자의 값 행 체크 설정은 독립 보존됩니다.
- XLSX의 `gridDropZones`와 `x14:hideValuesRow`를 읽고 씁니다. 표 형식을 클래식으로 잘못 저장하던 경로와 위치만 보고 체크 상태를 추정하던 경로를 제거했습니다.

## Alt 입력과 팝업

키팁 명령이 끝나도 입력기가 조합 이벤트를 나중에 전달할 수 있습니다. 키팁에서 비롯된 조합·입력은 새 입력 동작 전까지 버리고, 다음 정상 키 입력이나 셀 클릭 시 가드를 해제합니다. 시간 지연으로 모든 한글 입력을 버리는 방식은 사용하지 않습니다.

찾기·바꾸기는 다음 키를 명시 지정합니다.

| 키 | 기능 |
|---|---|
| Alt+N / Alt+E | 찾을 내용 / 바꿀 내용 |
| Alt+A / Alt+R | 모두 바꾸기 / 바꾸기 |
| Alt+F / Alt+I / Alt+V | 다음 찾기 / 모두 찾기 / 이전 찾기 |
| Alt+D | 닫기 (사용자 요청) |
| Alt+T | 옵션 펼치기·접기 |
| Alt+C / Alt+O / Alt+B | 대소문자 / 전체 셀 일치 / 전자·반자 |
| Alt+H / Alt+S / Alt+L | 범위 / 검색 순서 / 찾는 위치 |
| Alt+M / Alt+U | 찾기 서식 / 바꾸기 서식 |

공통 창의 확인은 Alt+O, 취소는 Alt+C, 닫기는 Alt+D를 기본으로 하며 창별 명시 키가 우선합니다.

공통 대화상자·메뉴·하위 메뉴와 별도 빠른 분석·무늬 선택·파일 화면에도 접근키 범위를 적용합니다. Alt를 누르면 작은 배지가 보이며, 표시된 키로 실행하거나 입력란으로 이동합니다. 최상위 창만 처리하고 숨김·비활성 항목은 제외합니다. 직접 지정한 키가 겹치면 해당 제어 사이를 이동하고 Enter로 실행합니다. AltGr와 Ctrl/Meta 조합은 가로채지 않습니다.

키 배정은 창별 명시 키, 기존 `(A)`/`(&A)` 표기, 설치된 한국어 Excel 16.0 레이블의 단일 키, WIXEL 자동 대안 순서입니다. Excel 리소스에서 일치한 단일 레이블 465개를 사용하고 문맥별 키가 다른 112개는 공통 추천에서 제외했습니다. 같은 레이블이라도 제품 버전·창에 따라 키가 다르므로 모든 Excel 접근키와 완전 동일하다는 보장은 아닙니다. `data-access-key-source`로 지정/Excel/자동 배정을 구분합니다.

## 검증

- 전체 Node 단위 테스트: **457/457**, 일반 빌드·Cloudflare 빌드·Wrangler 배포 모의 실행 성공.
- 최종 번들 `wixel-f2d1daa5162d4e8e.js`: 리본 스모크 **300개, bad 0**, 직접 단축키 **114/114**, 리본 키팁 **32/32**, 지연 IME **9/9**, 실제 찾기·바꾸기 창 **6/6**, 기존 저장 창 **12/12**.
- 같은 최종 번들: 피벗 표시 옵션 8조합 **226검사**, 클래식 피벗 A7/A1 각각 **61검사·실제 마우스 드래그 13회**. 드래그 띠와 시작 버튼 겹침·숫자가 아닌 위치·열 필드 중복 표시도 검사합니다. 총 **348검사·26회 드래그**, 페이지 오류·원격 쓰기 0.
- 공통 UI 소스 서버: 접근키 **22/22**, 기존 UI 회귀 **12/12**. 접근키 DOM 없는 단위 검사는 7개이며 전체 457개에 포함됩니다.
- 실제 Excel COM 합성 XLSX 8개: WIXEL 저장 후 Excel 일반 열기에서 옵션·레이아웃 **24검사**, 표에 표시한 **185셀** 일치. 복구 모드로 실패를 통과시키지 않았습니다.
- `8cc59a3`와 새 소스의 `check.mjs`/`pvcmp.mjs` 전후 비교: 같은 Excel 합성 원본 8개 모두 피벗 값·영역 차이 0, 저장 왕복 문제 0. 이 파일에는 수식이 없으므로 수식 정확도 검증으로 세지 않습니다. `pvcmp`는 가져온 상태를 비교하므로 옵션 변경 후 다시 계산하는 동작은 별도 UI 검사로 확인합니다.
- 별도 합성 브라우저만 사용하고 사용자 문서·온라인 보관함에 쓰지 않았습니다. 소스 모듈을 가져오는 공통 UI 검사는 배포 번들 검사와 구분합니다.

## 남은 검증 범위

- Windows의 실제 한글 IME 후보창을 직접 조작한 검증은 포함하지 않습니다. 지연된 조합·입력 이벤트를 Chromium에서 재현합니다.
- 실제 Excel 검증은 새 COM 인스턴스에서 합성 XLSX 8개를 생성·재열기한 결과입니다. 사용자 업무 파일과 모든 피벗 기능의 동등성까지 확인한 것은 아닙니다.
- XLSB/옛 XLS의 해당 표시 속성 변환은 이번 수정 범위에 포함하지 않습니다.
- 브라우저가 제공하는 파일 선택·인쇄 등 시스템 창의 키는 운영체제와 브라우저가 제어합니다.
