# 미디어·그리기·SVG 조합과 문서 출력

2026-10-02. 이 문서는 구현한 범위와 검증 가능한 계약을 기록한다. Excel·PowerPoint·FigJam 전체 기능과 동일하다는 의미가 아니다.

## 접근 경로

- 삽입 → 온라인 그림, GIF, 영상, 그리기 팔레트, SmartArt.
- SVG 그림 선택 → 셰이프 형식 → SVG 도형 변환. 우클릭의 그룹 해제는 SVG를 바로 개별 도형으로 바꿀 수도 있다.
- Ctrl로 도형을 복수 선택 → 셰이프 형식/우클릭 → 도형 병합 → 결합·병합·조각·교차·빼기. 빼기의 기준은 먼저 선택한 도형이다.
- 홈 → 교차색상. 보기 → 전체화면. 파일 → 다른 이름으로 저장 또는 내보내기 → 웹페이지(HTML)/PDF.

## 온라인 그림·GIF·영상

기존 Openverse·Wikimedia·iNaturalist·NASA에 Unsplash·Pexels·Pixabay를 추가했다. 종류에 맞는 공급자만 검색한다. GIF는 Wikimedia 원본 `image/gif`, 영상은 Wikimedia·NASA·Pexels·Pixabay를 사용한다. 직접 MP4/WebM 주소도 입력할 수 있다. CC 필터는 CC/CC0를 확인한 결과에만 적용하며, 별도 라이선스의 신규 3곳과 NASA를 CC 검색 결과로 오인시키지 않는다.

서버 환경 변수/Cloudflare Worker Secret:

| 공급자 | 키 | 종류 |
|---|---|---|
| Unsplash | `UNSPLASH_ACCESS_KEY` | 그림 |
| Pexels | `PEXELS_API_KEY` | 그림·영상 |
| Pixabay | `PIXABAY_API_KEY` | 그림·영상 |

키는 클라이언트·통합 문서·Git에 기록하지 않는다. 미설정 시 상태와 공식 사이트 검색/설정 문서 링크를 제공한다. 신규 공급자의 인증된 실검색은 키가 없는 개발 환경에서 검증하지 못했으며 공식 응답 모킹과 미설정 실제 응답을 구분한다.

`server/media-search.js`는 고정된 공급자 URL, 질의 길이·종류 검증, 10초 제한, 2MiB 응답 한도, 기존 원본 검사·인증·요청 제한을 이용한다. Unsplash는 hotlink/ixid 유지 및 실제 삽입 시 download tracking, Pixabay 그림은 다운로드 성공 후에만 삽입한다. Pixabay 캐시는 인스턴스 내 24시간이며 인스턴스 종료 시 소멸한다.

GIF 바이트를 PNG로 바꾸지 않는다. 영상은 클릭하여 재생하는 연결 미디어이며 자동 재생하지 않는다. XLSX에는 미리보기 그림·일반 하이퍼링크와 WIXEL 확장 메타데이터를 기록한다. Excel 자체 영상 플레이어와의 호환은 지원 범위가 아니다. 외부 URL의 만료·삭제·코덱·CORS·네트워크 제한이 재생에 영향을 줄 수 있다.

## 그리기 팔레트

`drawing-palette.js`와 기존 `app.js` 그리기 엔진을 연결한다. 선택·펜·형광펜·선·사각형·원·화살표·획 지우개, 색·굵기·불투명도와 Undo/Redo를 제공한다. 명시적으로 열린 팔레트만 연속 그리기를 유지한다. Escape/선택 도구/닫기/시트 변경은 그리기를 끝낸다. 펜·터치 pointer capture를 사용하고 취소된 초안은 제거한다. 지우개는 클릭한 도형 전체를 지우는 방식이며 자유 경로의 일부를 잘라내는 지우개는 아니다.

## SVG 변환과 도형 조합

`geometry-path.js`는 SVG M/L/H/V/C/S/Q/T/A/Z 및 변환 행렬을 읽는다. `svg-to-shapes.js`는 도형·path·그룹을 일반 편집 도형으로 바꾸며, 떨어진 경로는 분리하고 구멍은 외곽과 묶는다. 색·윤곽·변환을 보존하고 standard XLSX grpSp/custGeom으로 저장한다. 변환 전 모든 항목을 검증하여 실패 시 원본을 변경하지 않는다.

내장 아이콘 3,663개 중 3,659개가 변환되며, 사용자 지정 이음 한도/viewport 밖 잘림이 있는 4개는 거부한다. 외부 리소스·text·효과·clip·mask·실제 CSS·복잡한 gradient·비균등 윤곽 변환은 지원하지 않는다. 잘린 SVG 그림은 자르기 초기화 후 변환한다.

`shape-boolean.js`의 `mergeShapes`는 첫 도형의 서식을 기준으로 새 freeform 결과를 만든다. 결합은 합집합, 병합은 홀수 겹침 영역, 조각은 교차 경계별 구성요소, 교차는 공통 영역, 빼기는 첫 도형에서 나머지를 뺀 영역이다. 회전·대칭·구멍을 처리한다. 곡선 결과는 0.2 시트 픽셀 허용오차의 다각형 근사다. 입력 2~16개, 최대 2,000개 선분과 교차/출력 한도로 과도한 계산을 차단한다. 열린 선·그림·그룹·SmartArt·미해석 customGeometry는 직접 조합하지 않는다. 각 변환/해제/조합은 한 번의 `wb.transact`로 실행 취소할 수 있다.

## SmartArt

8분류 60종: 목록8·프로세스10·순환6·계층7·관계10·행렬5·피라미드6·그림8. 검색·분류별 견본·실시간 미리보기·선택 설명·접이식 색/스타일 패널·텍스트/계층 편집·그림 선택을 제공한다. 기존 modelVersion 1 및 편집 가능한 그룹 XLSX 저장을 유지한다. Microsoft의 모든 SmartArt 레이아웃/고유 OOXML 다이어그램 자동배치 전체 구현은 아니다.

## 교차색상·전체화면·내보내기

`alternating-colors.js`는 표 값과 직접 셀 서식을 유지하며 2~4개의 표준 조건부 수식 규칙을 추가한다. 머리글/바닥글·8색상표·사용자 색을 지원한다. `N("WIXEL_BANDING")` 식별자로 XLSX 왕복 뒤에도 해당 범위의 교차색상만 제거한다. 기존 조건부 서식과의 우선순위에 따라 일부 스타일이 함께 보일 수 있다.

전체화면은 Fullscreen API와 제한 환경의 앱 내부 확장 모드를 사용한다. 종료 버튼과 Escape를 제공한다.

HTML/PDF는 현재 시트의 인쇄 범위·페이지 설정을 사용하며 일반 파일 저장창을 먼저 연다. HTML은 실행 스크립트 없는 페이지별 문서이며 CSP를 포함하고 조건부 색·표·도형을 출력한다(최대300쪽). 연결 그림은 외부 URL이 필요할 수 있다. 직접 PDF 저장은 페이지를 이미지로 기록하므로 본문 검색/선택은 지원하지 않으며 이 제한은 미리보기에도 표시한다. 브라우저 기본 인쇄도 유지한다. 전체 통합 문서를 편집 가능한 HTML 앱으로 내보내는 기능은 아니다.

## 검증 도구

- `test/online-media.test.js`, `online-images.test.js`: 공급자 응답·키 미설정·CC·주소 검증·중계 보호.
- `test/shape-boolean.test.js`, `svg-to-shapes.test.js`: 영역 연산·변환·투명도·실패 원자성·표준 XLSX 왕복.
- `test/smartart.test.js`: 60레이아웃·작은 크기·노드 수·XLSX 왕복.
- `test/creative-workspace.test.js`: 영상 확장/표준 링크·교차색상 XLSX 왕복.
- `tools/creative-workspace.mjs`: 팔레트 마우스/터치·Undo·취소·모바일·교차색상·HTML/PDF 파일 바이트·저장 취소·전체화면.
- `tools/palette-lifecycle.mjs`: 시트 전환 중 초안 제거, 그리기 중 최종본 지정 차단, 일반 도형의 획 지우개 제외.
- `tools/shape-merge-ui.mjs`: 실제 선택·조합·SVG 해제·보호·Undo.
- `tools/svg-geometry-render.mjs`: SVG 원본과 변환 도형의 래스터 비교. 경계2px는 안티앨리어싱 차이로 별도 제외한다.
- `tools/svg-icon-audit.mjs`: 내장아이콘 변환 전수 검사.
- `tools/online-media.mjs`, `online-pictures.mjs`, `smartart.mjs`: 격리 합성 문서의 실제 UI. 공개공급자의 별도 실제 읽기와 모킹된 인증 공급자를 구분한다.

사용자 원본 파일·실제 열린 문서는 테스트에 사용하지 않았으며 테스트 문서는 외부로 보내지 않았다. 실제 Microsoft Excel/PPT 앱에서 새 기능 전체를 직접 조작한 검증은 포함하지 않는다.
