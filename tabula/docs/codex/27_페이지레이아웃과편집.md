# 27. 페이지 레이아웃과 편집

## SmartArt

WIXEL에서 삽입·선택·다시 편집할 수 있는 다이어그램을 추가했습니다. 리본의 `삽입 → SmartArt`에서 배치를 고른 뒤 텍스트 창에서 항목을 추가·삭제하고, 수준 올리기/내리기·위/아래 이동을 할 수 있습니다. 텍스트 창의 Tab/Shift+Tab도 수준을 바꿉니다. 색 모음과 단색·윤곽선·그림자 스타일, 그림 파일을 적용하고 확인할 때 한 번의 실행 취소로 기록합니다. 취소하면 원본을 바꾸지 않습니다.

| 범주 | 배치 |
|---|---|
| 목록 | 세로 목록, 블록 목록, 교대 목록 |
| 프로세스 | 기본 프로세스, 갈매기형 프로세스, 세로 프로세스, 단계 프로세스 |
| 순환 | 기본 순환, 방사형 순환 |
| 계층 | 조직도, 가로 계층, 계층 목록 |
| 관계 | 기본 방사형, 겹치는 관계, 관계 비교 |
| 행렬 | 기본 행렬, 제목 있는 행렬 |
| 피라미드 | 분할 피라미드 |
| 그림 | 그림 설명 목록, 그림 프로세스 |

총 **8범주·20배치**입니다. 항목은 최대 60개, 항목당 텍스트는 500자이며, 그림은 2MB 이하 PNG/JPEG, 합계 10MB 이내입니다. 항목이 많아지면 같은 크기로 글자를 줄이므로 읽기 쉬운 결과를 위해 도형 크기나 항목 수를 조정해야 합니다. 생성 시 통합 문서의 테마 색과 기본 글꼴을 사용하며, 이후 테마 변경을 모든 기존 사용자 지정 색에 자동 적용한다고 보장하지 않습니다.

### 저장 방식과 호환 범위

시트의 `shapes` 배열에 `kind: 'smartart'`와 `smartArt` 편집 모델을 저장합니다. 크기 변경에 맞춰 배치를 다시 계산합니다. `일반 도형으로 변환`하면 `kind: 'group'`으로 바뀌며, 공통 그룹 해제로 구성 도형을 개별 편집할 수 있습니다.

XLSX에는 **표준 DrawingML 도형 그룹(`xdr:grpSp`)과 실제 텍스트·연결선·그림**을 기록합니다. 따라서 Excel에서도 일반 그룹으로 열고 개별 도형을 편집할 수 있습니다. WIXEL 전용 확장에는 배치·항목·색·스타일을 넣어 WIXEL에서 다시 열 때 다이어그램 편집을 복원합니다. **Excel의 기본 SmartArt(`dgm`)를 생성하는 기능은 아닙니다.** Excel의 전체 SmartArt 갤러리·자동 배치 알고리즘과 동일하지 않으며, 임의의 기존 Excel SmartArt를 WIXEL 편집 모델로 가져오는 기능도 포함하지 않습니다.

표준 자식 도형의 텍스트·서식·좌표·그림 바이트를 검사하여 외부에서 바뀐 내용이 있으면 이전 편집 메타데이터를 우선하지 않습니다. 확장이 없거나 표준 내용이 달라진 파일은 표준 도형 내용과 부모 회전·대칭을 일반 그룹으로 복원하며 안내 경고를 표시하므로 SmartArt 편집 기능은 해제될 수 있습니다. 외부 편집기별 확장 보존과 모든 도형 표현의 완전한 일치는 보장하지 않습니다.

## 페이지 레이아웃: 테마와 인쇄 배율

페이지 레이아웃 리본의 테마 그룹을 테마 / 색 / 글꼴 / 효과로 정리했습니다. 글꼴은 7가지 제목·본문 조합, 효과는 없음·은은한 그림자·보통 그림자·강한 그림자 4가지를 제공합니다. 글꼴 선택은 통합 문서 기본 본문 글꼴을 바꾸며, 셀에 명시된 글꼴은 유지합니다. 효과는 새 도형·SmartArt의 기본 효과입니다. 기존 도형의 직접 지정된 색·그림자를 테마 변경으로 자동 덮어쓰지 않습니다.

너비와 높이 자동 맞춤, 배율을 리본 안에서 바로 설정합니다. 너비·높이 중 하나가 맞춤 상태이면 수동 배율을 비활성화합니다. 너비·높이를 모두 자동으로 바꾸면 10~400% 수동 배율을 사용할 수 있습니다. 한 번 변경은 한 번 실행 취소/다시 실행으로 돌아갑니다. 보호/읽기 전용 문서의 변경 제한을 적용하며 인쇄 자체는 허용합니다.

테마 색, 제목·본문 글꼴, 선택한 효과는 표준 OOXML 테마로 저장합니다. 가져온 테마를 바꾸지 않으면 원본 XML을 유지하며, 선택한 글꼴/효과를 변경할 때에도 다른 문자권 글꼴, 채우기·선 정의를 보존합니다. 설치되지 않은 글꼴의 화면 표시는 브라우저 대체 글꼴에 따릅니다. 미지원 외부 효과 스키마는 원본 XML 보존 범위이며 모든 Office 효과의 화면 구현을 뜻하지 않습니다.

## 인쇄 미리보기와 PDF 저장

기존 인쇄 경로는 `window.print()`만 호출하여, 호스트가 인쇄 창을 표시하지 않을 때 앱 안에서는 아무 반응이 없었습니다. 새 경로는 먼저 실제 페이지 미리보기를 열고 **인쇄**와 **PDF 파일 저장**을 제공합니다. 인쇄 버튼은 브라우저/운영체제 인쇄 창을 호출하며, 창이 나타나지 않을 경우 PDF 저장 안내를 남깁니다. 실제 사용자 IAB 탭이나 업무 파일에는 접근하지 않았습니다.

미리보기·브라우저 인쇄·직접 PDF는 동일한 페이지 스냅숏을 사용합니다. 현재 시트의 인쇄 영역, 용지·방향·여백, 배율, 반복 제목 행·열, 머리글/바닥글의 쪽수, 숨긴 행·열, 병합 셀을 반영합니다. 병합 셀이 페이지 경계를 넘으면 각 페이지의 교차 부분으로 나누고, 해당 병합 내용을 각 부분에 표시합니다. 표의 글꼴·크기·색·배경·기본 테두리 색을 보존합니다.

차트·그림·도형·SmartArt를 원래 시트 x/y 좌표와 같은 배율로 표 위에 배치합니다. 명시한 인쇄 영역에 걸친 개체는 영역 및 페이지 경계에 맞춰 잘라 출력하며, 영역 밖 개체·숨긴 개체·인쇄 제외 개체는 출력하지 않습니다. 개체를 별도 쪽으로 분리하는 이전 방식은 제거했습니다. 인쇄 영역을 지정하지 않으면 보이는 인쇄 대상 개체까지 사용 범위를 넓힙니다. 인쇄 스냅숏 생성과 PDF 저장은 원본 통합 문서를 변경하지 않습니다.

직접 PDF는 외부 라이브러리나 서버 없이 생성하는 **이미지 PDF**입니다. 한글과 그림의 화면 모양을 보존하지만 본문 텍스트 검색·벡터 편집·태그 접근성 PDF는 지원하지 않습니다. 외부 그림은 해당 서버의 CORS/접근 허용이 필요하며, 포함할 수 없으면 명시적인 오류와 브라우저 인쇄/파일 그림 삽입 안내를 표시합니다. 한 번에 20,000행·200열·500,000셀까지, 직접 PDF는 150쪽까지 지원합니다. 범위 초과 시 원본 내용을 조용히 잘라내지 않고 인쇄 영역을 나누도록 안내합니다. 매우 큰 한 행/열은 배율을 줄이라는 경고를 표시합니다. 물리 프린터 출력, 모든 Excel 인쇄 기능 및 복잡한 사용자 업무 파일의 픽셀 일치는 확인하지 않았습니다.

## 선택하여 붙여넣기

`Ctrl+Alt+V`와 홈/셀 우클릭의 선택하여 붙여넣기를 같은 대화상자에 연결했습니다. 내부 복사 데이터가 없어도 창을 열어 외부 클립보드 텍스트를 읽습니다. 브라우저가 읽기를 허용하지 않으면 창의 입력 영역에서 Ctrl+V로 붙여넣을 수 있습니다. 외부 Excel 클립보드의 바이너리 서식·메모·유효성 검사 전체를 읽는 것은 아니며, 외부 경로는 TSV/텍스트입니다. WIXEL 내 복사는 셀 자료형·복사 시점의 서식·열 너비·유효성 검사·조건부 서식을 보관합니다.

- 12가지: 모두, 수식, 값, 서식, 메모, 유효성 검사, 원본 테마 사용, 테두리만 제외, 열 너비, 수식 및 숫자 서식, 값 및 숫자 서식, 조건부 서식 모두 병합.
- 연산: 없음·더하기·빼기·곱하기·나누기. 대상 수식을 보존하며 0으로 나누기는 Excel 오류값으로 처리합니다.
- 내용 있는 셀만 붙여넣기, 행/열 바꿈, 연결하여 붙여넣기(L). 전치 시 상대·혼합·절대 참조를 Excel과 대조했습니다. 링크는 원본이 현재 통합 문서 안에 있는 경우만 지원합니다.
- 표시된 Alt 문자, Enter/Esc를 동작시킵니다. 잘라내기에는 복사 전용 옵션을 적용하지 않습니다. 한 번의 적용은 한 번의 Undo입니다.

## 검토: 범위 편집 허용과 메모

검토 탭에서 편집 허용 범위의 제목·비연속 참조·선택적 암호를 추가/수정/삭제합니다. 시트가 보호된 상태에서는 정의 변경을 막고, 해당 범위의 첫 입력에서 암호를 묻습니다. 암호가 없는 허용 범위는 시트 전체 보호를 유지한 채 편집할 수 있습니다. 해제 권한은 현재 세션의 WeakMap에만 있고 파일에는 저장하지 않습니다. 범위 정의·암호가 바뀌면 이전 권한이 적용되지 않습니다. 범위는 행/열 삽입·삭제 및 Undo에 따라 조정합니다.

XLSX 표준 `protectedRanges`를 읽고 씁니다. 기존 현대 해시/Windows 보안 설명자를 보존합니다. 지원하는 SHA 해시만 확인하며 Windows 계정 권한 자체를 브라우저에서 인증하지 않습니다. 권한 기반 범위는 Excel에서 범위 암호를 지정하거나 시트 보호를 해제해야 합니다. Excel 시트/범위 암호는 문서 암호화나 서버 접근 제어를 대체하지 않습니다.

메모 표시/숨기기·모두 표시·모두 숨기기를 추가했습니다. 표시 메모는 현재 화면의 셀만 조회하여 그리며, VML 표시 속성으로 Excel 왕복을 보존합니다. 범위·메모와 통합 문서 구조 보호 변경은 Undo를 지원합니다.

`test/review-state.test.js` 4개, `test/review-xlsx.test.js` 6개, `tools/review-ux.mjs` 10개가 소스에서 통과했습니다. 실제 Excel 16.0 build 14334 일반 Open/SaveAs에서 보호 범위 2개·메모 3개(표시 2, 숨김 1)·시트 보호를 보존했고, WIXEL 재읽기/재저장도 동일했습니다. 잘못된 VML 좌표와 명시적 False 표시값을 숨김으로 읽는 회귀를 포함합니다.

## 공유 해제

검토 탭의 통합 문서 공유 해제는 **현재 WIXEL 문서의 온라인 게시 링크를 중지**합니다. 게시 소유자의 기존 서버 권한으로 삭제를 요청하고 성공한 뒤 자동 다시 게시를 해제합니다. 읽기 전용 문서에서는 실행하지 않습니다. 이미 내려받은 사본·문서 내용 자체를 담은 오프라인 링크는 회수하지 못합니다. Excel의 공유 통합 문서(레거시), 사용자별 공동 편집 권한 관리 기능과는 다르며 그런 기능이 구현됐다고 표시하지 않습니다. 합성 UI 검사에서는 원격 삭제를 실행하지 않았습니다.

## 정렬·그룹화·선택 창

페이지 레이아웃에서 앞으로/뒤로·맨 앞으로/맨 뒤로, 선택 창, 맞춤/배분, 그룹화/그룹 해제, 회전/상하·좌우 대칭을 사용할 수 있습니다. 여러 개체의 상대 겹침 순서를 유지하고, 선택 창의 숨김·이름 변경도 보호 검사를 거칩니다. 이름 변경 중 Esc는 취소합니다.

도형과 그림을 Ctrl 또는 선택 창으로 여러 개 선택하여 그룹화합니다. 그룹의 이동·크기·회전·대칭과 중첩 그룹을 저장합니다. 그룹 해제는 현재 위치와 겹침 순서를 유지하며 복사본의 자식 ID가 충돌하지 않도록 다시 부여합니다. 비균등 배율+회전 때문에 전단 변환이 필요한 자식은 모습 보존을 위해 단일 항목 그룹으로 유지합니다. 차트·슬라이서와의 혼합 그룹화는 지원하지 않습니다. SVG 글자 줄바꿈은 브라우저의 HTML 도형 텍스트와 픽셀 단위로 완전히 같다고 보장하지 않습니다.

그룹 내부 그림의 자르기·투명도·테두리·둥근 모서리·그림자, 도형 텍스트 조각의 서식을 렌더링합니다. 그룹 복사 시 SVG 클립/효과 ID에 부모 ID를 포함합니다. 표준 도형 그룹 저장과 외부 편집 내용 우선 처리는 SmartArt와 공통입니다. `test/object-group.test.js`와 `tools/object-group.mjs`에서 좌표 변환·중첩·그림·Undo·보호·여러 개 선택을 검사합니다.
