# 20. 셀·행·열 우클릭 메뉴 (2026-10-02)

사용자가 제공한 Excel 행 선택 우클릭 화면을 기준으로 메뉴·미니 서식·접근키와 실제 작업 대상을 보강했다. 이 문서는 이번 변경의 검증 범위를 기록하며 Excel 전체 동등성을 의미하지 않는다.

## 변경

- 행/열 전체를 선택하고 셀 본문에서 우클릭해도 행/열 메뉴가 나온다. 머리글 우클릭, Shift+F10, 메뉴 키도 같은 선택 종류를 사용한다. 선택 안에서는 범위를 유지하고 밖에서는 누른 셀만 선택한다. 이동 옵션으로 만든 비연속 선택도 실제 좌표로 판별한다.
- 공통 메뉴: 잘라내기(T), 복사(C), 붙여넣기(P), 붙여넣기 옵션(전체·값·수식·서식·행/열 바꿈), 선택하여 붙여넣기(S), 삽입(I), 삭제(D), 내용 지우기(N), 셀 서식(F).
- 행 메뉴: 행 높이(R), 자동 맞춤, 숨기기(H), 숨기기 취소(U). 열 메뉴: 열 너비(W), 자동 맞춤, 숨기기(H), 숨기기 취소(U). 일반 셀 메뉴에서도 행 높이·열 너비와 숨기기 하위 메뉴를 사용할 수 있다.
- 일반 셀 메뉴에 정렬·필터 하위 메뉴, 해당 셀의 표·피벗 메뉴, 메모·링크·셀 그림 기능을 연결했다.
- 미니 서식 도구 모음: 글꼴·크기·크기 증감, 굵게·기울임꼴·밑줄, 가운데 맞춤, 채우기·글꼴 색, 테두리, 표시 형식·백분율·쉼표·소수 자릿수, 서식 복사·병합. 기존 명령/선택/Undo 경로를 사용한다.
- 메뉴와 도구 모음은 화면 안에 배치하고 작은 화면에서는 스크롤한다. Esc/바깥 클릭으로 함께 닫힌다. 메뉴 명시 접근키가 도구 모음 자동키보다 우선하며 스크롤 밖의 명시 메뉴 키도 해당 항목을 표시한 뒤 실행한다.

## 치수·선택·보호

행 높이는 포인트(0–409.5), 열 너비는 기본 글꼴 기준 문자 수(0–255)이다. 0은 이전 크기를 보존한 숨김이고 양수는 크기 변경과 숨김 해제다. 가져온 0px 치수는 숨김 취소 시 기본 크기로 복구한다. 행 자동 맞춤은 기존 수동 높이 표시를 해제한다.

`context-selection.js`가 실제 선택의 축 구간/합집합을 계산한다. 20,000개를 넘는 부분 축 작업은 아무것도 바꾸지 않고 범위를 줄이라는 안내를 표시한다. 전체 축 치수는 기본값과 기존 override만 변경한다. 전체 자동 맞춤은 희소 셀·블록·기존 치수의 대상만 사용한다. 치수 맵은 한 번에 기록해 반복 복사의 이차 비용을 피한다.

메뉴 활성 상태와 실행 시점에 게시 읽기 전용·시트 보호·최종본 정책을 검사한다. 셀 밀기는 보호된 시트에서 차단해 이웃의 잠긴 셀도 보호한다. 허용된 전체 행/열 작업은 기존 권한을 따른다. 잘라낸 셀의 선택 붙여넣기는 막고, 일반 붙여넣기는 기존 이동/Undo 의미를 유지한다. 붙여넣기의 확장된 실제 범위도 잠금 검사한다. 숨김 변화가 없는 높이·너비 변경/Undo는 가져온 수식의 저장값을 무효화하지 않는다.

## 검증

사용자 파일·브라우저 세션·실제 클립보드를 사용하지 않고 합성 문서와 분리된 브라우저 컨텍스트로 검사했다. 원격 쓰기는 차단했다.

`tools/context-menu-safety.mjs`는 소스/배포용 번들 모두 8개 시나리오·71개 검사를 통과했다(페이지 오류·원격 쓰기 0). 보호·게시 문서, 열린 창의 권한 변경, 잠긴 이웃 셀 밀기 차단, 허용된 전체 행 삽입·Undo, 잘라내기 데이터 보존, 붙여넣기 확장 범위, 가져온 수식 캐시를 검사했다.

숨겨진 새 Excel COM 인스턴스의 합성 문서로 Calibri 11/맑은 고딕 11의 열 치수 20개와 숨김/복원 정책을 비교했다. `test/dimension.test.js`는 XLSX 왕복 및 기존 글꼴 변환과의 일치도 검사한다. XLSX 읽기/쓰기 코드는 이번에 변경하지 않았다.

## 남은 한계

- 내부 크기는 정수 CSS px이므로 소수 포인트는 양자화된다. 열 문자 너비는 기존 XLSX 글꼴 추정표를 사용하며 미등록·대체 글꼴까지 실제 Excel과 정확히 같다고 보장하지 않는다.
- 전체 시트 행 높이는 기본 높이를 바꾸며, 모든 미사용 행에 수동 높이 플래그를 생성하지 않는다. 이후 큰 글꼴/줄 바꿈 입력의 자동 높이 정책은 Excel의 전체 행 수동 지정과 다를 수 있다.
- 기존 자동 맞춤 측정은 열은 앞 5,000행/최대 600px, 행은 앞 500열을 사용한다. 이 변경은 측정 엔진의 모든 Excel 동등성을 확장하지 않는다.
- 브라우저 클립보드 권한에 따라 외부 붙여넣기는 Ctrl+V가 필요하다. 선택하여 붙여넣기는 위셀 내부에서 복사한 셀을 대상으로 한다.
- 사용자 지정 추가 기능이 만드는 메뉴, 모든 Excel 버전의 상황별 메뉴 및 OS/IME의 모든 조합은 이번 검증 범위에 포함하지 않는다.
