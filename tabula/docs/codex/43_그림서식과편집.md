# 그림 서식과 편집 — 구현 범위와 검증

## 사용자 동작

그림을 선택하면 **그림 서식** 탭이 자동으로 열린다. 다른 탭으로 이동한 후에는 선택을 유지하는 동안 사용자가 고른 탭을 빼앗지 않는다. 그림 우클릭에는 스타일·자르기 미니 도구 모음과 잘라내기/복사/붙여넣기, 그림 바꾸기, 그룹화, 앞뒤 순서, 맞춤, 회전, 선택 창, 링크, 그림으로 저장, 원본 보기, 매크로 지정, 대체 텍스트, 크기/속성, 그림 서식이 있다.

리본에는 배경 제거, 수정, 색, 꾸밈 효과, 투명도, 압축, 바꾸기, 원래대로, 24개 스타일, 그림 테두리/효과/레이아웃, 대체 텍스트, 정렬, 자르기, cm 높이/너비/비율 잠금이 있다. 모든 실제 조작에는 고유한 키팁이 있다. 그림 탭은 위셀의 `Alt → J → Q`이며 Excel 버전별 키와 전부 동일하다는 의미는 아니다. `Ctrl+1`과 `F2`로 그림 서식을 열 수 있다.

서식 창은 탭, 미리보기, 확인/취소로 구성된다. 확인 전의 변경은 문서·실행 취소 기록에 반영하지 않는다. 확인 시 원래 문서·시트·그림·보호 상태를 재검사하고 하나의 트랜잭션으로 적용한다. cm 크기 입력의 change/Enter 중복 이벤트는 동일값 변경을 저장하지 않는다.

## 구현과 파일 보존

- `picture.js`: 크기/비율, 자르기, 스타일, 서식 초기화, 원본 복원.
- `picture-filter.js`: 밝기/대비/선명도, 채도/색온도/다시 칠하기, SVG 꾸밈 필터, 효과 정규화.
- `picture-pixels.js`, `picture-raster.js`: 로컬 배경 선택/보정, 압축, 저장용 보정 PNG.
- `picture-ui.js`: 초안 편집 및 취소 가능한 픽셀 작업.
- `picture-render.js`: 격자·그룹·인쇄에서 같은 자르기/효과 표현.
- `picture-drawingml.js`: 단독/그룹 그림의 표준 DrawingML과 원본 관계/편집 확장.
- `picture-export.js`: 셀을 복제하지 않는 저장 전용 개체 사본에 효과 PNG 준비. 실제 문서나 실행 취소에 캐시를 쓰지 않음.

밝기/대비, 회색조·일부 재색, 테두리/파선, 그림자, 네온, 부드러운 가장자리, 반사는 표준 DrawingML을 사용한다. 표준과 직접 대응하지 않는 보정은 저장 전에 표시용 PNG를 만들고 원본 그림과 편집 값은 별도 관계/확장에 보관한다. Node 동기 저장에서 필요한 PNG가 없다면 효과를 버리는 대신 오류를 반환한다. 이미지 바이트를 확장 JSON의 큰 base64 문자열로 중복하지 않는다.

그림 바꾸기는 기기/온라인/클립보드에서 가능하며 위치·크기·테두리 등 배치를 유지하고 새 원본을 기록한다. 그림 레이아웃은 선택한 그림을 캡션이 있는 편집 가능한 SmartArt로 변환하고 실행 취소로 복원한다. 그림으로 저장은 매번 저장 대상을 고르는 기존 정책을 사용한다. 인쇄도 공통 그림 렌더를 사용한다.

## 명시적인 차이와 제한

Excel 그림 기능 전체의 100% 동등성을 선언하지 않는다.

- 배경 제거는 색·연결 영역과 사용자 보정이다. Excel 자동 피사체 인식과 동일한 알고리즘이 아니며 머리카락/반투명 물체의 자동 분리를 보장하지 않는다.
- 꾸밈 효과는 흐리게·연필·포스터·물감·필름 입자 5종이다. Excel 전체 카탈로그나 3D 입체 회전/재질/조명까지 제공하지 않는다.
- 자르기는 8개 직접 조절 핸들·방향별 비율·종횡비 프리셋을 지원한다. Excel의 모든 자르기 도형(타원 등)을 제공하지는 않는다.
- VBA 이름은 저장하지만 일반 VBA 코드 실행은 지원하지 않는다. 기존 지원 이동 동작만 실행한다.
- CORS를 허용하지 않는 연결 그림은 픽셀 읽기/압축이 제한된다. 로컬 그림 파일로 바꾸어 편집할 수 있다.
- 원본 복원 데이터를 보관하면 압축 그림 외에 원본도 저장된다. 압축 결과 크기와 원본 보관 여부를 함께 확인한다.
- 고유 편집 확장은 다른 프로그램이 삭제할 수 있다. Excel의 표시 결과와 위셀 재편집 가능성을 별도로 검증한다.

## 검증 기록

- 최종 컴파일 앱에서 그림 서식 22개·기존 그림 편집 7개, **29개 시나리오 328개 확인 통과**. 320px 모바일·실제 픽셀·PNG/클립보드·XLSX·Undo·보호·비동기 시트 전환을 검사했으며 페이지 오류/원격 쓰기 0.
- 전체 Node 검사 **874/874 통과**, 소스/Cloudflare 빌드 성공, 컴파일 앱 리본 명령 **366개 오류 0**.

실제 업무 파일은 원본을 읽기 전용으로 검사하며 저장소에 포함하지 않는다.

- 실제 Excel 16.0에서 그림 10개·그룹 안 그림 2개 파일을 열고 다시 저장한 뒤 129개 항목 비교: 오류·경고 0. 원본 관계를 명시한 확장으로 그림 바꾸기/압축의 복원용 원본도 유지한다.
- Open XML SDK 2.20, Office 2019 기준 원본/Excel 재저장 drawing 스키마 오류 0.
- 실제 쿠첸 정산 파일 29,369셀·8,545수식, 여행 월간 보고서 932,457셀·698수식의 전후 계산/왕복 비교 오류 0. 두 파일에는 피벗 테이블이 없어 피벗 호환성 근거로 확대 해석하지 않는다.
- 회전 90도 PNG 저장과 클립보드 결과는 320×640 크기 및 색상 픽셀 위치를 검사했다.
- 비동기 저장 중 문서 변경은 저장 전 취소한다. 셀에 그림 배치도 시작 문서·시트·그림·대상 셀·보호 상태를 검사하고 표시 중인 자르기/보정/회전을 반영한다.
