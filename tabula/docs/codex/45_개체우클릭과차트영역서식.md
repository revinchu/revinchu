# 개체 우클릭과 차트 영역 서식

2026-10-02. 기준 `c53db43`, 브랜치 `codex/object-context-format`. 사용자 승인 범위: GitHub 저장 및 기존 Cloudflare 공개 앱 업데이트.

## 구현

- 슬라이서: 잘라내기/복사/붙여넣기, 새로 고침, 오름/내림차순, 필터 해제, 다중 선택, 보고서 연결, 제거, 앞뒤 순서 하위 메뉴, 매크로 이름, 대체 텍스트, 크기·위치·잠금·인쇄 속성 및 기존 설정 창. 피벗 새로 고침은 연결된 피벗의 snapshot/memo만 제거하며 통합 문서 전체 계산 캐시를 무효화하지 않는다. 보고서 연결은 같은 원본인 피벗만 대상으로 한다.
- 피벗: 선택 위치를 값·행/열 레이블로 판별해 복사, 셀 서식, 필드 표시 형식, 새로 고침, 정렬, 필드 제거, 값 요약 기준, 값 표시 형식, 자세한 정보, 값 필드 설정, 피벗 옵션, 필드 목록을 연결한다. 값이 행에 배치된 다중 값 피벗의 두 번째 이후 측정값에서도 해당 값 필드로 drilldown한다.
- 차트: 차트 전체와 그림 영역 우클릭을 구분하고 미니 채우기·윤곽선 툴바, 스타일 재설정, 종류 변경, 서식 파일 저장/적용, 데이터 선택, 3D 회전, 서식 패널을 연결한다. 삭제 명령은 차트 삭제임을 명시한다. 차트 데이터·원본 셀은 삭제하지 않으며 Undo가 가능하다. 2D 차트에서는 3D 회전을 비활성화한다.
- 영역 서식: 자동/없음/단색/그라데이션/그림·질감/패턴 채우기, 선 없음/실선/그라데이션/자동, 색·투명도·너비·겹선·대시·끝·연결, 그림자 프리셋·크기·각도·거리·흐림, 네온, 부드러운 가장자리, 위/아래 입체·깊이·윤곽·재질·조명을 제공한다. 패널 탭은 키보드로 이동하며 작은 화면에서는 줄을 나누고 내부 스크롤한다.

## 코드 계약

`chart-area-format.js`는 영역 모델 정규화와 SVG 렌더링, `chart-area-format-ui.js`는 편집 패널, `chart-area-drawingml.js`는 표준 XML을 담당한다. `chartAreaFormat`과 `plotAreaFormat`은 서로 독립적이다. 구형 `fill/plotFill/border`는 고급 모델이 없을 때의 fallback이다. 미니 툴바는 고급 모델을 갱신하고 기존 전체 옵션의 단색 입력은 해당 고급 모델을 해제한다.

그림·질감은 패키지 미디어와 관계 ID로 보존한다. UI에서 SVG/WebP를 PNG로 바꾸어 Excel 호환 이미지를 저장하며 타일은 원본 픽셀 크기와 배율을 사용한다. 외부 이미지 관계를 임의로 다운로드하지 않는다. 채우기·선·효과·3D 속성은 WIXEL 전용 확장 없이도 `c:spPr`/`cx:spPr`에서 읽는다.

`chart-template.js`는 OPC `.crtx`를 만들고 읽는다. 원본 통합 문서의 시트 이름, 셀 값, 계열 참조 대신 예시 데이터만 저장한다. `chart-context.js`의 서식 허용 목록을 양방향 적용하며 내부 계열 서식도 값/이름/참조를 제외한다. 템플릿 적용은 현재 원본 범위와 계열 참조를 유지한다. 파일 대기 중 통합 문서·시트·개체가 바뀌면 적용하지 않는다.

`slicer-properties.js`와 `pivot-context.js`는 대상과 패치를 계산하는 DOM 독립 모듈이다. 변경은 통합 문서 트랜잭션에 포함되며 취소/Undo/읽기 전용/보호 및 열린 창의 대상 변경을 검증한다. 슬라이서 대체 텍스트·매크로 이름·인쇄·잠금 속성은 표준 drawing 속성으로 보존한다.

- 소스 UI: 슬라이서 12/12 (104 검사), 피벗 16/16 (73 검사), 차트 메뉴 7/7 (42 검사), 영역 패널 9/9 (61 검사). 격리 합성 문서 사용, 페이지 오류 및 원격 쓰기 0.
- OpenXML SDK Office2019: 영역 서식 8종 모두 XML 오류 0.
- 실제 Excel 16.0에서 단색·선형/원형 그라데이션·패턴·효과·입체·그림·채우기 없음 8개 합성 XLSX를 일반 열기/저장했다. 차트 1개, 계열 1개, 값 30/70을 유지했고 재읽기 경고 0. 채우기 종류·그라데이션 색/투명도·그림 미디어·효과·입체 속성을 확인했다.
- 실제 Excel `ApplyChartTemplate`: WIXEL `.crtx`의 서식을 적용해도 기존 값 55/88과 계열 수 1이 유지됐다. Excel이 만든 `.crtx`도 WIXEL에서 읽었다.
- 합성 다중 값 피벗을 Excel에서 열기/저장/ShowDetail 후 WIXEL로 다시 읽었다. 피벗 1개·값 2개·값 행 배치를 유지했고, 두 번째 값의 세부 정보 결과가 원본 행 수와 일치했다.
- 사용자 원본 두 업무 파일의 이전 릴리스 대비 수식 불일치 0→0, 왕복 문제 0→0. 두 파일에는 피벗이 없으므로 실제 피벗 검증은 위 합성 문서로 별도 수행했다. 원본 파일을 수정하거나 저장소에 포함하지 않았다.

## 동등성의 남은 차이

- 매크로 지정은 이름을 보존하며 브라우저에서 VBA를 실행하지 않는다. 슬라이서 그룹화는 엔진이 지원하지 않아 비활성 안내한다.
- 3D 영역은 SVG의 2차원 입체 음영으로 표시한다. Excel의 실제 카메라·광택·재질 렌더링과 픽셀 단위로 같지 않으며 패널에서 이를 알린다.
- 영역 선의 화살표는 닫힌 직사각형 영역에 적용하지 않아 비활성 표시한다.
- 모든 외부 `.crtx`와 임의의 Excel 파일에 대한 완전한 호환을 증명한 것은 아니다. 위 형식·시나리오의 실제 동작과 표준 입출력을 검증했다.
