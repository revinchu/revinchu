# 셀 스타일과 지우기 보강

WIXEL 3.0의 추가 요청을 반영한 후속 변경입니다. 기본 3.0 커밋은 `aea80c7`, 작업 브랜치는 `codex/wixel-3-cloudflare`입니다.

## 셀 스타일

홈 › 셀 스타일에서 새 스타일을 만들고 표시 형식·맞춤·글꼴·테두리·채우기·보호의 여섯 요소를 선택합니다. 서식 창에서 정의를 조정하고 미리 볼 수 있습니다. 스타일 갤러리의 우클릭 또는 Shift+F10에서 수정·복제·삭제를 선택합니다. 표준 스타일의 삭제는 막습니다.

스타일 정의와 적용한 셀의 이름 연결을 저장하며 정의 변경·삭제는 실행 취소할 수 있습니다. 목록과 대용량 블록의 서식은 값 배열을 복사하지 않는 작은 이력으로 기록합니다. 사용자가 스타일 적용 후 직접 다르게 조정한 서식은 유지합니다.

스타일 병합은 사용자가 고른 `.xlsx`, `.xlsm`, `.xltx`, `.xltm`, `.wixel`, `.json` 파일의 이름 있는 스타일 정의를 가져옵니다. 현재 통합 문서의 셀·시트·수식·매크로를 불러오거나 바꾸지 않습니다. 중복 이름은 기존 정의 유지 또는 가져온 정의로 덮어쓰기를 선택합니다. 파일 선택이나 취소만으로 병합하지 않습니다. 여러 Excel 창의 열린 통합 문서 목록을 공유하는 데스크톱 기능과는 입력 방식이 다릅니다.

표준 XLSX에는 `cellStyleXfs`, `cellStyles`, 셀 `xfId`와 구성요소 `apply*`를 기록합니다. 이름·부모 서식·직접 서식·숨김 속성·대각선 테두리를 왕복 검증했습니다. 독립 openpyxl 파서에서도 이름과 여섯 서식 요소가 인식됩니다. 이 결과는 실제 Excel 데스크톱의 열기·복구 메시지 검증을 대신하지 않습니다.

## 지우기와 하이퍼링크

- **하이퍼링크 지우기**: 링크 속성만 없애며 셀 내용과 서식을 유지합니다.
- **하이퍼링크 제거**: 실제 링크가 있는 셀의 링크와 셀 서식을 초기화합니다. 선택한 다른 셀은 그대로 둡니다.
- **HYPERLINK 수식**: 링크 속성과 구분합니다. 위 명령으로 수식을 몰래 값으로 바꾸지 않으며 링크 기능까지 없애려면 값 붙여넣기를 안내합니다.
- 잠긴 셀과 서식 보호를 확인하고 비연속 선택·실행 취소를 지원합니다.
- 서식·메모 지우기는 파일의 수식 저장값과 수식 해석 정보를 보존합니다.
- 서식 지우기·표시 형식 변경·서식 복사/붙여넣기는 앞자리 0이 있는 텍스트, 수식처럼 생긴 텍스트, 숫자·논리·오류 값의 자료형을 유지합니다. 실제 재입력 때만 현재 표시 형식에 따라 해석합니다. 메모만 붙여넣기와 표시 문구를 바꾸지 않는 하이퍼링크 삽입도 같은 보존 규칙을 따릅니다.
- 조건부 서식은 선택한 범위만 빼고 나머지 적용 범위와 상대 참조 수식을 유지합니다.

동작 의미는 Microsoft의 [Range.ClearHyperlinks](https://learn.microsoft.com/en-us/office/vba/api/excel.range.clearhyperlinks), [Hyperlinks.Delete](https://learn.microsoft.com/en-us/office/vba/api/excel.hyperlinks.delete), [하이퍼링크 제거 안내](https://support.microsoft.com/en-us/word/remove-or-turn-off-hyperlinks)를 참고했습니다.

## 내부 자료형 보존 계약

`cellData(cell, newStyle)`은 서식 교체 시 원래 raw의 해석을 보존합니다. `null`은 서식 제거입니다. 필요한 경우에만 `inputType: 'text' | 'value'`를 저장하고, `setInput`은 이를 새 입력으로 전달하지 않습니다. 셀을 직접 재구성하여 서식을 바꾸지 말고 이 경로를 사용해야 합니다. XLSX 읽기는 표준 `t=n/b/e`와 `@` 표시 형식을 별개로 처리합니다.

## 남은 검증 및 배포

실제 Excel 365 앱에서의 열기·복구 알림 검증과 사용자 업무 파일 전후 비교는 실행하지 못했습니다. Google Sheets 비공개 OAuth 및 실시간 공동 편집은 구현 완료 범위에 포함하지 않습니다. QUERY 자체 `format` 절의 표시 우선순위는 이번 변경 범위가 아닙니다.

이 문서의 셀 스타일·지우기 검증을 마친 당시(`6514d4a`)에는 Cloudflare 이메일 확인과 Wrangler 배포 인증이 남아 있어 로컬 런타임까지만 검증했습니다. 이후 이메일 인증·OAuth·최초 공개 배포와 작은 합성 데이터 운영 검증을 완료했습니다. 실제 주소·배포 버전·운영 결과는 [12_공개배포와운영검증.md](12_공개배포와운영검증.md)를 확인하세요. 위 269개 단위 테스트와 로컬 UI 수치는 해당 커밋의 검증 이력으로 유지합니다.
