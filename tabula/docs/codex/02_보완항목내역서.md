## P0 — 보안 · 배포 안정성 (인터넷에 공개하기 전 필수)

### P0-1. 웹 가져오기 중계(`/api/fetch`) SSRF 강화 — 구현·검증 완료
- `server/network.js`: DNS가 반환한 모든 IP 검사, 검증한 IP로 실제 연결 고정, 원래 호스트의 TLS 인증서 검증 유지.
- HTTP(S) 80/443만 허용, 리디렉션 단계마다 재검사(최대 5회), 전체 15초, 압축 전후 응답 각각 5MB 제한.
- 사설·루프백·링크로컬·CGNAT·IPv6 ULA·mapped·리디렉션 우회·DNS 재바인딩 등에 대한 Node 테스트 추가. 실제 공개 HTTPS 가져오기 성공 확인.

### P0-2. 인증 기본값 — 구현·검증 완료
- 기본 `HOST=127.0.0.1`. 외부 주소로 수신할 때 `TABULA_TOKEN`이 없으면 시작을 거부합니다.
- 네이버 중계도 인증을 거칩니다. 무암호 로컬 모드는 요청 Host·Origin·접속 IP를 검사합니다.
- 웹 가져오기·네이버 대화상자에서 토큰 입력과 잘못된 토큰 재입력을 검증했습니다. 계정별 로그인·문서별 권한은 별도 장기 작업입니다.

### P0-3. 요청 제한 · HTTPS — 앱 측 제한 완료, 운영 설정 남음
- 중계 API에 IP당 기본 120회/분 제한, 보안 헤더, 정적 파일 허용 목록을 적용했습니다. 저장 본문 제한은 50MB입니다.
- 공개 운영 전 `04_서버호스팅가이드.md`의 HTTPS·HSTS·리버스 프록시 설정이 필요합니다. 프록시 뒤에서는 앱이 보는 IP가 같으므로 실제 클라이언트별 제한은 프록시에도 설정하세요.

### P0-4. 엑셀 365 확인란 저장 형식 실제 검증
- 현재: 확인란을 엑셀 365 방식(`xfComplement` + `xl/featurePropertyBag/featurePropertyBag.xml`)으로 씁니다. 형식은 공개 자료 기준으로 작성했고 **실제 엑셀에서 열어 확인하지 못했습니다.**

### P1-3. 개체 · 서식 세부 (#58, #74)
- 있음: 도형 채우기/윤곽/텍스트, 맞춤 · 회전 · 선택 창 · 크기, 기호 삽입, 대각선 테두리, 축소 맞춤, 무늬 채우기, 그라데이션.
- 없음/약함: 도형 효과(그림자 외 3차원 · 베벨 · 네온), 텍스트 효과(WordArt), 수식 편집기(수학 식 개체), 데이터 막대 "막대만 표시"·여백 세부 확인 필요, 페이지 나누기 미리 보기(현재 `window.print()` 기반 인쇄).
- 완료 기준: 엑셀에서 만든 해당 개체가 들어간 파일을 열었을 때 모양 유지 + 저장 후 엑셀에서 다시 열어도 유지.

### P1-4. 남은 엑셀 차이 메모
- 1904 날짜 체계: XLSX의 `date1904`를 감지해 경고하지만 계산·표시·재저장을 지원하지 않습니다. 숫자를 일괄 보정하면 일반 숫자·수식이 손상되므로 워크북 날짜 체계부터 모델링하고 xlsb·차트·피벗까지 함께 검증해야 합니다.
- `TEXT(x,"aaa")`: 파일 저장값은 `"aaa"`(만든 쪽이 다른 로캘 · 구글 시트)였지만 한국어판 엑셀은 요일('수')을 보여 줍니다 → **현재 동작 유지**가 결정 사항.
- `TODAY()/NOW()/RAND()` 계열은 저장값과 다른 것이 정상 (check 결과에서 제외해 읽기).
- 구글 시트 오류값 `#ERROR!` 는 WIXEL 에서 `#REF!` 등으로 보임 — 필요 시 표시만 맞춤.
- 윗주(phonetic): 읽을 때 본문과 섞이지 않게 처리됨. 편집 UI 없음(한국어 사용 빈도 낮음).
