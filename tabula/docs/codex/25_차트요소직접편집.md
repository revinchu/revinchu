# 25. 차트 요소 직접 편집 (2026-10-02)

## 직접 조작

- 제목·범례: 클릭해서 선택한 다음 끌거나 방향키로 이동한다. Ctrl+방향키는 10px 이동, Esc는 진행 중 미리보기를 취소한다. 차트 자체의 위치는 바뀌지 않는다.
- 계열·데이터 요소: 한 번 클릭하면 계열, 같은 계열을 다시 클릭하면 해당 데이터 요소를 선택한다. Ctrl+1 또는 더블클릭은 현재 선택의 서식 창을 연다. 열린 서식 창도 다른 요소 선택을 따라간다.
- 원형·도넛: 계열 또는 조각을 바깥쪽으로 끌어 분리하며, 서식 창에서 0–400% 값을 입력할 수 있다. 조각의 명시적 0은 계열 분리율을 상속하지 않는다. 3차원 원형은 Y 투영을 역보정하며 기본 3D 도넛은 제공하지 않는다.
- Delete: 제목·범례는 해당 요소만 제거한다. 계열·데이터 점은 해당 계열을 차트에서 제거하고 원본 셀을 유지한다. 마지막 계열을 삭제해도 차트 개체는 남는다. 데이터 레이블은 해당 계열의 레이블을 제거한다. 차트의 빈 영역을 선택한 상태에서 Delete하면 전체 차트를 삭제한다.
- 색 변경은 선택한 계열 또는 데이터 요소에만 적용한다. 기본 막대·꺾은선·산점·원형·도넛의 계열/요소와 범례 색을 검사한다. 영역형은 계열 채우기를 편집하며 별도 요소 색 기능을 제공하지 않는다.

선택 표시와 드래그 미리보기는 저장 모델 밖에 있다. 드래그 종료 때 한 번의 트랜잭션으로 확정하며 Esc·문서/시트 전환·읽기 전용·시트 보호를 확인한다. 모델리스 서식 창은 이전 문서에 늦게 도착한 입력을 적용하지 않는다. 설정에는 해당 요소의 색·텍스트·분리율과 자동 위치 복원이 표시되고, 기존 전체 차트 옵션 창도 유지한다.

## 모델·저장

`titleLayout/legendLayout: {x,y,w?,h?}`는 차트 전체 기준 좌상단 비율이다. SVG는 좌상단이 (0,0)인 그룹을 해당 위치로 옮긴다. 표준 차트의 `c:layout/c:manualLayout`은 edge 모드로 왕복한다.

`seriesFmt[fi].explode`는 계열, `pointExplosion[p]`는 원본 범주 번호별 조각 분리율이다. `c:ser/c:explosion`, `c:dPt/c:explosion`으로 저장하며 색과 분리율을 같은 dPt에 합친다. `_fi/_pi`는 화면에서 숨긴 계열·범주가 있어도 실제 원본 번호로 편집하기 위한 인덱스다.

기존 `hiddenSeries` 저장에서 삭제된 첫 계열의 참조가 남은 계열에 재사용되던 오류를 수정했다. 저장에서는 원본 `_fi`로 참조를 찾고, 이미 출력에서 제거한 계열을 전용 확장으로 한 번 더 숨기지 않는다. Excel 파일에는 남은 계열만 있으며 원본 셀은 유지된다.

지도·폭포·히스토그램 등 ChartEx의 자유 제목·범례 위치는 위셀 확장으로 보존한다. 해당 ChartEx 위치를 Excel 기본 배치와 동일하게 표현하는 표준 위치 어댑터는 이번 범위에 없다. UI에서도 이 제한을 표시한다. 기존 범주 필터(hiddenCats)의 Excel 표준 보존은 완성되지 않았으며, 원본 참조가 재계산되면 Excel은 전체 범주를 표시할 수 있다. 원본 데이터 연결을 끊는 값 스냅샷 변환은 하지 않는다.

## 검증

설치된 Excel16.0의 새 숨김 COM 인스턴스에서 pie/line/column의 Point.Delete, 선택 객체 Delete, Series.Delete 9경로를 검사했다. 모두 계열2→1, 원본 셀·수식 불변이었다. 기존 사용자의 Excel 인스턴스와 업무 파일은 열지 않았다.

표준 확장 없는 합성7개를 실제 Excel에서 정상 열고 재저장했다. 제목·범례 수동 위치, 점 분리(명시0 포함), 계열 삭제 뒤 남은 C열 원본 참조·색, 마지막 계열 삭제 뒤 빈 차트 보존을 확인했다. 재저장본의 WIXEL 재읽기·다시 저장도 검증한다. 모든 파일이나 픽셀 수준 동등성을 뜻하지 않는다.
