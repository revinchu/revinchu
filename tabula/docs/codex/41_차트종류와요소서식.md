# 차트 종류와 요소 서식 보강 — 2026-10-02

## 문제와 변경

기존에 선버스트 엔진은 있었지만 삽입 리본의 계층 구조 메뉴에는 트리맵만 노출됐다. 대조 원형·대조 가로 막대형도 리본에서 누락됐다. 계층 데이터는 항목 필터를 거치면 부모 정보가 사라졌고, 일부 선택 색상이 원본 항목 번호를 따르지 않았다.

- 삽입의 **모든 차트**, 선버스트/트리맵, 대조 원형/막대, 표면/등고선, 지도 메뉴를 연결했다. 모든 버튼에 접근 가능한 이름과 KeyTip이 있다.
- 기존 61개에서 **86개 세부 형태**로 확장했다(모델 유형 22개, 갤러리 분류 17개). 원통·원뿔·피라미드 묶은/누적/100%누적, 세로 막대 깊이 축, 누적 막대·선 콤보와 누적 영역·막대 콤보를 포함한다. 메뉴 항목만 늘린 것이 아니라 3차원 도형과 계열 깊이를 렌더링한다.
- 콤보는 계열마다 종류, 배치, 왼쪽 기본 축/오른쪽 보조 축을 편집한다. 종류 변경 시 이전 유형의 계열 오버라이드를 해제하며 기존 색 등 공통 서식은 유지한다.
- 선버스트는 중심 구멍과 계층별 고리, 빈 하위 분류를 지원한다. 트리맵은 상위 레이블 배너/겹치기/없음을 지원한다. 필터 전 원본 번호와 안정적인 계층 경로를 보존한다.
- 차트의 축·계열·조각·계층 항목·레이블을 선택해서 서식 창에서 직접 변경한다. 상위 항목의 색은 하위 항목에 상속되며 개별 지정 색은 우선한다. 축 범위/주 단위/역순/표시 형식, 선/표식/레이블 내용·색·글꼴, 막대 간격·겹침 등을 연결했다.
- 축 Delete는 선택 축만 숨긴다. 계열 레이블 Delete는 값/항목명/계열명/백분율을 모두 끈다. 서식 창은 실행 취소와 문서/시트 전환을 반영하며 보호 및 완료 표시된 문서를 수정하지 않는다.
- 선택 요소 패널은 모바일 폭에 맞추며 본문을 스크롤한다. 차트에서 빠르게 선택해 서식 창이 열려도 Delete/Escape가 그리드 편집 문맥에 남는다.

기준은 Microsoft의 [차트 종류](https://support.microsoft.com/en-us/excel/available-chart-types-in-office), [선버스트 설명](https://support.microsoft.com/en-gb/office/create-a-sunburst-chart-in-office-4a127977-62cd-4c11-b8c7-65b84a358e0c), [계층 차트 설명](https://www.microsoft.com/en-us/copilot/blog/2015/08/11/breaking-down-hierarchical-data-with-treemap-and-sunburst-charts/)을 참고했고, 실제 Excel 생성 파일도 함께 비교했다.

## 데이터와 파일 계약

`chart-hierarchy.js`는 DOM 없이 계층 트리·색상 상속·레이블·트리맵 배치를 계산한다. `buildChartHierarchy`는 원본 데이터 경로를 JSON 문자열 key로 제공하며 _pi 원본 점 번호와 catLevels 구간을 유지한다. 최대 30,000개 항목/64단계/200,000개 계층 칸을 넘으면 한국어 안내를 표시한다. 0·음수·비숫자는 면적에서 제외한다.

`chartComboDefaults`는 comboLayout별 계열 종류/축/grouping 기본값을 제공한다. barShape은 box/cylinder/cone/pyramid, 3차원 세로 막대 grouping=standard는 계열 깊이를 사용한다. seriesFmt에는 개별 grouping과 barShape를 저장할 수 있다.

ChartEx의 상위 레이블, 범주·계열 레이블, 글꼴·색과 별도 colorStyle 색 목록을 읽고 쓴다. 일반 OOXML 차트에도 모양·계열별 grouping과 레이블 서식을 기록한다. 팔레트는 이름 또는 가져온 색 배열을 받는다. 자체 확장 정보가 없는 표준 파일 왕복을 별도로 검사한다.

## 검증

- `test/chart-hierarchy.test.js`, `chart-variants.test.js`, `chart-ex-fidelity.test.js`, `chart-selection-ops.test.js` 등 DOM 없는 렌더·모델·표준 OOXML 검사.
- `tools/chart-parity-ux.mjs`: 리본 실제 메뉴, 검색 확정/재열기, 콤보 기본값, 계열 서식, 축 선택/삭제/Undo, 계층 색, 완료 표시 보호, 390px 모바일.
- 기존 `chart-direct-editing.mjs`, `chart-upgrade-ux.mjs`, `chart-dialog-ux.mjs` 회귀와 리본 스모크.
- 실제 Excel 16.0이 생성한 계층 차트 2개 판독. 위셀 합성 차트 13개를 Excel에서 정상 열기→SaveAs→재읽기. Office2019 SDK 차트 요소 XML 검사 13개 오류 0(통합문서 전체 스키마 검사를 의미하지 않는다).
- 사용자 원본 두 개 읽기 전용 회귀: 쿠첸 정산 8,545개 수식, 헬로우트래블 2018.12 698개 수식. 기존 대비 수식 불일치 0→0, 저장·재열기 문제 0→0. 두 파일에 피벗이 없어 이번 검사가 실제 피벗 계산 검증을 대신하지 않는다. 원본과 생성된 업무 데이터는 커밋하지 않는다.

최종 단위 **829/829**, 배포 번들의 차트 UI/렌더 검사 **98/98**, 리본 명령 **338개 오류 0**을 확인했다. 단일 파일 빌드와 Cloudflare 빌드 모두 성공했다. 배포 버전은 로컬 `.local/release.json` 및 공개 배포 검증 기록을 확인한다.

## 남은 동등성 범위

**86개 선택 항목은 Excel 기능 전체 또는 픽셀 동등성 100%를 뜻하지 않는다.** 다음은 완료로 주장하지 않는다.

| 범위 | 남은 차이 |
|---|---|
| 계층 레이블 | 공간에 따른 내부 자동 배치. 파일의 위치 속성은 보존하지만 모든 Excel 배치 옵션과 화면이 같지는 않음 |
| 색상 스타일 | colorStyle 기본 색은 반영. 후속 variation 명암 규칙 전체는 미지원 |
| 부모별 임의색 | hierarchyColors는 위셀 확장으로 보존. Excel 표준 dPt에 동일한 부모 경로 표현은 미구현 |
| 지도 | 국가/지역 단위. 도시·우편번호 및 Excel 온라인 지도 전체 범위 미지원 |
| 표면형 축 | 독자 3축 렌더링. 새 일반 축 직접 선택/범위 편집에서 제외 |
| 축·분석 서식 | 로그/날짜 축 전체 옵션, 모든 오차 막대·추세선·효과·글꼴·요소별 레이아웃은 추가 호환 검사와 구현이 필요 |
| 통계·고급 차트 | 모든 Excel 버전, 모든 피벗 차트 조합, 자동 권장 알고리즘·충돌 회피·3D 화면의 픽셀 일치는 미검증 |

이후의 동등성 판정은 종류 이름의 개수 대신 실제 Excel 파일별 값·형태·편집·저장·재열기 결과로 진행한다.
