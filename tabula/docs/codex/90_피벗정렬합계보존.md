## 재현된 문제와 설계

리본/빠른 정렬/일반 정렬 대화상자가 피벗 출력을 일반 셀 범위로 취급했다. 합성 피벗의 내림차순에서 총합계 120이 첫 데이터 행으로 올라갔고, 일반 데이터와 피벗을 함께 선택하면 서로의 셀이 섞였다. 오름차순에서도 피벗 정의에 정렬 기준이 기록되지 않아 새로 고침 후 순서가 사라졌다. 수정 전 Chromium 기본 18사례 중 16실패, 기존 피벗 전용 우클릭·필터 경로 2통과를 기록했다.

- `pivot-sort-scope.js`는 실제 피벗 소유 범위로 정렬 대상을 분류한다. 하나의 피벗 내부 선택은 피벗 정의 변경으로 처리한다. 일반 범위에 피벗이 걸치거나 여러 피벗이 섞인 경우 직접 셀 이동을 차단한다. 값이나 캡션이 '총합계'인지로 판별하지 않는다.
- 앱은 일반 표/머리글/연속 영역 추측 전에 피벗 정렬로 연결한다. 행·열 항목, 다단계 부분합, 접힌 그룹과 값 배치의 역할 메타데이터로 같은 수준의 항목을 정렬한다. 원본 셀과 합계 위치를 보존하며 한 번의 실행 취소로 복원한다.
- 모델의 `sortRange`, `sortMulti`, `sortBlock`도 피벗 출력과의 교차를 검사한다. 일반 필터 드롭다운, 색 정렬, 가로 정렬, 뒤늦게 확인한 일반 정렬 대화상자에서도 피벗을 직접 이동시키지 못한다. 인접한 일반 데이터와 원본 시트 정렬은 허용한다.
- 값 셀에서 선택한 반대 축 항목 경로를 `sort.at`으로 전달한다. 총합계 열 기준과 개별 열 기준을 구별한다. 맨 아래 총합계 행에서 특정 열의 값을 선택하면 열 항목을 정렬한다. 총합계 교차점·보고서 필터·빈 줄에서는 다른 필드를 임의로 선택하지 않는다.
- 기타 정렬 옵션은 선택한 열/행의 값 기준과 총합계 기준을 전환할 수 있다. 기존 값 기준과 사용자 지정 목록 설정을 보존한다.
- 값 기준 오름차순에서 오류 항목이 숫자보다 먼저 나오던 비교를 수정했다. 합성 Excel 16.0 build 14334 피벗 AutoSort에서 확인한 대로 양방향 모두 오류 항목을 정상값 뒤에 놓는다.
- XLSX 표준 `autoSortScope`에 지표와 반대 축 항목 참조를 기록한다. 참조는 공유 캐시 순서가 아닌 해당 피벗 필드 항목 순서다. 특정 열/행 정렬 기준이 저장 후 사라지는 문제를 고친다.

동작 기준: [Microsoft 피벗 테이블 정렬](https://support.microsoft.com/en-us/excel/sort-data-in-a-pivottable-or-pivotchart). 개별 값/부분합은 같은 수준의 항목을 정렬하며 총합계 열의 값도 정렬 기준으로 사용할 수 있다. 피벗에 대한 셀/글꼴 색 정렬은 지원 대상이 아니다.
