# Tabula — 브라우저용 엑셀 스타일 스프레드시트

엑셀(Microsoft Excel)의 화면 구성과 조작 방식을 그대로 따른 웹 스프레드시트입니다.
외부 라이브러리 없이 순수 HTML/CSS/JavaScript(ES 모듈)로 동작합니다.

![Tabula 화면](docs/screenshot.png)

## 실행

```bash
cd tabula
npm start          # http://localhost:5178
npm test           # 수식 엔진·채우기·CSV 단위 테스트 (node --test)
```

Node 18 이상이면 됩니다(설치할 패키지 없음). `index.html`을 아무 정적 서버로 열어도 동작합니다.

## 주요 기능

| 영역 | 내용 |
|------|------|
| 화면 | 제목 표시줄(자동 저장 토글, 실행 취소/다시 실행), 리본(파일·홈·삽입·페이지 레이아웃·수식·데이터·검토·보기·도움말), 이름 상자, 수식 입력줄, 시트 탭, 상태 표시줄(평균·개수·합계, 확대/축소) |
| 입력 | 셀에 바로 입력, F2/더블클릭 편집, Tab→Enter 시 시작 열로 복귀, Alt+Enter 줄 바꿈, Ctrl+Enter 선택 영역 일괄 입력, 한글 IME 조합 입력 |
| 수식 | 연산자 우선순위, 상대/절대 참조(F4 전환), 다른 시트 참조(`Sheet2!A1`, `'시트 이름'!A1`), 열 참조(`A:A`), 순환 참조 감지, 입력 중 셀 클릭·방향키로 참조 삽입(색상 강조), 함수 자동 완성, 괄호 자동 닫기 |
| 함수 | SUM, AVERAGE, COUNT/COUNTA/COUNTIF(S), SUMIF(S), IF/IFS/IFERROR, VLOOKUP/HLOOKUP/XLOOKUP/INDEX/MATCH, 텍스트·날짜·수학 함수 등 80여 개 |
| 서식 | 글꼴/크기/굵게/기울임/밑줄/취소선, 글꼴 색·채우기 색(테마 팔레트), 테두리, 맞춤·들여쓰기·자동 줄 바꿈, 셀 병합, 표시 형식(일반·숫자·통화·회계·날짜·시간·백분율·분수·지수·텍스트, 자릿수 늘림/줄임), 서식 복사, 셀 스타일, 표 서식, 조건부 서식(셀 강조 규칙·상위 규칙·데이터 막대·색조) |
| 편집 | 복사/잘라내기/붙여넣기(값·수식·서식·행/열 바꿈, 외부 TSV), 채우기 핸들(숫자 계열·요일·월·“항목1” 증가·수식 복사), Ctrl+D/Ctrl+R, 행·열 삽입/삭제(수식 참조 자동 조정), 정렬, 중복 제거, 찾기/바꾸기/이동, 메모 |
| 파일 | 브라우저(localStorage) 자동 저장, `.tabula`(JSON) 저장/열기, CSV 가져오기/내보내기(UTF-8 BOM), 인쇄 |

## 구조

```
tabula/
├── index.html        # 화면 뼈대
├── styles.css        # 엑셀 스타일
├── server.js         # 정적 파일 서버 (포트 5178)
├── src/
│   ├── formula.js    # 수식 엔진: 토크나이저·파서·평가기·함수·참조 재작성
│   ├── format.js     # 표시 형식, 입력값 해석
│   ├── workbook.js   # 통합 문서 모델: 셀·재계산·실행 취소·행/열 구조 변경·병합·조건부 서식
│   ├── series.js     # 채우기 핸들 연속 데이터
│   ├── csv.js        # CSV/TSV
│   ├── ribbon.js     # 리본 정의/렌더링
│   ├── ui.js         # 메뉴·대화상자·알림
│   ├── app.js        # 그리드 렌더링·선택·편집·키보드/마우스·명령
│   ├── icons.js, funcinfo.js, samples.js
└── test/             # node --test 단위 테스트
```

## 제한 사항

- 화면 그리드는 DOM 테이블로 그리므로 10,000행 × 702열(ZZ)까지 지원합니다.
- .xlsx 파일 읽기/쓰기, 차트, 피벗 테이블, 필터, 틀 고정은 아직 지원하지 않습니다.
- 데이터는 사용 중인 브라우저에만 저장됩니다. 다른 기기로 옮기려면 `파일 → 다른 이름으로 저장`으로 `.tabula` 파일을 내려받으세요.
